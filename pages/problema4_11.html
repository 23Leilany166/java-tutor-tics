Problema 4.11

Mezcla alfabética de los países de América

Descripción

Se tienen tres arreglos: SUR, CENTRO y NORTE que almacenan los nombres de los países del Sur, Centro y Norteamérica respectivamente. El programa mezcla los tres arreglos para crear un cuarto arreglo AMERICA con los países ordenados alfabéticamente.

Diagramas de flujo

Código Java

public class Problema4_11 {
    public static String[] mezclarArreglos(String[] sur, String[] centro, String[] norte) {
        int tps = sur.length, tpc = centro.length, tpn = norte.length;
        String[] america = new String[tps + tpc + tpn];
        int ps = 0, pc = 0, pn = 0, pa = 0;
        while (ps < tps && pc < tpc && pn < tpn) {
            if (sur[ps].compareToIgnoreCase(centro[pc]) <= 0 && sur[ps].compareToIgnoreCase(norte[pn]) <= 0)
                america[pa++] = sur[ps++];
            else if (centro[pc].compareToIgnoreCase(sur[ps]) <= 0 && centro[pc].compareToIgnoreCase(norte[pn]) <= 0)
                america[pa++] = centro[pc++];
            else america[pa++] = norte[pn++];
        }
        return america;
    }
}
