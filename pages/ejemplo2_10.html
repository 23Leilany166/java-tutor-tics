Ejemplo 2.10

Estructura selectiva doble y anidada en Java

Ejemplo

Análisis del caso

Analicemos el siguiente caso. En este ejemplo se presenta una estructura selectiva doble y anidada, en la cual se utilizan tres condiciones (condición1, condición2 y condición3) para determinar qué operaciones realizar según el resultado de cada evaluación.

Diagrama de flujo

Código representativo en Java


public class Ejemplo2_10 {
    public static void main(String[] args) {
        boolean condicion1 = true;
        boolean condicion2 = false;
        boolean condicion3 = true;

        if (condicion1) {
            if (condicion2) {
                System.out.println("Operación 21");
            } else {
                System.out.println("Operación 22");
            }
        } else {
            if (condicion3) {
                System.out.println("Operación 31");
            }
        }
    }
}

Este código muestra cómo se implementa la estructura selectiva doble y anidada en Java. Dependiendo de las condiciones, se ejecutará una de las tres operaciones posibles.
