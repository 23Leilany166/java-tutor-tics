Práctica 3.18

Potencia sin usar operador de potencia

Construir un algoritmo que calcule base^exponente sin utilizar Math.pow. Se asume exponente entero no negativo.

Idea

  • Inicializar resultado = 1.
  • Multiplicar resultado por la base, exp veces.
  • Si exp = 0, devolver 1.

Código (Java)


// src/Practica3_18.java
public class Practica3_18 {
    public static double powNoPow(double base, int exp) {
        if (exp == 0) return 1.0;
        double r = 1.0;
        for (int i = 1; i <= exp; i++) r *= base;
        return r;
    }
}

Pruebas (JUnit)


// tests/TestPractica3_18.java
import org.junit.Test;
import static org.junit.Assert.*;

public class TestPractica3_18 {
    @Test
    public void testBasico() {
        assertEquals(8.0, Practica3_18.powNoPow(2.0, 3), 1e-9);
        assertEquals(1.0, Practica3_18.powNoPow(5.0, 0), 1e-9);
    }
}

Práctica 3.19

Potencia sin multiplicación ni operador de potencia

Calcular base^exponente sin utilizar Math.pow ni el operador *, empleando sumas repetidas.

Lógica del algoritmo

  • Inicia el resultado en la base.
  • Para cada iteración, suma el valor acumulado tantas veces como indique la base.
  • Evita operaciones de potencia y multiplicación.

Código (Java)


// src/Practica3_19.java
public class Practica3_19 {
    public static int powNoMul(int base, int exp) {
        if (exp == 0) return 1;
        int resultado = base;
        for (int i = 1; i < exp; i++) {
            int suma = 0;
            for (int j = 0; j < base; j++) {
                suma += resultado;
            }
            resultado = suma;
        }
        return resultado;
    }
}

Pruebas (JUnit)


// tests/TestPractica3_19.java
import org.junit.Test;
import static org.junit.Assert.*;

public class TestPractica3_19 {
    @Test
    public void testBasico() {
        assertEquals(8, Practica3_19.powNoMul(2, 3));
    }
}

Práctica 3.20

Recibos de la Compañía de Luz del Centro

La empresa desea calcular el costo de electricidad para cada cliente y obtener el total de cobros del periodo.

Lógica del problema

  • Leer nombre, dirección y registros inicial y final del cliente.
  • Calcular consumo = registro final - registro inicial.
  • Aplicar las reglas de cobro según el rango de consumo.
  • Imprimir recibo y sumar al total general.

Código (Java)


// src/Practica3_20.java
public class Practica3_20 {
    public static double calcularCosto(double consumo) {
        double costo;
        if (consumo <= 140) costo = 35;
        else if (consumo <= 310) costo = 35 + (consumo - 140) * 0.98;
        else costo = 35 + 170 * 0.98 + (consumo - 310) * 0.67;
        return costo;
    }
}

Pruebas (JUnit)


// tests/TestPractica3_20.java
import org.junit.Test;
import static org.junit.Assert.*;

public class TestPractica3_20 {
    @Test
    public void testCostoAlto() {
        assertEquals(35 + 170 * 0.98 + (400 - 310) * 0.67, Practica3_20.calcularCosto(400), 1e-9);
    }
}
