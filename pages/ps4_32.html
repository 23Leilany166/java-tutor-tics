Práctica 4.32

Suma de una matriz con la traspuesta de otra

Dada una matriz A(M×N) y una matriz B(N×M), construya un algoritmo que obtenga la suma de A + Bᵀ e imprima la matriz resultante.

Datos del problema

  • A[1..M, 1..N], B[1..N, 1..M]: arreglos bidimensionales
  • 1 < M < 10, 1 < N < 10

Ejemplo en Java


int[][] A = {{1, 2}, {3, 4}};
int[][] B = {{5, 6}, {7, 8}};

int[][] R = Practica4_32.sumarConTraspuesta(A, B);
Practica4_32.imprimirMatriz(R);

// Salida esperada:
// 6 9
// 9 12

Prueba JUnit


@Test
public void testSumaConTraspuesta() {
    int[][] A = {{1, 2}, {3, 4}};
    int[][] B = {{5, 6}, {7, 8}};
    int[][] esperado = {{6, 9}, {9, 12}};
    int[][] resultado = Practica4_32.sumarConTraspuesta(A, B);
    for (int i = 0; i < 2; i++)
        assertArrayEquals(esperado[i], resultado[i]);
}
