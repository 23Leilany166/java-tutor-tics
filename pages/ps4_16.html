Práctica 4.16

Diagonal de una matriz cuadrada

Escriba un diagrama de flujo tal que, dada una matriz A(N x N), escriba los elementos de su diagonal principal.

Datos del problema

  • A[1..N, 1..N]: arreglo bidimensional de tipo real
  • 1 < N < 50

Lógica

Para mostrar la diagonal principal, basta recorrer la matriz con un solo índice i e imprimir A[i][i] para cada fila.

Código en Java


// src/Practica4_16.java
public static void imprimirDiagonal(double[][] A, int N) {
    System.out.println("Diagonal principal de la matriz:");
    for (int i = 0; i < N; i++) {
        System.out.print(A[i][i] + " ");
    }
}

Ejemplo de entrada y salida


Entrada:
N = 3
Matriz:
1 2 3
4 5 6
7 8 9

Salida:
Diagonal principal: 1 5 9
