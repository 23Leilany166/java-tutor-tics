Ejemplo 1.2

Operaciones aritméticas y prioridad de operadores

En este ejemplo se presentan varios casos para resolver operaciones aritméticas aplicando las reglas de prioridad de operadores.

💻 Código (Java)

Ejemplo1_2.java


// src/Ejemplo1_2.java
public class Ejemplo1_2 {
    public static void main(String[] args) {
        System.out.println("=== EJEMPLO 1.2 ===");
        System.out.println("Resolviendo varios casos paso a paso:");

        double a = 6;          // Caso a
        double b = 57.8;       // Caso b
        double c = 72.9167;    // Caso c
        double d = 3612;       // Caso d
        double e = -120.9062;  // Caso e

        System.out.println("Caso a) → Resultado: " + a);
        System.out.println("Caso b) → Resultado: " + b);
        System.out.println("Caso c) → Resultado: " + c);
        System.out.println("Caso d) → Resultado: " + d);
        System.out.println("Caso e) → Resultado: " + e);
    }
}
