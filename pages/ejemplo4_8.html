Ejemplo 4.8

Arreglo de reales con índices negativos

Ejemplo

Descripción

Consideremos el arreglo de reales del ejemplo anterior, utilicemos ahora índices negativos. Su representación queda como se muestra en la figura correspondiente del libro.

MATRIZ1 = ARREGLO [-11..3, -17..-13] de reales.

El número total de elementos se obtiene mediante: NTE = (3 - (-11) + 1) * (-13 - (-17) + 1) = 15 × 5 = 75.

  • Cada elemento de MATRIZ1 será un número real.
  • Para hacer referencia a cada elemento se usarán dos índices, y el nombre de la variable tipo arreglo será: MATRIZ1[i, j].

Representación textual

        MATRIZ1
       -17  -16  -15  -14  -13
-11     [ ]  [ ]  [ ]  [ ]  [ ]
-10     [ ]  [ ]  [ ]  [ ]  [ ]
 -9     [ ]  [ ]  [ ]  [ ]  [ ]
 ...     ⋮    ⋮    ⋮    ⋮    ⋮
  2     [ ]  [ ]  [ ]  [ ]  [ ]
  3     [ ]  [ ]  [ ]  [ ]  [ ]

Donde:
   -11 ≤ i ≤ 3
   -17 ≤ j ≤ -13

Fragmento representativo en Java

// src/Ejemplo4_8.java
public class Ejemplo4_8 {
    public static double[][] crearMatriz() {
        int filas = (3 - (-11)) + 1;      // 15 filas
        int columnas = (-13 - (-17)) + 1; // 5 columnas
        double[][] matriz = new double[filas][columnas];
        double valor = 1.0;
        for (int i = 0; i < filas; i++) {
            for (int j = 0; j < columnas; j++) {
                matriz[i][j] = valor++;
            }
        }
        return matriz;
    }

    public static int contarElementos(double[][] matriz) {
        int total = 0;
        for (double[] fila : matriz) total += fila.length;
        return total;
    }

    public static void main(String[] args) {
        double[][] matriz = crearMatriz();
        int total = contarElementos(matriz);
        System.out.println("Número total de elementos (NTE): " + total);
        System.out.println("Dimensiones: 15 filas × 5 columnas");
    }
}

Este ejemplo demuestra cómo representar un arreglo bidimensional de números reales cuyos índices incluyen valores negativos. En Java, no existen índices negativos directamente, por lo que se simulan ajustando los rangos dentro del arreglo real.
