Ejemplo 4.8

Simulación de una matriz con índices negativos en Java

Descripción

Consideremos un arreglo de números reales con índices negativos. La matriz se define como: MATRIZ1 = ARREGLO[-11..3, -17..-13].

El número total de elementos se obtiene mediante: NTE = (3 - (-11) + 1) * (-13 - (-17) + 1) = 15 × 5 = 75.

Código Java

public class Ejemplo4_8 {
    public static double[][] crearMatriz() {
        int filas = (3 - (-11)) + 1;
        int columnas = (-13 - (-17)) + 1;
        double[][] matriz = new double[filas][columnas];
        double valor = 1.0;
        for (int i = 0; i < filas; i++) {
            for (int j = 0; j < columnas; j++) {
                matriz[i][j] = valor++;
            }
        }
        return matriz;
    }
    public static int contarElementos(double[][] matriz) {
        int total = 0;
        for (double[] fila : matriz) total += fila.length;
        return total;
    }
    public static void main(String[] args) {
        double[][] matriz = crearMatriz();
        int total = contarElementos(matriz);
        System.out.println("Número total de elementos (NTE): " + total);
    }
}

Resultado esperado

Número total de elementos (NTE): 75
Dimensiones: 15 filas x 5 columnas
