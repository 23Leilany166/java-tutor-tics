Práctica 1.11

Cálculo del perímetro de un triángulo a partir de sus coordenadas

Descripción

Dadas las coordenadas de tres puntos P1, P2 y P3 que forman los vértices de un triángulo, el programa calcula su perímetro aplicando la fórmula de la distancia entre dos puntos.

Diagrama de flujo

Código Java

double d12 = Math.sqrt(Math.pow(x2 - x1, 2) + Math.pow(y2 - y1, 2));
double d23 = Math.sqrt(Math.pow(x3 - x2, 2) + Math.pow(y3 - y2, 2));
double d31 = Math.sqrt(Math.pow(x3 - x1, 2) + Math.pow(y3 - y1, 2));
double perimetro = d12 + d23 + d31;
System.out.printf("El perímetro del triángulo es: %.2f%n", perimetro);

Ejemplo de ejecución

Entrada:
X1=0, Y1=0
X2=3, Y2=0
X3=0, Y3=4

Salida:
El perímetro del triángulo es: 12.00
