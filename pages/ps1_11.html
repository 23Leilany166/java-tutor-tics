Práctica 1.11

Cálculo del perímetro de un triángulo a partir de sus coordenadas

Descripción

Construya un diagrama de flujo tal que, dadas las coordenadas de los puntos P1, P2 y P3 que corresponden a los vértices de un triángulo, calcule su perímetro.

Datos del problema

X1, Y1, X2, Y2, X3, Y3

Donde:

  • X1 y Y1: variables de tipo real que representan las coordenadas en el eje de las X y las Y del punto P1.
  • X2 y Y2: variables de tipo real que representan las coordenadas en el eje de las X y las Y del punto P2.
  • X3 y Y3: variables de tipo real que representan las coordenadas en el eje de las X y las Y del punto P3.

Consideraciones

Para calcular la distancia entre dos puntos P1 y P2 hacemos:

Fórmula 6.13
D = √((X1 − X2)² + (Y1 − Y2)²)

Diagrama de flujo

Código Java

double d12 = Math.sqrt(Math.pow(x2 - x1, 2) + Math.pow(y2 - y1, 2));
double d23 = Math.sqrt(Math.pow(x3 - x2, 2) + Math.pow(y3 - y2, 2));
double d31 = Math.sqrt(Math.pow(x3 - x1, 2) + Math.pow(y3 - y1, 2));
double perimetro = d12 + d23 + d31;
System.out.printf("El perímetro del triángulo es: %.2f%n", perimetro);

Ejemplo de ejecución

Entrada:
X1=0, Y1=0
X2=3, Y2=0
X3=0, Y3=4

Salida:
El perímetro del triángulo es: 12.00
