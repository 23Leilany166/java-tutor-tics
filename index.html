Inversor de Datos (Scanner)

Un ejercicio básico para practicar la lectura de datos desde la consola utilizando la clase java.util.Scanner y la impresión de esos datos en orden inverso.

Requisitos

  • Crear una clase InversorDatos.
  • TODO el código debe estar dentro del método main.
  • Usar Scanner para leer desde System.in.
  • Solicitar y leer cuatro números enteros (ej. A, B, C, D).
  • Imprimir los números en la consola en el orden inverso (D, C, B, A).

Ejemplo de uso esperado

(Al ejecutar el programa en la consola)

Ingrese 4 enteros, separados por espacio:
7 28 150 35
Datos en orden inverso:
35, 150, 28, 7

Notas rápidas

  • System.in es el flujo de entrada estándar (consola).
  • Scanner es una herramienta poderosa para "parsear" tipos primitivos.
  • Es una buena práctica cerrar el Scanner (scanner.close()) cuando ya no se necesita.
Tip: System.out.printf() permite formatear la salida de manera similar a C, usando especificadores como %d (decimal/entero) y \n (nueva línea).

Calculadora de Aumento de Sueldo (if-else)

Implementar lógica condicional simple usando una estructura if-else para aplicar diferentes tasas de aumento de sueldo basadas en un umbral.

Requisitos

  • Crear una clase CalculadoraAumento.
  • Implementar toda la lógica en el método main usando variables locales y estructuras if-else.
  • Calcular el nuevo sueldo directamente sin métodos auxiliares.
  • Lógica:
    • Si el sueldoActual es inferior a 1000, aplicar un aumento del 15% (multiplicar por 1.15).
    • En caso contrario (si es 1000 o más), aplicar un aumento del 12% (multiplicar por 1.12).

Ejemplo de uso esperado

(Al ejecutar el programa en la consola)

Sueldo 840.50 -> Nuevo Sueldo: 966.58
Sueldo 1200.00 -> Nuevo Sueldo: 1344.00
Sueldo 1000.00 -> Nuevo Sueldo: 1120.00

Notas rápidas

  • Este ejercicio refuerza la estructura condicional básica if (condicion) { ... } else { ... }.
  • Todo el código está en main, sin métodos auxiliares, como se espera para ejercicios básicos.
Tip: Para mayor claridad, puedes definir las tasas de aumento como constantes: final double AUMENTO_MINIMO = 1.15;.

Función Selectiva (switch)

Practicar la estructura de control switch de Java para ejecutar diferentes operaciones matemáticas basadas en un valor selector (int).

Requisitos

  • Crear una clase ProcesadorFunciones.
  • TODO el código debe estar en el método main.

(Al ejecutar el programa en la consola)

Suma de Gastos de Viaje (while y valor centinela)

Implementar un bucle while que lea valores (gastos) desde la consola hasta que el usuario ingrese un "valor centinela" (en este caso, -1) para terminar la entrada y sumar el total.

Requisitos

  • Crear una clase SumadorGastos con un método main.
  • Usar Scanner para leer valores double.
  • Usar una variable double totalGastos = 0; para acumular la suma.
  • Implementar un bucle while que se ejecute mientras el gasto leído sea diferente de -1.
  • Leer el primer gasto *antes* de entrar al bucle.
  • Dentro del bucle: sumar el gasto al total y leer el *siguiente* gasto.
  • Imprimir el totalGastos al finalizar el bucle.

Ejemplo de uso esperado

(Al ejecutar el programa en la consola)

Ingrese el monto del gasto (o -1 para terminar): 100.50
Ingrese el monto del gasto (o -1 para terminar): 50.00
Ingrese el monto del gasto (o -1 para terminar): 75.25
Ingrese el monto del gasto (o -1 para terminar): -1
El total de gastos del viaje es: $225.75

Notas rápidas

  • Este patrón se llama "bucle controlado por centinela".
  • La lectura se hace dos veces: una para "cebar" el bucle y otra al final de cada iteración.

Sueldos Superiores al Promedio (Arreglos)

Practicar el manejo de arreglos (double[]) en dos pasadas. La primera pasada es para calcular el promedio de todos los sueldos, y la segunda es para contar cuántos sueldos superan ese promedio.

Requisitos

  • Crear una clase AnalizadorSueldos.
  • TODO el código debe estar en el método main.
  • Pasada 1 (Calcular Promedio):
    • Iterar sobre el arreglo sueldos (usando un bucle for o for-each).
    • Sumar todos los valores en una variable total.
    • Calcular el promedio = total / sueldos.length.
  • Pasada 2 (Contar):
    • Inicializar int contador = 0.
    • Iterar nuevamente sobre el arreglo sueldos.
    • Si sueldo > promedio, incrementar contador.
  • Imprimir el resultado.

Ejemplo de uso esperado

(Al ejecutar el programa en la consola)

El promedio de sueldos es: 2951.14
Número de sueldos sobre el promedio: 2

Notas rápidas

  • Este problema demuestra por qué los arreglos son esenciales: permiten almacenar datos para procesarlos múltiples veces.
  • El bucle for-each (for (double sueldo : sueldos)) es más limpio que un for con índice cuando no necesitas la posición.

Algoritmo de Ordenación por Selección Directa

Implementar el algoritmo de ordenación por selección. Este método consiste en buscar el elemento mínimo en la porción no ordenada del arreglo y moverlo a la posición correcta (intercambio).

Requisitos

  • Crear una clase Ordenador.
  • TODO el código debe estar en el método main.
  • El algoritmo debe modificar (mutar) el arreglo directamente.
  • Lógica (Selección Directa):
    • Bucle externo i desde 0 hasta vector.length - 2.
    • Asumir que el mínimo está en i (int minIndex = i).
    • Bucle interno j desde i + 1 hasta vector.length - 1.
    • Si vector[j] < vector[minIndex], actualizar minIndex = j.
    • Después del bucle interno, intercambiar vector[i] con vector[minIndex].

Ejemplo de uso esperado

(Al ejecutar el programa en la consola)

Arreglo original: [32, 84, 25, 33, 61, 44, 29, 52]
Arreglo ordenado: [25, 29, 32, 33, 44, 52, 61, 84]

Notas rápidas

  • La ordenación por selección tiene una complejidad temporal de O(n²) en todos los casos (peor, mejor y promedio).
  • Es un algoritmo "in-place", ya que no requiere memoria adicional (aparte de una variable temporal para el intercambio).

Analizador de Triángulos (Validación, Tipo y Área)

Analizar triángulos dados sus tres lados. El programa debe determinar si los lados forman un triángulo válido, qué tipo de triángulo es, y calcular su área.

Requisitos

  • Validación: (a + b > c) && (a + c > b) && (b + c > a).

Insertar y Eliminar en ArrayList

Usar la clase java.util.ArrayList para gestionar una colección de datos desordenada, aprovechando sus métodos nativos .add() y .remove().

Requisitos

  • Crear una clase Almacen.
  • TODO el código debe estar en el método main.
  • Crear un ArrayList<Integer> elementos.
  • Usar .add(e) para insertar elementos.
  • Usar .remove(Integer.valueOf(e)) para eliminar la primera ocurrencia de un valor.
  • Mostrar el estado del ArrayList después de cada operación.

Ejemplo de uso esperado

(Al ejecutar el programa en la consola)

Insertado: 10. Lista actual: [10]
Insertado: 20. Lista actual: [10, 20]
Insertado: 30. Lista actual: [10, 20, 30]
Insertado: 10. Lista actual: [10, 20, 30, 10]
Eliminado: 10. Lista actual: [20, 30, 10]
No se encontró: 99. Lista actual: [20, 30, 10]
Eliminado: 20. Lista actual: [30, 10]
Estado final: [30, 10]

¡Cuidado con .remove()!

ArrayList tiene dos métodos remove:

  • remove(int index): Elimina por posición.
  • remove(Object o): Elimina por valor.

Si tienes un ArrayList<Integer> y llamas a .remove(10), Java lo interpreta como remove(int index) e intentará borrar el elemento en la posición 10, (lanzando IndexOutOfBoundsException si es muy pequeño). Debes forzarlo a usar el método de Objeto con .remove(Integer.valueOf(10)).
