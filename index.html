Inversor de Datos (Scanner)

Un ejercicio básico para practicar la lectura de datos desde la consola utilizando la clase java.util.Scanner y la impresión de esos datos en orden inverso.

Requisitos

  • Crear una clase InversorDatos.
  • Implementar un método main.
  • Dentro de main, crear una instancia de Scanner para leer desde System.in.
  • Solicitar y leer cuatro números enteros (ej. A, B, C, D).
  • Imprimir los números en la consola en el orden inverso (D, C, B, A).

Código Real del Ejercicio

// Archivo: InversorDatos.java
import java.util.Scanner;

public class InversorDatos {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        System.out.println("Ingrese 4 enteros, separados por espacio:");
        int a = scanner.nextInt();
        int b = scanner.nextInt();
        int c = scanner.nextInt();
        int d = scanner.nextInt();
        
        // Imprime en orden inverso
        // Ejemplo de entrada: 7 28 150 35
        // Salida esperada: 35, 150, 28, 7
        System.out.println("Datos en orden inverso:");
        System.out.printf("%d, %d, %d, %d\n", d, c, b, a);
        
        scanner.close();
    }
}

Notas rápidas

  • System.in es el flujo de entrada estándar (consola).
  • Scanner es una herramienta poderosa para "parsear" tipos primitivos.
  • Es una buena práctica cerrar el Scanner (scanner.close()) cuando ya no se necesita.
Tip: System.out.printf() permite formatear la salida de manera similar a C, usando especificadores como %d (decimal/entero) y \n (nueva línea).

Calculadora de Aumento de Sueldo (if-else)

Implementar lógica condicional simple usando una estructura if-else para aplicar diferentes tasas de aumento de sueldo basadas en un umbral.

Requisitos

  • Crear una clase CalculadoraAumento.
  • Implementar toda la lógica en el método main usando variables locales y estructuras if-else.
  • Calcular el nuevo sueldo directamente sin métodos auxiliares.
  • Lógica:
    • Si el sueldoActual es inferior a 1000, aplicar un aumento del 15% (multiplicar por 1.15).
    • En caso contrario (si es 1000 o más), aplicar un aumento del 12% (multiplicar por 1.12).

Ejemplo de uso esperado

public class CalculadoraAumento {
    public static void main(String[] args) {
        // Casos de prueba
        double sueldo1 = 800.0;
        double sueldo2 = 1000.0;
        double sueldo3 = 1200.0;

        // Calcular nuevo sueldo para sueldo1
        double nuevoSueldo1;
        if (sueldo1 < 1000) {
            nuevoSueldo1 = sueldo1 * 1.15;
        } else {
            nuevoSueldo1 = sueldo1 * 1.12;
        }
        System.out.println("Sueldo " + sueldo1 + " -> Nuevo: " + nuevoSueldo1);
        
        // Similar para sueldo2 y sueldo3...
    }
}

Notas rápidas

  • Este ejercicio refuerza la estructura condicional básica if (condicion) { ... } else { ... }.
  • En Java, es preferible encapsular esta lógica en un método en lugar de hacerlo todo en main.
Tip: Para mayor claridad, puedes definir las tasas de aumento como constantes: final double AUMENTO_MINIMO = 1.15;.

Función Selectiva (switch)

Practicar la estructura de control switch de Java para ejecutar diferentes operaciones matemáticas basadas en un valor selector (int).

Requisitos

  • Crear una clase ProcesadorFunciones.
  • Crear un método public double calcularValor(int num, int v).
  • El método debe usar switch sobre el parámetro num:
    • case 1: debe devolver 100 * v.
    • case 2: debe devolver Math.pow(100, v).
    • case 3: debe devolver 100.0 / v (asegurar división de punto flotante).
    • default: (para cualquier otro valor de num) debe devolver 0.0.

Ejemplo de uso esperado

public class ProcesadorFunciones {
    public double calcularValor(int num, int v) {
        switch (num) {
            case 1:
                return 100 * v;
            case 2:
                return Math.pow(100, v);
            case 3:
                return 100.0 / v;
            default:
                return 0.0;
        }
    }
}

// --- En el método main ---
ProcesadorFunciones pf = new ProcesadorFunciones();
System.out.println(pf.calcularValor(1, 8));   // Salida: 800.0
System.out.println(pf.calcularValor(3, 4));   // Salida: 25.0
System.out.println(pf.calcularValor(7, 6));   // Salida: 0.0

Notas rápidas

  • Math.pow(base, exponente) se usa para la exponenciación.
  • Usar 100.0 en lugar de 100 fuerza a que la división sea de tipo double.
  • Cuando un case usa return, no es necesario usar break.

Suma de Gastos de Viaje (while y valor centinela)

Implementar un bucle while que lea valores (gastos) desde la consola hasta que el usuario ingrese un "valor centinela" (en este caso, -1) para terminar la entrada y sumar el total.

Requisitos

  • Crear una clase SumadorGastos con un método main.
  • Usar Scanner para leer valores double.
  • Usar una variable double totalGastos = 0; para acumular la suma.
  • Implementar un bucle while que se ejecute mientras el gasto leído sea diferente de -1.
  • Leer el primer gasto *antes* de entrar al bucle.
  • Dentro del bucle: sumar el gasto al total y leer el *siguiente* gasto.
  • Imprimir el totalGastos al finalizar el bucle.

Ejemplo de uso esperado

import java.util.Scanner;

public class SumadorGastos {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        double totalGastos = 0;

        System.out.print("Ingrese gasto (o -1 para terminar): ");
        double gasto = scanner.nextDouble();

        while (gasto != -1) {
            totalGastos += gasto;
            System.out.print("Ingrese gasto (o -1 para terminar): ");
            gasto = scanner.nextDouble();
        }

        System.out.printf("Total de gastos: %.2f\n", totalGastos);
        scanner.close();
    }
}

Notas rápidas

  • Este patrón se llama "bucle controlado por centinela".
  • La lectura se hace dos veces: una para "cebar" el bucle y otra al final de cada iteración.

Sueldos Superiores al Promedio (Arreglos)

Practicar el manejo de arreglos (double[]) en dos pasadas. La primera pasada es para calcular el promedio de todos los sueldos, y la segunda es para contar cuántos sueldos superan ese promedio.

Requisitos

  • Crear una clase AnalizadorSueldos.
  • Crear un método public int contarSueldosSobrePromedio(double[] sueldos).
  • Pasada 1 (Calcular Promedio):
    • Iterar sobre el arreglo sueldos (usando un bucle for o for-each).
    • Sumar todos los valores en una variable total.
    • Calcular el promedio = total / sueldos.length.
  • Pasada 2 (Contar):
    • Inicializar int contador = 0.
    • Iterar nuevamente sobre el arreglo sueldos.
    • Si sueldo > promedio, incrementar contador.
  • Devolver contador.

Ejemplo de uso esperado

public class AnalizadorSueldos {
    public int contarSueldosSobrePromedio(double[] sueldos) {
        if (sueldos == null || sueldos.length == 0) {
            return 0;
        }
        
        double total = 0;
        for (double sueldo : sueldos) {
            total += sueldo;
        }
        double promedio = total / sueldos.length;
        
        int contador = 0;
        for (double sueldo : sueldos) {
            if (sueldo > promedio) {
                contador++;
            }
        }
        return contador;
    }
}
// --- En main ---
// (Promedio de la tabla 4.1 es 1921.14)
double[] sueldos = {1200.00, 3950.00, 7575.00, 980.00, 1050.70};
AnalizadorSueldos as = new AnalizadorSueldos();
System.out.println(as.contarSueldosSobrePromedio(sueldos)); // Salida: 2

Notas rápidas

  • Este problema demuestra por qué los arreglos (o Colecciones) son esenciales: permiten almacenar datos para procesarlos múltiples veces.
  • El bucle for-each (for (double sueldo : sueldos)) es más limpio que un for con índice cuando no necesitas la posición.

Algoritmo de Ordenación por Selección Directa

Implementar el algoritmo de ordenación por selección. Este método consiste en buscar el elemento mínimo en la porción no ordenada del arreglo y moverlo a la posición correcta (intercambio).

Requisitos

  • Crear una clase utilitaria Ordenador.
  • Crear un método public static void ordenarPorSeleccion(int[] vector).
  • El método debe modificar (mutar) el arreglo recibido.
  • Lógica (Selección Directa):
    • Bucle externo i desde 0 hasta vector.length - 2.
    • Asumir que el mínimo está en i (int minIndex = i).
    • Bucle interno j desde i + 1 hasta vector.length - 1.
    • Si vector[j] < vector[minIndex], actualizar minIndex = j.
    • Después del bucle interno, intercambiar vector[i] con vector[minIndex].

Ejemplo de uso esperado

import java.util.Arrays;

public class Ordenador {
    public static void ordenarPorSeleccion(int[] vector) {
        for (int i = 0; i < vector.length - 1; i++) {
            int minIndex = i;
            for (int j = i + 1; j < vector.length; j++) {
                if (vector[j] < vector[minIndex]) {
                    minIndex = j;
                }
            }
            // Intercambio
            int temp = vector[i];
            vector[i] = vector[minIndex];
            vector[minIndex] = temp;
        }
    }
}
// --- En main ---
int[] data = {32, 84, 25, 33, 61, 44, 29, 52};
Ordenador.ordenarPorSeleccion(data);
System.out.println(Arrays.toString(data)); // [25, 29, 32, 33, 44, 52, 61, 84]

Notas rápidas

  • La ordenación por selección tiene una complejidad temporal de O(n²) en todos los casos (peor, mejor y promedio).
  • Es un algoritmo "in-place", ya que no requiere memoria adicional (aparte de una variable temporal para el intercambio).

Reporte INAH (Arreglos Tridimensionales)

Practicar el manejo de arreglos de 3 dimensiones (int[][][]) para procesar datos de visitantes (Centro Arqueológico, Mes, Año) y generar reportes.

Requisitos

  • Crear una clase ReporteINAH que almacene los datos en int[][][] visitantes.
  • La dimensión debe ser [58][12][10] (Centro, Mes, Año).
  • Inciso a: Método getAnoMayorAfluencia(int centro).
    • Debe sumar los 12 meses para cada uno de los 10 años, solo para el centro dado.
    • Devolver el año (1990-1999) con la suma máxima.
  • Inciso b: Método getCentroMayorAfluencia(int ano).
    • Sumar los 12 meses para cada uno de los 58 centros, solo para el ano dado.

  • Inciso c: Método getMesMayorAfluencia(int ano).
    • Sumar los 58 centros para cada uno de los 12 meses, solo para el ano dado.
    • Devolver el índice del mes (0-11) con la suma máxima.

Ejemplo de uso esperado

public class ReporteINAH {

    public ReporteINAH(int[][][] datos) {
        this.visitantes = datos;

            if (sumaAnual > maxVisitas) {
                maxVisitas = sumaAnual;
                anoMax = 1990 + a;
            }
        }
        return anoMax;
    }
    // ... (Implementación similar para b y c) ...
}

Notas rápidas

  • El manejo de índices es crucial. Si el libro usa claves de 1-58, en Java serán índices 0-57.
  • Los años 1990-1999 se mapean a índices 0-9.
  • Usar long para las sumas es una buena práctica para evitar desbordamiento (overflow) de enteros.

Conversor de Acres a Hectáreas (Métodos Estáticos)

Crear una clase utilitaria (utility class) con métodos static para realizar conversiones de unidades, específicamente de acres a hectáreas, usando las constantes de conversión dadas.

Requisitos

  • Crear una clase ConversorUnidades.
  • Declarar constantes estáticas y finales:
    • private static final double METROS_CUADRADOS_POR_ACRE = 4047.0;
    • private static final double METROS_CUADRADOS_POR_HECTAREA = 10000.0;
  • Crear un método public static double acresAhectareas(double acres).
  • Lógica: (acres * METROS_CUADRADOS_POR_ACRE) / METROS_CUADRADOS_POR_HECTAREA.
  • Añadir un constructor privado private ConversorUnidades() {} para prevenir la instanciación.

Ejemplo de uso esperado

public class ConversorUnidades {

    private static final double METROS_CUADRADOS_POR_ACRE = 4047.0;
    private static final double METROS_CUADRADOS_POR_HECTAREA = 10000.0;

    // Constructor privado para evitar instanciación
    private ConversorUnidades() {}

    public static double acresAhectareas(double acres) {
        double metrosCuadrados = acres * METROS_CUADRADOS_POR_ACRE;
        return metrosCuadrados / METROS_CUADRADOS_POR_HECTAREA;
    }
}

// --- En main ---
double acres = 100.0;
double hectareas = ConversorUnidades.acresAhectareas(acres);
System.out.printf("%.2f acres son %.2f hectáreas\n", acres, hectareas);
// Salida: 100.00 acres son 40.47 hectáreas

Notas rápidas

  • Las "Clases Utilitarias" agrupan funcionalidad relacionada pero no guardan estado (atributos no estáticos).
  • static significa que el método pertenece a la clase, no a una instancia.

Clase Triángulo (Validación, Tipo y Área)

Implementar una clase Triangulo que almacene sus tres lados. La clase debe ser capaz de determinar si los lados forman un triángulo válido, qué tipo de triángulo es, y calcular su área.

Requisitos

  • Clase Triangulo con atributos double a, double b, double c.
  • Método public boolean esValido().
    • Lógica: (a + b > c) && (a + c > b) && (b + c > a).
  • Método public String getTipo().
    • Si no es válido, devolver "Invalido".
    • Si a == b && b == c, devolver "Equilatero".
    • Si a == b || b == c || a == c, devolver "Isosceles".
    • En otro caso, devolver "Escaleno".
  • Método public double getArea() (Fórmula de Herón).
    • Si no es válido, devolver 0.
    • Calcular s = (a + b + c) / 2.0.
    • Devolver Math.sqrt(s * (s - a) * (s - b) * (s - c)).

Ejemplo de uso esperado

public class Triangulo {
    // ... (atributos y constructor) ...
    
    public boolean esValido() {
        return (a + b > c) && (a + c > b) && (b + c > a);
    }
    
    public String getTipo() {
        if (!esValido()) return "Invalido";
        if (a == b && b == c) return "Equilatero";
        if (a == b || b == c || a == c) return "Isosceles";
        return "Escaleno";
    }
    
    public double getArea() {
        if (!esValido()) return 0.0;
        double s = (a + b + c) / 2.0;
        return Math.sqrt(s * (s - a) * (s - b) * (s - c));
    }
}
// --- En main ---
Triangulo t1 = new Triangulo(5, 5, 5);
System.out.println(t1.getTipo()); // Equilatero
System.out.printf("%.2f\n", t1.getArea()); // 10.83

Notas rápidas

  • La validación (esValido()) es crucial y debe ser llamada por los otros métodos (getTipo, getArea) para evitar resultados incorrectos.
  • La Fórmula de Herón calcula el área de un triángulo conociendo sus tres lados.

Insertar y Eliminar en Arreglo (ArrayList)

Usar la clase java.util.ArrayList para gestionar una colección de datos desordenada, aprovechando sus métodos nativos .add() y .remove().

Requisitos

  • Crear una clase Almacen que encapsule ArrayList elementos.
  • El constructor debe inicializar la lista: elementos = new ArrayList<>();.
  • Método public void insertar(int e).
    • Simplemente debe usar elementos.add(e).
  • Método public boolean eliminar(int e).
    • Debe eliminar la *primera* ocurrencia del valor e.
    • Debe devolver true si lo encontró y eliminó, false en caso contrario.
    • Usar elementos.remove(Integer.valueOf(e)).

Ejemplo de uso esperado

import java.util.ArrayList;
import java.util.List;

public class Almacen {
    private List elementos;

    public Almacen() {
        this.elementos = new ArrayList<>();
    }

    public void insertar(int e) {
        this.elementos.add(e);
    }

    public boolean eliminar(int e) {
        // Debe usar Integer.valueOf() para forzar la eliminación por Objeto,
        // no por índice.
        return this.elementos.remove(Integer.valueOf(e));
    }
}
// --- En main ---
Almacen a = new Almacen();
a.insertar(10);
a.insertar(20);
a.insertar(10);
a.eliminar(10); // Elimina solo el primer 10
System.out.println(a.getElementos()); // [20, 10]

¡Cuidado con .remove()!

ArrayList tiene dos métodos remove:

  • remove(int index): Elimina por posición.
  • remove(Object o): Elimina por valor.

Si tienes un ArrayList y llamas a .remove(10), Java lo interpreta como remove(int index) e intentará borrar el elemento en la posición 10, (lanzando IndexOutOfBoundsException si es muy pequeño). Debes forzarlo a usar el método de Objeto con .remove(Integer.valueOf(10)).

public class Fabrica {

        this.costos = costos;

    public double[] getCostoAnualPorProducto() {
        double[] costoAnual = new double[10];

            double cantidadTotal = 0;
            for (int i = 0; i < 12; i++) { // Iterar por mes
                cantidadTotal += this.produccion[i][j];
            }
            costoAnual[j] = cantidadTotal * this.costos[j];
        }
        return costoAnual;
    }
    
    // ... (otros métodos) ...
}

Notas rápidas

  • El orden de los bucles importa. Para el inciso 'a' (costo por producto), el bucle externo debe iterar sobre los productos (columnas) y el interno sobre los meses (filas).

Gestión de Personal (Clases y Búsqueda)

Modelar un sistema de RRHH usando clases Empleado y Departamento. Este ejercicio reemplaza los "arreglos paralelos" del libro con una estructura orientada a objetos, donde los datos relacionados se agrupan en clases.

Requisitos

        Departamento dep = null;
        for(Departamento d : departamentos) {
            if(d.getClaveDept() == emp.getClaveDept()) {
                dep = d;
                break;
            }
        }
        
        System.out.println("Sueldo: " + emp.getSueldo());
        System.out.println("Depto: " + (dep != null ? dep.getNomDept() : "N/A"));
        System.out.println("Jefe: " + (dep != null ? dep.getNomJefe() : "N/A"));
    }
}

Notas rápidas

  • Este ejercicio es una transición clave de la programación estructurada (arreglos paralelos) a la OOP (objetos que contienen sus propios datos).
  • Las listas (ArrayList) están ordenadas, lo que permite usar Búsqueda Binaria (Collections.binarySearch) si se implementa la interfaz Comparable.
  • Para búsquedas más rápidas por clave, se usaría un HashMap.
