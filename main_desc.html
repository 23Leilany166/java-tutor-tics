Variables y Asignación (Ejemplo 1.5)

Practicar la declaración, asignación y seguimiento de variables de diferentes tipos primitivos y objetos simples en Java, observando cómo cambian sus valores y manejando posibles errores de tipo.

Requisitos

  • Declarar variables de tipo `int`, `double`, `char`, y `boolean`.
  • Realizar una secuencia de asignaciones como las descritas en el ejemplo 1.5.
  • Utilizar operaciones aritméticas (`+`, `*`, `/`, `%` - módulo en Java, `Math.pow()`) y lógicas (`&&`, `||`, `!`, `>`, `<`, `==`, `!=`).
  • Simular el seguimiento de los valores de las variables (como en la Tabla 1.8), imprimiendo sus valores después de ciertas asignaciones.
  • Identificar y comentar las asignaciones que causarían errores de compilación en Java debido a incompatibilidad de tipos (p. ej., asignar `double` a `int` sin casting explícito).

Ejemplo de uso esperado

public class SeguimientoVariables {
    public static void main(String[] args) {
        int i = 0, acum = 0, j = 0; // int para enteros
        double rea = 0.0, sum = 0.0; // double para reales
        char car = ' '; // char para caracter
        boolean band = false; // boolean para lógico

        // 1. i = 0 (ya inicializado)
        System.out.println("Paso 1: i = " + i);

        // 2. i = i + 1
        i = i + 1;
        System.out.println("Paso 2: i = " + i);

        // 3. acum = 0 (ya inicializado)
        System.out.println("Paso 3: acum = " + acum);

        // 4. j = 5^2 / 3 (División entera en Java para int)
        j = (int) Math.pow(5, 2) / 3; // O j = (5 * 5) / 3;
        System.out.println("Paso 4: j = " + j);

        // 5. car = 'a'
        car = 'a';
        System.out.println("Paso 5: car = " + car);

        // 6. acum = j / i
        if (i != 0) { // Evitar división por cero
             acum = j / i; // División entera
             System.out.println("Paso 6: acum = " + acum);
        } else {
             System.out.println("Paso 6: Error - División por cero.");
        }

        // ... continuar con las demás asignaciones ...

        // 13. i = rea; // Error de tipo: double no puede asignarse a int sin cast
        System.out.println("Paso 13: Causa error de compilación (asignar double a int).");
        // Para que funcione: i = (int) rea;

        // 14. car = j; // Error de tipo: int no puede asignarse a char sin cast
        System.out.println("Paso 14: Causa error de compilación (asignar int a char).");
        // Para que funcione: car = (char) j; (aunque el resultado numérico puede no ser un caracter imprimible esperado)
    }
}

Notas rápidas

  • Java es fuertemente tipado. Presta atención a las conversiones entre `int`, `double`, `char`.
  • La división `/` entre enteros (`int`) en Java produce un resultado entero (truncado).
  • Usa `Math.pow(base, exponente)` para la potencia, devuelve `double`.
  • El operador `^` en Java es XOR bit a bit, no potencia.
  • Comenta las líneas que generan error de compilación o usa casting explícito `(tipoDeseado)valor`.

Invertir Orden de Datos (Problema 1.6)

Leer cuatro números enteros e imprimirlos en orden inverso. Este ejercicio introduce la lectura de datos del usuario y la impresión formateada en Java.

Requisitos

  • Crear una clase Java con un método `main`.
  • Utilizar la clase `java.util.Scanner` para leer cuatro enteros (`int`) del usuario.
  • Almacenar los enteros en cuatro variables distintas (p. ej., `a`, `b`, `c`, `d`).
  • Imprimir los valores de las variables en orden inverso (d, c, b, a) usando `System.out.println` o `System.out.printf`.

Ejemplo de uso esperado

import java.util.Scanner;

public class InvertirDatos {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.println("Ingrese cuatro números enteros:");
        int a = scanner.nextInt(); // Leer A
        int b = scanner.nextInt(); // Leer B
        int c = scanner.nextInt(); // Leer C
        int d = scanner.nextInt(); // Leer D

        System.out.println("Los números en orden inverso son:");
        System.out.println(d); // Escribir D
        System.out.println(c); // Escribir C
        System.out.println(b); // Escribir B
        System.out.println(a); // Escribir A

        // Opcional: imprimir en una sola línea
        // System.out.printf("%d, %d, %d, %d%n", d, c, b, a);

        scanner.close();
    }
}
// Si la entrada es: 7 28 150 35
// La salida será:
// 35
// 150
// 28
// 7

Notas rápidas

  • Recuerda importar `java.util.Scanner`.
  • Cierra el `Scanner` al finalizar para liberar recursos (`scanner.close()`).
  • `System.out.println` imprime y añade un salto de línea.
  • `System.out.printf` permite formatear la salida. `%d` es para enteros, `%n` para un salto de línea independiente del sistema operativo.

Temperatura según Sonidos de Grillo (Problema 2.1)

Calcular la temperatura en grados Fahrenheit basada en el número de sonidos de un grillo por minuto, utilizando una fórmula dada. Practicar el uso de estructuras condicionales `if` en Java para validar la entrada.

Requisitos

  • Leer un número entero `N` que representa los sonidos por minuto.
  • Verificar si `N` es mayor que 0 usando una estructura `if`.
  • Si `N > 0`, calcular la temperatura `T` usando la fórmula `T = N / 4.0 + 40`. (Usar `4.0` para asegurar división de punto flotante).
  • Imprimir la temperatura calculada `T`.
  • Si `N` no es mayor que 0, el programa puede optar por no imprimir nada o mostrar un mensaje indicando que la entrada no es válida.

Ejemplo de uso esperado

import java.util.Scanner;

public class TemperaturaGrillo {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Ingrese el número de sonidos por minuto: ");
        int n = scanner.nextInt(); // Leer N

        if (n > 0) { // Evaluar si N > 0
            double t = n / 4.0 + 40; // Calcular T
            System.out.printf("Temperatura: %.2f°F%n", t); // Imprimir T
        } else {
            System.out.println("El número de sonidos debe ser positivo."); // Caso N <= 0
        }

        scanner.close();
    }
}
// Si la entrada es: 8
// La salida será: Temperatura: 42.00°F
// Si la entrada es: -5
// La salida será: El número de sonidos debe ser positivo.

Notas rápidas

  • La estructura `if` simple ejecuta un bloque de código solo si la condición es verdadera.
  • Usa `double` para la variable `t` ya que el resultado de la división puede tener decimales.
  • Dividir por `4.0` (un `double`) fuerza que la división sea de punto flotante, incluso si `n` es `int`.
  • `%.2f` en `printf` formatea un número de punto flotante con 2 decimales.

Suma de Elementos de un Array (Problema 4.1)

Leer un arreglo unidimensional de números reales y calcular la suma de todos sus elementos. Practicar la declaración, inicialización, llenado y recorrido de arrays en Java.

Requisitos

  • Definir el tamaño del arreglo (p. ej., N=100 según el problema, o leer N del usuario).
  • Declarar un arreglo de `double` (para números reales) del tamaño definido (p. ej., `double[] vec = new double[N];`).
  • Usar un bucle `for` para leer N valores `double` del usuario y almacenarlos en el arreglo `vec`.
  • Inicializar una variable `suma` (de tipo `double`) a 0.0.
  • Usar otro bucle `for` (o un bucle `for-each`) para recorrer el arreglo.
  • En cada iteración del segundo bucle, sumar el elemento actual del arreglo a la variable `suma`.
  • Después del segundo bucle, imprimir el valor final de `suma`.

Ejemplo de uso esperado

import java.util.Scanner;
import java.util.Arrays; // Para imprimir el array fácilmente (opcional)

public class SumaArray {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        // Usaremos un tamaño más pequeño para el ejemplo
        final int N = 5; // Tamaño del arreglo
        double[] vec = new double[N]; // Declarar arreglo de double
        double suma = 0.0; // Acumulador

        System.out.println("Ingrese " + N + " números reales:");
        // Ciclo para leer y llenar el arreglo
        for (int i = 0; i < vec.length; i++) {
            System.out.print("Elemento " + (i + 1) + ": ");
            vec[i] = scanner.nextDouble();
        }

        // Ciclo para sumar los elementos
        for (int i = 0; i < vec.length; i++) {
            suma += vec[i]; // Acumular
        }

        // Alternativa con for-each:
        // for (double elemento : vec) {
        //     suma += elemento;
        // }

        System.out.println("Arreglo ingresado: " + Arrays.toString(vec)); // Opcional
        System.out.printf("La suma de los elementos es: %.2f%n", suma); // Imprimir suma

        scanner.close();
    }
}
// Si la entrada es: 1.5 2.0 3.5 4.0 5.5
// La salida será: La suma de los elementos es: 16.50

Notas rápidas

  • Los índices de los arrays en Java van de `0` a `N-1`, donde `N` es el tamaño.
  • `vec.length` devuelve el tamaño del arreglo `vec`.
  • Un bucle `for-each` (`for (tipo elemento : coleccion)`) es una forma concisa de iterar sobre los elementos de un array o colección sin usar índices.
  • La clase `java.util.Arrays` ofrece métodos útiles para trabajar con arrays, como `toString()` para obtener una representación textual.

Almacenar Años Bisiestos y Perfectos (Prob 4.14)

Generar y almacenar en un array todos los años que sean simultáneamente bisiestos y perfectos dentro del rango [1, 2020]. Practicar lógica condicional compleja, bucles anidados y manejo dinámico de arrays (usando `ArrayList`).

Requisitos

  • Usar un `ArrayList` para almacenar los años encontrados, ya que no se sabe cuántos serán.
  • Iterar con un bucle `for` desde el año 1 hasta el 2020.
  • Dentro del bucle, para cada año:
    • **Verificar si es bisiesto:** Un año es bisiesto si es divisible por 4, excepto si es divisible por 100 a menos que también sea divisible por 400. Usar operadores módulo (`%`) y lógicos (`&&`, `||`, `!`). (`(año % 4 == 0 && año % 100 != 0) || (año % 400 == 0)`).
    • **Verificar si es perfecto:** Un número es perfecto si la suma de sus divisores propios (incluyendo 1 pero no el número mismo) es igual al número. Calcular la suma de los divisores usando un bucle anidado (desde 1 hasta `año / 2`) y el operador módulo (`%`). (`sumaDivisores == año`).
    • Si el año cumple **ambas** condiciones (bisiesto Y perfecto), agregarlo al `ArrayList`.
  • Después del bucle principal, imprimir el contenido del `ArrayList`.

Ejemplo de uso esperado

import java.util.ArrayList;
import java.util.List;

public class BisiestosPerfectos {

    // Función para verificar si un año es bisiesto
    public static boolean esBisiesto(int anio) { //
        return (anio % 4 == 0 && anio % 100 != 0) || (anio % 400 == 0);
    }

    // Función para verificar si un número es perfecto
    public static boolean esPerfecto(int numero) { //
        if (numero <= 1) return false;
        int sumaDivisores = 1; // 1 siempre es divisor
        for (int i = 2; i <= numero / 2; i++) {
            if (numero % i == 0) {
                sumaDivisores += i;
            }
        }
        return sumaDivisores == numero;
    }

    public static void main(String[] args) {
        List bisiestosPerfectos = new ArrayList<>(); // Usar ArrayList
        int limiteSuperior = 2020;

        for (int anio = 1; anio <= limiteSuperior; anio++) {
            if (esBisiesto(anio) && esPerfecto(anio)) { // Verificar ambas condiciones
                bisiestosPerfectos.add(anio); // Agregar al ArrayList
            }
        }

        System.out.println("Años bisiestos y perfectos entre 1 y " + limiteSuperior + ":");
        if (bisiestosPerfectos.isEmpty()) {
            System.out.println("No se encontraron años que cumplan ambas condiciones.");
        } else {
            System.out.println(bisiestosPerfectos); // Imprimir lista
        }
    }
}
// Salida esperada (Nota: No existen números perfectos conocidos que sean bisiestos en ese rango):
// Años bisiestos y perfectos entre 1 y 2020:
// No se encontraron años que cumplan ambas condiciones.

Notas rápidas

  • Los números perfectos conocidos son 6, 28, 496, 8128.... Ninguno de estos coincide con años bisiestos comunes.
  • Es buena práctica crear funciones separadas para `esBisiesto` y `esPerfecto` para mayor claridad.
  • Un `ArrayList` es más flexible que un array (`int[]`) cuando no se conoce el tamaño final.
  • Para la condición de número perfecto, basta comprobar divisores hasta `numero / 2`.
Tip: Prueba el código con un rango más pequeño y conocido (ej. hasta 30) para verificar la lógica de `esPerfecto` (debería encontrar 6 y 28). Verifica `esBisiesto` con años conocidos (ej. 2000, 2024 son bisiestos; 1900 no lo es).

Análisis Ventas Empleados (Problema 5.2)

Manejar información de empleados (número, nombre, ventas mensuales, salario) almacenada en un array de objetos. Realizar consultas como encontrar al empleado con mayores ventas anuales, incrementar salarios basados en ventas, y listar empleados con ventas bajas en un mes específico. Practicar la creación de clases, arrays de objetos, y algoritmos de búsqueda y actualización sobre estructuras complejas.

Requisitos

  • Crear una clase `Empleado` con atributos: `numero` (int), `nombre` (String), `ventas` (array de `double` de tamaño 12), `salario` (double).
  • Crear un constructor para la clase `Empleado` que inicialice estos atributos.
  • Crear un array de objetos `Empleado` (`Empleado[] empleados = new Empleado[N];`).
  • Leer los datos de N empleados (hasta 100) y llenar el array.
  • Implementar la lógica para:
    • **a) Mayor venta anual:** Iterar sobre los empleados. Para cada uno, sumar las ventas de los 12 meses. Mantener un registro del empleado con la suma máxima encontrada hasta el momento. Imprimir el número y nombre de ese empleado.
    • **b) Incremento salarial:** Iterar sobre los empleados. Para cada uno, sumar las ventas anuales. Si la suma es > 1,000,000, actualizar su salario multiplicándolo por 1.10 (`empleado.salario *= 1.10;`).
    • **c) Ventas bajas en diciembre:** Iterar sobre los empleados. Si `empleado.ventas[11]` (índice 11 para diciembre) es < 30,000, imprimir el número y nombre del empleado.
  • Opcional: Implementar un menú para que el usuario elija qué operación realizar, similar al diagrama de flujo.

Ejemplo de uso esperado

import java.util.Scanner;
import java.util.Arrays;

// Definición de la clase Empleado
class Empleado { //
    int numero; //
    String nombre; //
    double[] ventas = new double[12]; //
    double salario; //

    // Constructor
    public Empleado(int numero, String nombre, double salario) {
        this.numero = numero;
        this.nombre = nombre;
        this.salario = salario;
    }

    // Método para calcular ventas anuales
    public double getTotalVentasAnuales() {
        double suma = 0;
        for (double ventaMes : ventas) {
            suma += ventaMes;
        }
        return suma;
    }

    // Método toString para fácil impresión (opcional)
    @Override
    public String toString() {
        return "Empleado [Numero=" + numero + ", Nombre=" + nombre + ", Salario=" + salario +
               ", Ventas=" + Arrays.toString(ventas) + "]";
    }
}

public class GestionEmpleadosTienda {
    static Scanner scanner = new Scanner(System.in);
    static int N = 0; // Número real de empleados
    static Empleado[] empleados; // Array de empleados

    public static void main(String[] args) {
        // --- 1. Leer datos iniciales ---
        leerDatosIniciales();

        // --- 2. Menú de opciones (similar al Diagrama 5.2) ---
        int opcion;
        do {
            mostrarMenu();
            opcion = scanner.nextInt();
            scanner.nextLine(); // Consumir newline

            switch (opcion) {
                case 1: // a) Mayor venta anual
                    encontrarMayorVentaAnual();
                    break;
                case 2: // b) Incrementar salario
                    incrementarSalarios();
                    System.out.println("Salarios actualizados (si aplica).");
                    break;
                case 3: // c) Ventas bajas en diciembre
                    listarVentasBajasDiciembre();
                    break;
                case 4:
                    System.out.println("Terminando programa.");
                    break;
                default:
                    System.out.println("Opción inválida.");
            }
        } while (opcion != 4);

        scanner.close();
    }

    // --- Métodos auxiliares ---
    static void leerDatosIniciales() {
      // Implementación para leer N y los datos de cada empleado, llenando el array 'empleados'

       if (N < 1 || N > 100) {

           System.exit(1); // Salir si el dato es incorrecto
       }

          System.out.println("Datos Empleado " + (i + 1));
          System.out.print("Numero: "); int num = scanner.nextInt();

    static void mostrarMenu() {

        System.out.println("1. Empleado con mayor venta anual");
        System.out.println("2. Incrementar salario por ventas altas");

             double ventasAnuales = empleados[i].getTotalVentasAnuales();
             if (ventasAnuales > 1000000) {
                 empleados[i].salario *= 1.10;
                 // Opcional: imprimir qué empleado recibió aumento
                 // System.out.println("Salario incrementado para: " + empleados[i].nombre);
             }
         }
    }

    static void listarVentasBajasDiciembre() { // Inciso c
        System.out.println("Empleados con ventas < $30,000 en Diciembre:");
        boolean encontrados = false;

                System.out.println("Número: " + empleados[i].numero + ", Nombre: " + empleados[i].nombre);
                encontrados = true;
            }
        }
        if (!encontrados) {
            System.out.println("Ningún empleado cumple el criterio.");
        }
    }
}

Notas rápidas

Calcular Tangente (PS 2.1)

Calcular la tangente de un ángulo dado su seno y coseno, asegurándose de que el coseno no sea cero para evitar la división por cero. Practicar operaciones matemáticas básicas y validación de entradas con `if`.

Requisitos

  • Leer dos valores `double`: `seno` y `coseno`.
  • Verificar si `coseno` es diferente de cero usando `if (coseno != 0)`.
  • Si `coseno` no es cero, calcular `tangente = seno / coseno`.
  • Imprimir el valor de `tangente`.
  • Si `coseno` es cero, imprimir un mensaje indicando que la tangente es indefinida (o un error apropiado).

Ejemplo de uso esperado

import java.util.Scanner;

public class CalcularTangente {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Ingrese el valor del seno: ");
        double seno = scanner.nextDouble(); //
        System.out.print("Ingrese el valor del coseno: ");
        double coseno = scanner.nextDouble(); //

        if (coseno != 0) { //
            double tangente = seno / coseno; //
            System.out.printf("La tangente es: %.4f%n", tangente);
        } else {
            System.out.println("La tangente es indefinida (coseno es cero)."); //
        }

        scanner.close();
    }
}
// Si la entrada es: seno=0.866, coseno=0.5
// La salida será: La tangente es: 1.7320
// Si la entrada es: seno=1.0, coseno=0.0
// La salida será: La tangente es indefinida (coseno es cero).

Notas rápidas

  • La división por cero en punto flotante (`double` o `float`) en Java no lanza una excepción, sino que resulta en `Infinity`, `-Infinity` o `NaN` (Not a Number). Sin embargo, es buena práctica verificar explícitamente para dar un mensaje más claro al usuario.
  • Usa `double` para todas las variables trigonométricas.

public class PromedioAlumnosAnidado {

        final int NUM_CALIFICACIONES = 5; //

        System.out.println("Ingrese los datos de los " + NUM_ALUMNOS + " alumnos:");

Notas rápidas

  • Los arrays paralelos mantienen información relacionada en el mismo índice en arrays diferentes.
  • `Arrays.binarySearch(array, fromIndex, toIndex, key)` busca `key` en el rango especificado. Devuelve el índice si lo encuentra, o `-(punto de inserción) - 1` si no lo encuentra.
  • La inserción en un array ordenado requiere desplazar los elementos posteriores para mantener el orden. Es más eficiente hacerlo desde el final hacia la posición de inserción.
  • Usar `ArrayList` (donde `Contacto` es una clase con nombre y teléfono) suele ser más idiomático en Java que arrays paralelos, pero el ejercicio pide simular la estructura del problema original.
