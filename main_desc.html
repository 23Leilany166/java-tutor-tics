Ejemplo 1.6

Escribir números en orden inverso

Este programa lee cuatro números enteros (A, B, C y D) y los escribe en la consola en orden inverso (D, C, B, A).

Requisitos

  • Leer cuatro variables de tipo entero: A, B, C, y D.
  • Usar la clase Scanner para la entrada de datos.
  • Imprimir los valores en la consola en el orden: D, C, B, A.

Diagrama de Flujo

Este diagrama ilustra el flujo secuencial simple del programa.

Ejemplo de uso esperado

import java.util.Scanner;

public class Ejemplo_1_6 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.println("--- Lectura de 4 números enteros ---");
        
        System.out.print("Ingrese el valor A: ");
        int A = sc.nextInt();
        
        System.out.print("Ingrese el valor B: ");
        int B = sc.nextInt();
        
        System.out.print("Ingrese el valor C: ");
        int C = sc.nextInt();
        
        System.out.print("Ingrese el valor D: ");
        int D = sc.nextInt();

        System.out.println("\n--- Números en orden inverso ---");
        System.out.println("Valor D: " + D);
        System.out.println("Valor C: " + C);
        System.out.println("Valor B: " + B);
        System.out.println("Valor A: " + A);
    }
}

Notas de Diagrama de Flujo

Este problema introduce los símbolos básicos del diagrama de flujo:

  • Inicio / Fin: Se usa un óvalo o cápsula.
  • Lectura (Entrada): Se usa un paralelogramo (para leer A, B, C, D).
  • Escritura (Salida): Se usa un símbolo de documento (para escribir D, C, B, A).
Tip: Este es un algoritmo puramente secuencial. No requiere decisiones (if) ni bucles (while/for).
Problema 1.7

Calcular el área de un triángulo (Fórmula de Herón)

Este programa calcula el área de un triángulo dados sus tres lados (L1, L2, L3), aplicando la fórmula de Herón. El código incluye un main para uso interactivo y un método static (calcularAreaHeron) que contiene la lógica pura.

Fórmulas a utilizar

  1. Calcular el semiperímetro (S):
    S = (L1 + L2 + L3) / 2
  2. Calcular el Área:
    Area = √(S * (S - L1) * (S - L2) * (S - L3))

Diagrama de Flujo

Este diagrama ilustra el flujo secuencial del cálculo.

Código Fuente

import java.util.Locale;
import java.util.Scanner;
import java.lang.Math; // Para usar Math.sqrt()

public class Problema_1_7 {

    /**
     * El método main maneja la interacción con el usuario.
     */
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in).useLocale(Locale.US);

        System.out.println("--- Calculadora de Área de Triángulo (Fórmula de Herón) ---");
        
        System.out.print("Ingrese la longitud del Lado 1 (L1): ");
        double L1 = sc.nextDouble();
        
        System.out.print("Ingrese la longitud del Lado 2 (L2): ");
        double L2 = sc.nextDouble();
        
        System.out.print("Ingrese la longitud del Lado 3 (L3): ");
        double L3 = sc.nextDouble();
        
        sc.close();

        // Llama al método de lógica
        double AREA = calcularAreaHeron(L1, L2, L3);

        if (AREA == -1.0) {
            System.out.println("\nError: Los lados ingresados no forman un triángulo válido.");
        } else {
            // Calcular S solo para mostrarlo (la lógica ya lo hizo)
            double S = (L1 + L2 + L3) / 2.0;
            System.out.println("\n--- Resultados ---");
            System.out.printf("Lados: L1=%.2f, L2=%.2f, L3=%.2f%n", L1, L2, L3);
            System.out.printf("Semiperímetro (S): %.4f%n", S);
            System.out.printf("Área del triángulo: %.4f%n", AREA);
        }
    }

    
    /**
     * Calcula el área usando la fórmula de Herón.
     * Esta es la lógica que se prueba.
     * @return El área, o -1.0 si los lados son inválidos.
     */
    public static double calcularAreaHeron(double L1, double L2, double L3) {
        double S = (L1 + L2 + L3) / 2.0;
        double radicando = S * (S - L1) * (S - L2) * (S - L3);
        
        if (radicando < 0) {
            return -1.0; // Usamos -1.0 como señal de error (triángulo inválido)
        } else {
            return Math.sqrt(radicando); // Regresamos el área
        }
    }
}

Notas rápidas

Puntos clave:

  • Separación de Lógica: El main se encarga de E/S. El método calcularAreaHeron se encarga del cálculo.
  • Los datos L1, L2, L3 deben ser de tipo double.
  • Se utiliza Math.sqrt(valor) para la raíz cuadrada.
  • Manejo de Errores: El método calcularAreaHeron devuelve -1.0 para indicar un error (triángulo inválido), y el main se encarga de interpretar ese valor y mostrar un mensaje amigable.
Tip: Un triángulo es válido solo si la suma de dos de sus lados es siempre mayor que el tercero. Si no, el "radicando" (lo de adentro de la raíz) será negativo. Devolver -1.0 es una forma simple de manejar este error sin "crashing".
Problema 2.2

Evaluar la expresión P³ + Q⁴ - 2*P² < 680

Este programa solicita dos valores enteros, P y Q, y determina si satisfacen la expresión P³ + Q⁴ - 2*P² < 680. Si la cumplen, imprime los valores de P y Q.

Requisitos

  • Usar la clase Scanner para leer los enteros P y Q.
  • Calcular el resultado de la expresión: P³ + Q⁴ - 2*P².
  • Usar una estructura condicional if para verificar si el resultado es menor que 680.
  • Si la condición se cumple, imprimir un mensaje afirmativo junto con los valores de P y Q.
  • Si no se cumple, indicar que no se satisface.

Ejemplo de uso esperado

import java.util.Scanner;
import java.lang.Math; // Para usar Math.pow

public class Problema_2_2 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        
        System.out.println("Ingrese el valor entero P:");
        int P = sc.nextInt();
        
        System.out.println("Ingrese el valor entero Q:");
        int Q = sc.nextInt();
        
        // Calcular la expresión. Usamos double porque Math.pow retorna double.
        double resultado = Math.pow(P, 3) + Math.pow(Q, 4) - 2 * Math.pow(P, 2);
        
        System.out.println("Resultado de la expresión: " + resultado);

        // Evaluar la condición
        if (resultado < 680) {
            System.out.println("La expresión P³ + Q⁴ - 2*P² < 680 SÍ se cumple.");
            System.out.println("Valor de P: " + P);
            System.out.println("Valor de Q: " + Q);
        } else {
            System.out.println("La expresión P³ + Q⁴ - 2*P² < 680 NO se cumple.");
        }
    }
}

Notas rápidas

Asegúrate de:

  • Importar java.util.Scanner para la entrada de datos.
  • Usar Math.pow(base, exponente) para calcular las potencias.
  • Almacenar el resultado en una variable double, ya que Math.pow devuelve ese tipo.
  • Probar con valores que cumplan (ej. P=5, Q=3) y que no cumplan (ej. P=10, Q=10).
Tip: El problema pide imprimir P y Q solo "en caso afirmativo", por lo que el bloque else es opcional, pero útil para la depuración.
Ejemplo 3.4

Programa para obtener el total de gastos de un viaje

Este programa calcula el total de gastos de un viaje. Se compone de dos partes: 1. Un método main que permite al usuario ingresar gastos interactivamente usando Scanner (finalizando con -1). 2. Un método calcularTotalGastos que toma un ArrayList<Double> y retorna la suma. Esta separación permite probar la lógica del cálculo automáticamente.

Requisitos

  • Método main (Parte Interactiva):
    • Usar Scanner.
    • Bucle while que finalice con -1.
    • Imprimir el total.
  • Método calcularTotalGastos (Parte Lógica):
    • Aceptar un ArrayList<Double>.
    • Devolver un double con la suma.

Diagrama de Flujo (Método main)

Este diagrama representa la lógica interactiva del método main.

Código Fuente

import java.util.ArrayList;
import java.util.Scanner;

public class Ejemplo_3_4 {

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        double sumGas = 0;

        System.out.println("Ingrese los gastos (ingrese -1 para finalizar):");
        double gasto = sc.nextDouble();

        while (gasto != -1) {
            sumGas += gasto;
            System.out.println("Ingrese los gastos (ingrese -1 para finalizar):");
            gasto = sc.nextDouble();
        }

        System.out.println("El total de gastos del viaje es: " + sumGas);
    }

    public double calcularTotalGastos(ArrayList gastos) {
        double total = 0.0;
        for (double gasto : gastos) {
            total += gasto;
        }
        return total;
    }
}

Notas rápidas

Asegúrate de:

  • Probar la parte interactiva ejecutando el main.
  • El bucle while con valor centinela (-1) es ideal para la entrada manual.
  • El bucle for-each es perfecto para procesar la lista en el método de lógica.
Tip (¡Importante!): Al separar la lógica (sumar una lista) de la entrada/salida (pedir números con Scanner), hacemos el código testeable. Las pruebas automáticas (JUnit) pueden llamar a calcularTotalGastos fácilmente, pero no pueden "escribir" en un Scanner.
Problema 3.15

Calculadora de Costo de Llamadas (Clase de Lógica)

Esta es una clase de lógica (`problema_3_15`) diseñada para calcular el costo total de llamadas. No contiene un método main ni Scanner. Mantiene un estado interno (el contador cl y la cuenta total) y procesa llamadas una por una a través del método procesarLlamada.

Lógica de Cálculo (Secuencial y Aditivo)

El costo de cada llamada se calcula sumando los resultados de tres bloques de reglas secuenciales:

  1. Bloque 1 (Costo base o 'H'):
    • Si es 'H' y > 3 min: $7.59 + ($3.03 * mins_extra).
    • En otro caso: $7.59.
  2. Bloque 2 (Recargo 'L'):
    • Si es 'L': cl++.
    • Si cl es > 50: se añade $0.60.
  3. Bloque 3 (Costo general por duración):
    • Si > 3 min: $1.20 + ($0.48 * mins_extra).
    • Si 3 min o menos: $1.20.

Diagrama de Flujo

Este diagrama representa la lógica de la clase problema_3_15.

Código Fuente (Clase de Lógica)

public class problema_3_15 {
    
    private int cl = 0;
    private double cuenta = 0;

    public void procesarLlamada(String tipo, int dur) {
        
        // --- Bloque 1 ---
        if (tipo.equals("H") && dur > 3) {
            double costo = 7.59 + ((dur - 3) * 3.03);
            cuenta += costo;
        } else {
            double costo = 7.59;
            cuenta += costo;
        }
        
        // --- Bloque 2 ---
        if (tipo.equals("L")) {
            cl++;
            if (cl > 50) {
                cuenta += 0.60;
            }
        }
        
        // --- Bloque 3 ---
        if (dur > 3) {
            double costo = 1.20 + ((dur - 3) * 0.48);
            cuenta += costo;
        } else {
            double costo = 1.20;
            cuenta += costo;
        }
    }

    public double getCuenta() {
        return cuenta;
    }

    public int getCL() {
        return cl;
    }
}

Notas rápidas

Puntos clave del diseño:

  • Clase Estatal (Stateful): cl y cuenta guardan su valor entre llamadas.
  • Lógica Aditiva: El costo final es la suma de los 3 bloques.
  • Diseño Testeable: El código está separado para ser probado.
  • Getters: getCuenta() y getCL() son esenciales para que un test pueda verificar el estado.
Tip: Este diseño es un ejemplo de Separación de Intereses. La clase problema_3_15 se encarga *solo* de la lógica de negocio.
Problema 4.2

Eliminar elementos repetidos de un arreglo

Este programa recibe un arreglo unidimensional (vector) de enteros desordenado, que puede contener valores repetidos (VEC[1..N], con N <= 500). El objetivo es procesar este arreglo y obtener como salida el mismo vector, pero sin repeticiones.

Requisitos

  • Leer N (número de elementos) en el main.
  • Leer los N enteros en un ArrayList (VEC) en el main.
  • La lógica de filtrado debe estar en un método static ArrayList<Integer> eliminarDuplicados(ArrayList<Integer> vec).
  • El método eliminarDuplicados debe usar un LinkedHashSet para filtrar duplicados y mantener el orden de la primera aparición.
  • El método main debe llamar a la lógica e imprimir la lista resultante.

Diagrama de Flujo

Este diagrama ilustra la lógica principal del programa.

Código Fuente

import java.util.ArrayList;
import java.util.LinkedHashSet;
import java.util.Scanner; // Importante para mantener el orden
import java.util.Set;

public class Problema_4_2 {

    /**
     * El método main ahora se enfoca solo en la entrada y salida.
     */
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.println("Ingrese el tamaño del vector (N <= 500):");
        int N = sc.nextInt();

        if (N < 1 || N > 500) {
            System.out.println("Tamaño fuera de rango (1 <= N <= 500).");
            sc.close(); // Cerrar scanner antes de salir
            return;
        }

        // Usar genéricos: ArrayList
        ArrayList VEC = new ArrayList<>();
        System.out.println("Ingrese los " + N + " elementos del vector:");
        
        for (int i = 0; i < N; i++) {
            System.out.print("Elemento " + (i + 1) + ": ");
            VEC.add(sc.nextInt());
        }
        sc.close(); // Cerrar el scanner

        System.out.println("Vector original: " + VEC);

        // --- Llamada al método de lógica ---
        ArrayList vecSinRepetir = eliminarDuplicados(VEC);

        System.out.println("Vector sin repeticiones: " + vecSinRepetir);
    }

    /**
     * Esta es la función de lógica que probaremos.
     * Recibe una lista con duplicados y devuelve una lista sin duplicados,
     * manteniendo el orden de la primera aparición.
     *
     * @param vec La lista original con duplicados.
     * @return Una nueva ArrayList sin duplicados.
     */
    public static ArrayList eliminarDuplicados(ArrayList vec) {
        // 1. Usar un LinkedHashSet para eliminar duplicados
        //    LinkedHashSet mantiene el orden de inserción
        Set setSinRepetir = new LinkedHashSet<>(vec);

        // 2. Convertir el set de vuelta a una lista
        return new ArrayList<>(setSinRepetir);
    }
}

Notas rápidas

Puntos clave:

  • Separación de Lógica: El main maneja la E/S, mientras eliminarDuplicados maneja el procesamiento.
  • La forma más simple en Java de eliminar duplicados es usar un Set.
  • Se usa LinkedHashSet porque, a diferencia de HashSet, garantiza que se mantenga el orden de inserción (el orden en que apareció cada elemento por primera vez).
  • Alternativa algorítmica: Se puede resolver sin Set usando bucles: crear un nuevo ArrayList (vecSinRepetir) e iterar sobre VEC. Por cada elemento, verificar si vecSinRepetir.contains(elemento) es false antes de agregarlo.
Tip: Si el orden de los elementos no importara en la salida, se podría usar HashSet, que es ligeramente más rápido en algunas operaciones que LinkedHashSet.

Problema 5.3

Introducción a Objetos - Clase Domicilio

Programa que introduce el concepto de Programación Orientada a Objetos (POO). El método main pide al usuario los datos de un domicilio (calle, número, etc.) y los utiliza para crear un objeto (instanciar) de la clase Domicilio. Finalmente, imprime los atributos del objeto creado.

Requisitos

  • Definir una clase Domicilio para que actúe como un "molde" para los datos.
  • La clase Domicilio debe tener atributos para: calle, numero, ciudad y pais.
  • La clase Domicilio debe tener un constructor que acepte los cuatro datos y los asigne a los atributos.
  • El método main debe usar Scanner para leer los cuatro datos del usuario.
  • El main debe crear una instancia (objeto) de la clase Domicilio usando la palabra clave new.
  • El main debe imprimir los atributos del objeto creado para verificar que se guardaron correctamente.

Diagrama de Flujo (Método main)

Este diagrama representa el flujo del método main, que lee los datos, crea el objeto y muestra los resultados.

Código Fuente (Clase Domicilio)

import java.util.Scanner;

/**
 *
 * @author zenri
 */
public class Ejemplo_5_3 {

    /**
     * @param args the command line arguments
     */
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        System.out.print("Ingrese la calle: ");
        String calle = scanner.nextLine();
        System.out.print("Ingrese el número: ");
        int numero = scanner.nextInt();
        scanner.nextLine();
        System.out.print("Ingrese la ciudad: ");
        String ciudad = scanner.nextLine();
        System.out.print("Ingrese el país: ");
        String pais = scanner.nextLine();

        // 2. Se crea la "instancia" u "objeto"
        Domicilio domicilio = new Domicilio(calle, numero, ciudad, pais);

        // 3. Se accede a los atributos del objeto
        System.out.println("Calle: " + domicilio.calle);
        System.out.println("Número: " + domicilio.numero);
        System.out.println("Ciudad: " + domicilio.ciudad);
        System.out.println("País: " + domicilio.pais);
    }
}

// 1. Se define la "clase" o "molde"
class Domicilio {

    String calle;
    int numero;
    String ciudad;
    String pais;

    // Este es el "constructor". Se llama al usar 'new Domicilio(...)'
    public Domicilio(String calle, int numero, String ciudad, String pais) {
        this.calle = calle;
        this.numero = numero;
        this.ciudad = ciudad;
        this.pais = pais;
    }
}

Notas rápidas

Puntos clave:

  • Clase: Es el molde o plantilla (class Domicilio).
  • Objeto: Es la "cosa" real creada a partir del molde (la variable domicilio en el main).
  • Constructor: Es el método especial que se llama con new para inicializar los atributos del objeto.
  • Atributos: Son las variables *dentro* de la clase (calle, numero, etc.).
  • Recuerda usar sc.nextLine(); después de sc.nextInt(); para consumir el "Enter" y evitar errores al leer la siguiente cadena.
Tip (this): La palabra clave this se usa dentro del constructor para desambiguar. En this.calle = calle;:
  • this.calle se refiere al atributo de la clase.
  • calle (solo) se refiere al parámetro que llega al método.
PS 2.4

Calcular aumento de sueldo (15% o 12%)

Programa que calcula un aumento de sueldo (15% si SUE < 1000, 12% si no). La lógica del if-else se ha movido del método main a un método estático separado (calcularNuevoSueldo).

Requisitos

  • Leer el sueldo del trabajador (SUE).
  • Separar la lógica en un método static double calcularNuevoSueldo(double sueldo).
  • Dentro del método, si sueldo < 1000, el aumento es del 15%.
  • En caso contrario (else), el aumento es del 12%.
  • El método debe retornar el nuevo sueldo (sueldo + aumento).
  • El método main solo debe pedir el dato, llamar al método de lógica y mostrar el resultado.

Diagrama de Flujo

Este diagrama ilustra la lógica condicional del cálculo.

Código Fuente

import java.util.Scanner;

public class PS_2_4 {

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        System.out.print("Ingrese el sueldo del trabajador: $");
        double sueldo = scanner.nextDouble();
        scanner.close();
        
        double nuevoSueldo = calcularNuevoSueldo(sueldo);
        
        System.out.printf("El sueldo con el aumento incorporado es: $%.2f%n", nuevoSueldo);
    }

    public static double calcularNuevoSueldo(double sueldo) {
        double aumento;
        if (sueldo < 1000) {
            aumento = sueldo * 0.15; // Aumento del 15%
        } else {
            aumento = sueldo * 0.12; // Aumento del 12%
        }
        return sueldo + aumento;
    }
}

Notas rápidas

Puntos clave:

  • Este es un problema de bifurcación simple if-else.
  • Separación de Lógica: La lógica se movió a un método static para ser reutilizable y testeable.
  • El main ahora sigue el principio de Separación de Intereses: solo se preocupa de la E/S (Entrada/Salida).
Tip: Mover la lógica de negocio (el "cómo" calcular) a su propio método (calcularNuevoSueldo) es una práctica excelente. Hace que el main sea fácil de leer y permite probar la lógica de cálculo de forma aislada.
PS 2.5

Calcular dos expresiones con Manejo de Excepciones

Programa que calcula (A-C)² / D y (A-B)³ / D. Utiliza manejo de excepciones. La lógica de cálculo está en un método static que lanza (throws) una excepción si D es 0, y el método main atrapa (catches) el error.

Requisitos

  • Leer cuatro valores enteros: A, B, C, y D.
  • La lógica debe estar en un método static int[] calcularResultados(...).
  • Si D == 0, el método de lógica debe lanzar una IllegalArgumentException.
  • El método main debe llamar a la lógica dentro de un bloque try...catch.
  • Si se atrapa una excepción, main debe imprimir el mensaje de error.
  • Los cálculos deben realizarse usando división entera (int).

Diagrama de Flujo

Este diagrama ilustra la lógica condicional del cálculo.

Código Fuente

import java.util.Scanner;

public class PS_2_5 {

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.println("Ingrese el valor de A:");
        int A = scanner.nextInt();
        // ... (resto de las lecturas)
        System.out.println("Ingrese el valor de D:");
        int D = scanner.nextInt();
        scanner.close();

        try {
            int[] resultados = calcularResultados(A, B, C, D);
            System.out.println("El resultado de (A - C)^2 / D es: " + resultados[0]);
            System.out.println("El resultado de (A - B)^3 / D es: " + resultados[1]);
        
        } catch (IllegalArgumentException e) {
            System.out.println("Error: " + e.getMessage());
        }
    }

    public static int[] calcularResultados(int A, int B, int C, int D) {
        if (D == 0) {
            throw new IllegalArgumentException("D no puede ser igual a 0. No se puede calcular la expresión.");
        }
        int resultado1 = (A - C) * (A - C) / D;
        int resultado2 = (A - B) * (A - B) * (A - B) / D;
        return new int[]{resultado1, resultado2};
    }
}

Notas rápidas

Puntos clave:

  • Manejo de Excepciones: El flujo try...catch reemplaza al if...else del main.
  • throw: Se usa para "lanzar" un error. Detiene la ejecución del método calcularResultados y pasa el control al bloque catch.
  • División Entera: Este código usa int. 5 / 2 dará 2.
Tip: Usar throw new IllegalArgumentException es una forma estándar en Java de indicar que un argumento (como D) no es válido para un método. Obliga a quien llame al método (en este caso, main) a manejar el problema.
PS 2.6

Calcular precio de billete de ferrocarril

Calcula el precio de un billete de ida y vuelta con un descuento condicional. Se aplica un descuento del 30% si la estancia es superior a 7 días y la distancia total (ida y vuelta) es superior a 800 km.

Requisitos

  • Leer la distancia de ida (distanciaIda) y el tiempo de estancia (tiempoEstancia) en main.
  • La lógica de cálculo debe estar en un método static double calcularPrecioBillete(int, int).
  • El método debe calcular la distancia total (distanciaIda * 2).
  • El método debe calcular el precio base (distanciaTotal * 0.23).
  • El método debe aplicar la condición: tiempoEstancia > 7 && distanciaTotal > 800.
  • Si se cumple, aplicar descuento del 30% (multiplicando por 0.70).
  • El método debe retornar el precio final.
  • El método main debe imprimir el resultado formateado.

Diagrama de Flujo

Este diagrama ilustra la lógica condicional del cálculo del descuento.

Código Fuente

import java.util.Scanner;

/**
 *
 * @author imac27
 */
public class PS_2_6 {

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        System.out.print("Ingrese la distancia del viaje de ida (en km): ");
        int distanciaIda = scanner.nextInt();
        
        System.out.print("Ingrese el tiempo de estancia (en días): ");
        int tiempoEstancia = scanner.nextInt();
        scanner.close();
        
        // Llamar a la lógica
        double precioFinal = calcularPrecioBillete(distanciaIda, tiempoEstancia);
        
        // Imprimir el resultado (usando printf para formato de moneda)
        System.out.printf("El precio del billete de ida y vuelta es: $%.2f%n", precioFinal);
    }

    /**
     * Calcula el precio del billete de ida y vuelta, aplicando descuentos si cumplen
     * las condiciones.
     *
     * @param distanciaIda Distancia del viaje de ida (en km).
     * @param tiempoEstancia Tiempo de estancia (en días).
     * @return El precio final del billete.
     */
    public static double calcularPrecioBillete(int distanciaIda, int tiempoEstancia) {
        int distanciaVuelta = distanciaIda;
        int distanciaTotal = distanciaIda + distanciaVuelta; // o (distanciaIda * 2)
        double precioPorKm = 0.23;
        
        double precioBillete = distanciaTotal * precioPorKm;
        
        // Lógica del descuento
        if (tiempoEstancia > 7 && distanciaTotal > 800) {
            // Aplicar descuento del 30% (es más eficiente multiplicar por 0.7)
            precioBillete = precioBillete * 0.70;
        }
        
        return precioBillete;
    }
}

Notas rápidas

Puntos clave:

  • El método main se encarga de la E/S (Entrada/Salida).
  • El método calcularPrecioBillete se encarga de la lógica.
  • El operador && (AND lógico) es esencial para la condición de descuento.
  • El descuento (30%) se aplica multiplicando por el restante (70% o 0.70).
  • Usar double es crucial para los cálculos de dinero.
Tip: Mover la lógica a su propio método (calcularPrecioBillete) hace que el main sea mucho más fácil de leer.
PS 2.7

Calcular aumento de sueldo escalonado

Calcula un aumento de sueldo basado en rangos: Si SUELDO < $10,000, aumento del 15%. Si $10,000 <= SUELDO <= $15,000, aumento del 11%. Si SUELDO > $15,000, aumento del 8%.

Requisitos

  • Leer el sueldo (sueldo) en el método main.
  • La lógica de cálculo debe estar en un método static double calcularNuevoSueldo(double sueldoActual).
  • El método debe usar if-else if-else para los rangos.
  • Si sueldo < 10000, retornar sueldo * 1.15 (15%).
  • Si sueldo < 15000, retornar sueldo * 1.11 (11%).
  • Si no, retornar sueldo * 1.08 (8%).
  • El método main debe llamar a calcularNuevoSueldo e imprimir el resultado final.

Este diagrama ilustra la lógica condicional del cálculo.

     * @return El nuevo sueldo calculado.

            // Esto incluye sueldos >= 10000 Y < 15000
            return sueldoActual * 1.11; // Aumento del 11%
        } else {
            // Esto incluye sueldos >= 15000
            return sueldoActual * 1.08; // Aumento del 8%
        }
    }
}

  • El orden del if es importante. Al checar < 10000 primero, el else if solo necesita checar < 15000.
  • El cálculo sueldo * 1.15 es una forma directa de calcular el 15% de aumento (100% + 15%).
Tip: Mover la lógica a su propio método (calcularNuevoSueldo) hace que el main sea mucho más fácil de leer y permite probar la lógica de cálculo de forma aislada.
PS 3.26

Estadísticas de Alumnos por Sexo (con Objetos)

Programa que procesa los datos de N alumnos. Esta versión utiliza Programación Orientada a Objetos (POO): 1. El main lee los datos y crea una List<Alumno>. 2. Un método static (calcularEstadisticas) recibe la lista y procesa los datos. 3. El método devuelve un objeto Estadisticas con todos los resultados.

Requisitos

  • Definir una clase interna Alumno para almacenar el sexo y promedio.
  • Definir una clase interna Estadisticas para almacenar los 5 resultados calculados.
  • El main debe:
    • Leer N.
    • En un bucle for, leer los datos de cada alumno.
    • Crear un objeto Alumno por cada uno y guardarlo en una ArrayList.
    • Llamar al método calcularEstadisticas pasándole la lista.
    • Imprimir los resultados recibidos en el objeto Estadisticas.
  • El método calcularEstadisticas debe:
    • Recibir una List<Alumno>.
    • Iterar sobre la lista, acumulando y contando por sexo.
    • Calcular los promedios y porcentajes (validando la división por cero).
    • Retornar un new Estadisticas(...) con los resultados.

Diagrama de Flujo

Este diagrama ilustra la lógica general del procesamiento.

Código Fuente (POO)

import java.util.ArrayList;
import java.util.List; // Importar List
import java.util.Scanner; // Importar ArrayList

public class PS_3_26 {

    // --- 1. Clase interna para guardar los datos de un alumno ---
    public static class Alumno {
        int sexo;
        double promedio;
        public Alumno(int sexo, double promedio) { /*...*/ }
        public int getSexo() { return sexo; }
        public double getPromedio() { return promedio; }
    }

    // --- 2. Clase interna para guardar los resultados ---
    public static class Estadisticas {
        public final double porcentajeFemenino;
        public final double promedioFemenino;
        public final double porcentajeMasculino;
        public final double promedioMasculino;
        public final double promedioGeneral;
        public Estadisticas(double porFem, double promFem, ...) { /*...*/ }
    }

    // --- 3. El método main (ahora solo maneja I/O) ---
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        List listaAlumnos = new ArrayList<>();

        System.out.print("Ingrese el número de alumnos: ");
        int N = scanner.nextInt();

        for (int i = 1; i <= N; i++) {
            // ... (Lectura de datos: sexo, promedio, etc.) ...
            
            // Creamos y añadimos el alumno a la lista
            listaAlumnos.add(new Alumno(sexo, promedio));
        }
        scanner.close();

        // --- 4. Llamamos al método de lógica ---
        Estadisticas stats = calcularEstadisticas(listaAlumnos);

        // --- 5. Imprimimos los resultados ---
        System.out.println("\nEstadísticas de la universidad:");
        System.out.println("Porcentaje de población femenina: " + stats.porcentajeFemenino + "%");
        System.out.println("Promedio de la población femenina: " + stats.promedioFemenino);
        // ... (resto de impresiones) ...
    }

    // --- 6. El método de lógica (¡Este es el que probaremos!) ---
    public static Estadisticas calcularEstadisticas(List alumnos) {
        int N = alumnos.size();
        int contadorFemenino = 0;
        int contadorMasculino = 0;
        double sumaFemenino = 0; 
        double sumaMasculino = 0;
        double sumaTotal = 0;

        // Iteramos sobre la lista de alumnos
        for (Alumno alumno : alumnos) {
            if (alumno.getSexo() == 0) {
                contadorFemenino++;
                sumaFemenino += alumno.getPromedio();
            } else {
                contadorMasculino++;
                sumaMasculino += alumno.getPromedio();
            }
            sumaTotal += alumno.getPromedio();
        }

        // Hacemos los cálculos (con validación de división por cero)
        double promedioFemenino = (contadorFemenino > 0) ? sumaFemenino / (double) contadorFemenino : 0;
        double promedioMasculino = (contadorMasculino > 0) ? sumaMasculino / (double) contadorMasculino : 0;
        double promedioGeneral = (N > 0) ? sumaTotal / (double) N : 0;
        double porcentajeFemenino = (N > 0) ? (contadorFemenino / (double) N) * 100 : 0;
        double porcentajeMasculino = (N > 0) ? (contadorMasculino / (double) N) * 100 : 0;
        
        // Devolvemos el objeto con todos los resultados
        return new Estadisticas(porcentajeFemenino, promedioFemenino, porcentajeMasculino, promedioMasculino, promedioGeneral);
    }
}

Notas rápidas

Puntos clave:

  • POO: Se usan clases (Alumno, Estadisticas) para organizar los datos, en lugar de variables sueltas.
  • Separación de Lógica: El main solo maneja la E/S. El método calcularEstadisticas maneja la lógica de negocio.
  • Colecciones: Se usa List<Alumno> para guardar los datos en memoria antes de procesarlos.
  • Paso de Datos: El main le pasa la lista completa al método de lógica y este le devuelve un *único objeto* (Estadisticas) con todos los resultados.
Tip (POO): Este patrón (Clase de Datos, Clase de Resultados, Método de Lógica) es extremadamente común, robusto y fácil de probar con JUnit.
PS 4.4

Calcular el producto de dos vectores

Programa que, dados dos vectores (arreglos unidimensionales) A y B de tipo entero y de tamaño N, calcula el producto de dichos vectores. (Se asume que "producto" se refiere al producto punto o producto escalar).

Requisitos

  • Leer el tamaño N de los vectores en el main.
  • Leer los N elementos del vector A en el main.
  • Leer los N elementos del vector B en el main.
  • La lógica de cálculo debe estar en un método static int calcularProducto(int[] A, int[] B, int N).
  • El método debe calcular el producto punto: $PROD = A_0 \times B_0 + \dots + A_{N-1} \times B_{N-1}$.
  • El método debe retornar el producto (un int).
  • El main debe imprimir el resultado.

Diagrama de Flujo

Este diagrama ilustra la lógica del cálculo del producto punto.

Código Fuente

import java.util.Scanner;

/**
 *
 * @author imac27
 */
public class PS_4_4 {

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Ingrese el tamaño de los vectores: ");
        int N = scanner.nextInt();

        int[] A = new int[N];
        int[] B = new int[N];

        System.out.println("Ingrese los elementos del vector A:");
        for (int i = 0; i < N; i++) {
            System.out.print("Elemento " + (i+1) + ": ");
            A[i] = scanner.nextInt();
        }

        System.out.println("Ingrese los elementos del vector B:");
        for (int i = 0; i < N; i++) {
            System.out.print("Elemento " + (i+1) + ": ");
            B[i] = scanner.nextInt();
        }

        // Se llama al método de lógica
        int producto = calcularProducto(A, B, N);

        System.out.println("El producto de los vectores es: " + producto);
    }

    /**
     * Calcula el producto punto (escalar) de dos vectores.
     * Esta es la lógica que se prueba.
     */
    public static int calcularProducto(int[] A, int[] B, int N) {
        int producto = 0;

        for (int i = 0; i < N; i++) {
            producto += A[i] * B[i];
        }

        return producto;
    }    
}

Notas rápidas

Puntos clave:

  • El "producto de vectores" se refiere al producto punto (escalar), que resulta en un solo número (un escalar).
  • Se calcula sumando los productos de los elementos en la misma posición: $A[i] \times B[i]$.
  • Separación de Lógica: El main se encarga de la E/S, y calcularProducto se encarga del cálculo.
  • Se necesita un acumulador (producto) inicializado en 0.
Tip: Mover la lógica a su propio método (calcularProducto) hace que el main sea mucho más fácil de leer y permite probar la lógica de cálculo de forma aislada.
PS 4.20

Asignar valores a Matriz A(MxN) desde Vector B(N)

Programa que asigna valores a una matriz A (de M x N) a partir de un vector B (de N elementos), usando los siguientes criterios:
a) A[i, j] = B[j] si i <= j
b) A[i, j] = 0 si i > j

Requisitos

  • Leer M (filas) y N (columnas) en el main.
  • Leer el vector B de N elementos en el main.
  • La lógica de generación debe estar en un método static double[][] generarArregloA(int m, int n, double[] B).
  • El método debe crear la matriz A de M x N.
  • El método debe iterar (i para filas, j para columnas) y aplicar la lógica:
    • Si i <= j, asignar A[i][j] = B[j].
    • Si i > j, asignar A[i][j] = 0.
  • El método debe retornar la matriz A generada.
  • El main debe imprimir la matriz A resultante.

Diagrama de Flujo

Este diagrama ilustra la lógica condicional para llenar la matriz.

Código Fuente

import java.util.Scanner;
import java.util.Arrays; // Útil para imprimir arreglos

public class PS_4_20 {

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Ingrese el numero de renglones (M) del arreglo A: ");
        int m = scanner.nextInt();

        System.out.print("Ingrese el numero de columnas (N) del arreglo A: ");
        int n = scanner.nextInt();

        double[] B = new double[n];

        // Leer los valores del arreglo B
        System.out.println("Ingrese los valores del arreglo B:");
        for (int i = 0; i < n; i++) {
            System.out.print("Ingrese el valor B[" + (i + 1) + "]: ");
            B[i] = scanner.nextDouble();
        }
        scanner.close(); // Cerrar el scanner

        // --- Llamada al método de lógica ---
        double[][] A = generarArregloA(m, n, B);

        // Imprimir el arreglo A
        System.out.println("El arreglo A es:");
        for (int i = 0; i < m; i++) {
            // Usar Arrays.toString() es una forma limpia de imprimir cada fila
            System.out.println(Arrays.toString(A[i]));
        }
    }

    /**
     * Genera la matriz A[m][n] basado en el vector B[n].
     * Esta es la función que probaremos.
     *
     * @param m Renglones de A
     * @param n Columnas de A (y tamaño de B)
     * @param B El vector de entrada
     * @return La matriz A generada
     */
    public static double[][] generarArregloA(int m, int n, double[] B) {
        double[][] A = new double[m][n];

        // Asignar valores a A según los criterios
        for (int i = 0; i < m; i++) { // i = fila
            for (int j = 0; j < n; j++) { // j = columna
                if (i <= j) {
                    A[i][j] = B[j];
                } else {
                    // i > j
                    A[i][j] = 0;
                }
            }
        }
        return A;
    }
}

Notas rápidas

Puntos clave:

  • Separación de Lógica: El main maneja la E/S, y generarArregloA maneja el cálculo.
  • Esto genera una matriz donde la "parte triangular inferior" (debajo de la diagonal) es cero.
  • La diagonal principal (i == j) y la parte superior (i < j) toman valores del vector B.
  • El valor asignado B[j] depende del índice de la columna (j).
Tip: Mover la lógica de generación de la matriz a su propio método (generarArregloA) es una excelente práctica. Hace que el main sea limpio y que la lógica sea testeable.
PS 4.36 (POO)

Actualización de Inventario de Tienda (con POO)

Programa que administra el inventario de una tienda (N <= 100 productos). Esta versión usa POO: 1. Una clase Inventario almacena el estado (claves, cantidades). 2. El main maneja la E/S. 3. Métodos static (procesarCompra, procesarVenta) contienen la lógica y modifican el objeto Inventario.

Requisitos

  • Definir una clase Inventario para guardar los arreglos de claves, cantidades, el numProductos actual y el MAX_PRODUCTOS.
  • El main debe leer los productos iniciales y luego entrar en un bucle de transacciones.
  • El bucle termina si el tipo de operación es 'X'.
  • Implementar un método buscarProducto (búsqueda lineal) que retorna el índice o -1.
  • Implementar procesarCompra(inv, clave, cant):
    • Si el producto existe, suma cant al stock.
    • Si no existe y hay espacio (numProductos < MAX), lo añade como nuevo producto.
    • Si no hay espacio, devuelve un error.
  • Implementar procesarVenta(inv, clave, cant):
    • Si el producto no existe, devuelve un error.
    • Si existe pero stock < cant, devuelve error de stock.
    • Si existe y hay stock, resta cant.
  • El main imprime el inventario final.

Diagrama de Flujo

Este diagrama ilustra la lógica principal del bucle de transacciones.

Código Fuente (POO)

import java.util.Scanner;

public class PS_4_36 {

    // 1. Clase interna estática para guardar el estado del inventario
    public static class Inventario {
        public final int MAX_PRODUCTOS;
        public int[] clavesProductos;
        public int[] cantidadesProductos;
        public int numProductos;
        public Inventario(int max) { /*...*/ }
    }

    // 2. El método main (ahora solo maneja I/O)
    public static void main(String[] args) {
        Inventario inv = new Inventario(100); // MAX_PRODUCTOS = 100
        Scanner scanner = new Scanner(System.in);

        // ... (Lectura de N, claves iniciales y cantidades) ...

        // Paso 3: Actualizar los arreglos según las transacciones
        boolean finDatos = false;
        while (!finDatos) {
            System.out.println("Ingrese (Tipo, Clave, Cantidad) o (X, 0, 0):");
            char tipoOperacion = scanner.next().charAt(0);
            int claveProducto = scanner.nextInt();
            int cantidad = scanner.nextInt();
            
            String resultadoOperacion = null; // Para guardar mensajes de error

            switch (tipoOperacion) {
                case 'C':
                    resultadoOperacion = procesarCompra(inv, claveProducto, cantidad);
                    break;
                case 'V':
                    resultadoOperacion = procesarVenta(inv, claveProducto, cantidad);
                    break;
                case 'X':
                    finDatos = true;
                    break;
                default:
                    resultadoOperacion = "Operación inválida.";
            }
            
            if (resultadoOperacion != null) {
                System.out.println(resultadoOperacion);
            }
        }

        // ... (Impresión del inventario final) ...
        scanner.close();
    }

    // --- 3. Métodos de Lógica (¡Esto es lo que probaremos!) ---

    public static int buscarProducto(Inventario inv, int claveProducto) {
        for (int i = 0; i < inv.numProductos; i++) {
            if (inv.clavesProductos[i] == claveProducto) {
                return i; // Se encontró
            }
        }
        return -1; // No se encontró
    }

    public static String procesarCompra(Inventario inv, int claveProducto, int cantidad) {
        int indice = buscarProducto(inv, claveProducto);
        if (indice != -1) {
            // Producto existe, sumar stock
            inv.cantidadesProductos[indice] += cantidad;
            return null; // Éxito
        } else {
            // Producto no existe, añadir nuevo
            if (inv.numProductos < inv.MAX_PRODUCTOS) {
                inv.clavesProductos[inv.numProductos] = claveProducto;
                inv.cantidadesProductos[inv.numProductos] = cantidad;
                inv.numProductos++;
                return null; // Éxito
            } else {
                return "No se pueden agregar más productos. Capacidad máxima alcanzada.";
            }
        }
    }

    public static String procesarVenta(Inventario inv, int claveProducto, int cantidad) {
        int indice = buscarProducto(inv, claveProducto);
        if (indice != -1) {
            // Producto existe
            if (inv.cantidadesProductos[indice] >= cantidad) {
                inv.cantidadesProductos[indice] -= cantidad;
                return null; // Éxito
            } else {
                return "No hay suficiente cantidad del producto.";
            }
        } else {
            return "El producto no existe.";
        }
    }
}

Notas rápidas

Puntos clave:

  • POO: Se usa una clase Inventario para encapsular los datos. Los métodos static operan sobre esta clase.
  • Búsqueda Lineal: El método buscarProducto usa un for simple. Esto significa que el arreglo de claves no necesita estar ordenado.
  • Lógica de Compra: A diferencia del código anterior, este añade nuevos productos al inventario si no existen y hay espacio.
  • Manejo de Errores: Los métodos de lógica devuelven null si todo va bien, o un String con el mensaje de error. El main se encarga de imprimir ese error.
Tip: Pasar el objeto Inventario a cada método de lógica es un patrón común. Permite que todos los métodos trabajen sobre el mismo "estado" centralizado, modificándolo según sea necesario.
