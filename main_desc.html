Escribir números en orden inverso

  • La entrada y salida son directas.

Problema 1.7

Calcular el área de un triángulo (Fórmula de Herón)

Lee los tres lados de un triángulo como números decimales y calcula su área usando la fórmula de Herón. Primero calcula el semiperímetro, luego aplica la fórmula matemática para obtener el área del triángulo.

Requisitos

  • Leer los 3 lados del triángulo (decimales: L1, L2, L3).
  • Calcular el semiperímetro: S = (L1 + L2 + L3) / 2.
  • Aplicar la fórmula de Herón: Área = √(S × (S - L1) × (S - L2) × (S - L3)).
  • Mostrar el área calculada.

Fórmulas a utilizar

  1. Semiperímetro (S):
    S = (L1 + L2 + L3) / 2
  2. Área del triángulo:
    Area = √(S * (S - L1) * (S - L2) * (S - L3))

Ejemplo de uso esperado

--- Cálculo de área de un triángulo ---
Ingresa Lado 1: 5
Ingresa Lado 2: 6
Ingresa Lado 3: 7
El área del triángulo es: 14.696938456699069

Notas rápidas

Puntos clave:

  • Usa double para precisión en los cálculos.
  • Usa Math.pow() si es necesario o multiplica directamente.
  • Usa Math.sqrt() para la raíz cuadrada.
  • El resultado puede no ser un número entero.
Tip: Para un triángulo válido, la suma de dos lados debe ser mayor que el tercero.

PS 4.20

Asignar valores a Matriz A(MxN) desde Vector B(N)

Crea una matriz A de tamaño M×N usando un vector B de N elementos, aplicando estas reglas: si la fila es menor o igual a la columna, asigna B[i]; si la fila es mayor que la columna, asigna 0. El resultado es una matriz triangular superior.

Requisitos

  • Leer los valores M (filas) y N (columnas) en el main.
  • Leer el vector B de N elementos (índices de 1 a N).
  • Crear la matriz A de tamaño M x N.
  • Usar dos ciclos anidados: i para filas y j para columnas.
  • Asignar los valores en A siguiendo la lógica:
    • Si i < j → A[i][j] = B[i]
    • Si i = j → A[i][j] = B[i]
    • Si i > j → A[i][j] = 0
  • Imprimir la matriz resultante.
  • No se utiliza ningún método adicional; toda la lógica está en el main.

Ejemplo de uso esperado


Ingrese el valor de M (max 30): 3
Ingrese el valor de N (max 20): 4

Ingrese los valores del vector B:
B[1]: 5
B[2]: 7
B[3]: 9
B[4]: 4

Matriz A resultante:
5   5   5   5
0   7   7   7
0   0   9   9

Notas rápidas

Puntos clave:

  • Índices desde 1 a M (filas) y 1 a N (columnas).
  • Si i ≤ j: A[i][j] = B[i].
  • Si i > j: A[i][j] = 0.
  • La diagonal también usa B[i].
  • La parte inferior es siempre 0.
Tip: Usa dos ciclos anidados: uno para filas y otro para columnas.

    • Si la clave existe, se suma la cantidad.
    • Si no existe y hay espacio, se agrega como nuevo producto.
    • Si no hay espacio, se reporta error.
  • Venta (V):
    • Si la clave no existe → error.
    • Si existe pero no hay suficiente stock → error.
    • Si hay stock suficiente → se descuenta.
  • Al final, imprimir el inventario actualizado.
