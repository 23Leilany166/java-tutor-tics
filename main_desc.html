Ejemplo 1.6

Escribir números en orden inverso

Este programa lee cuatro números enteros (A, B, C y D) y los escribe en la consola en orden inverso (D, C, B, A).

Requisitos

  • Leer cuatro variables de tipo entero: A, B, C, y D.
  • Usar la clase Scanner para la entrada de datos.
  • Imprimir los valores en la consola en el orden: D, C, B, A.

Ejemplo de uso esperado

import java.util.Scanner;

public class Ejemplo_1_6 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.println("--- Lectura de 4 números enteros ---");
        
        System.out.print("Ingrese el valor A: ");
        int A = sc.nextInt();
        
        System.out.print("Ingrese el valor B: ");
        int B = sc.nextInt();
        
        System.out.print("Ingrese el valor C: ");
        int C = sc.nextInt();
        
        System.out.print("Ingrese el valor D: ");
        int D = sc.nextInt();

        System.out.println("\n--- Números en orden inverso ---");
        System.out.println("Valor D: " + D);
        System.out.println("Valor C: " + C);
        System.out.println("Valor B: " + B);
        System.out.println("Valor A: " + A);
    }
}

Notas de Diagrama de Flujo

Este problema introduce los símbolos básicos del diagrama de flujo:

  • Inicio / Fin: Se usa un óvalo o cápsula.
  • Lectura (Entrada): Se usa un paralelogramo (para leer A, B, C, D).
  • Escritura (Salida): Se usa un símbolo de documento (para escribir D, C, B, A).
Tip: Este es un algoritmo puramente secuencial. No requiere decisiones (if) ni bucles (while/for).
Problema 1.7

Calcular el área de un triángulo (Fórmula de Herón)

Este programa calcula el área de un triángulo dados sus tres lados (L1, L2, L3), aplicando la fórmula de Herón.

Fórmulas a utilizar

  1. Calcular el semiperímetro (S):
    S = (L1 + L2 + L3) / 2
  2. Calcular el Área:
    Area = √(S * (S - L1) * (S - L2) * (S - L3))

Ejemplo de uso esperado

import java.util.Scanner;
import java.util.Locale;
import java.lang.Math; // Para usar Math.sqrt()

public class Problema_1_7 {
    public static void main(String[] args) {
        // Usar Locale.US para asegurar que el Scanner lea decimales con '.'
        Scanner sc = new Scanner(System.in).useLocale(Locale.US);

        System.out.println("--- Calculadora de Área de Triángulo (Fórmula de Herón) ---");
        
        System.out.print("Ingrese la longitud del Lado 1 (L1): ");
        double L1 = sc.nextDouble();
        
        System.out.print("Ingrese la longitud del Lado 2 (L2): ");
        double L2 = sc.nextDouble();
        
        System.out.print("Ingrese la longitud del Lado 3 (L3): ");
        double L3 = sc.nextDouble();

        // 1. Calcular el semiperímetro (S)
        double S = (L1 + L2 + L3) / 2.0;

        // 2. Calcular el Área
        // (Validación opcional: asegurarse de que el radicando no sea negativo)
        double radicando = S * (S - L1) * (S - L2) * (S - L3);
        
        if (radicando < 0) {
            System.out.println("\nError: Los lados ingresados no forman un triángulo válido.");
        } else {
            double AREA = Math.sqrt(radicando);

            System.out.println("\n--- Resultados ---");
            System.out.printf("Lados: L1=%.2f, L2=%.2f, L3=%.2f%n", L1, L2, L3);
            System.out.printf("Semiperímetro (S): %.4f%n", S);
            System.out.printf("Área del triángulo: %.4f%n", AREA);
        }
    }
}

Notas rápidas

Puntos clave:

  • Los datos L1, L2, L3 deben ser de tipo double (real).
  • El semiperímetro S y el AREA también deben ser double.
  • Para calcular la raíz cuadrada, se utiliza el método Math.sqrt(valor).
  • Asegúrate de que la división para S sea una división de punto flotante (ej. / 2.0).
Tip: Un triángulo es válido solo si la suma de dos de sus lados es siempre mayor que el tercero. La fórmula de Herón fallará (raíz negativa) si los lados no forman un triángulo.
Problema 2.2

Evaluar la expresión P³ + Q⁴ - 2*P² < 680

Este programa solicita dos valores enteros, P y Q, y determina si satisfacen la expresión P³ + Q⁴ - 2*P² < 680. Si la cumplen, imprime los valores de P y Q.

Requisitos

  • Usar la clase Scanner para leer los enteros P y Q.
  • Calcular el resultado de la expresión: P³ + Q⁴ - 2*P².
  • Usar una estructura condicional if para verificar si el resultado es menor que 680.
  • Si la condición se cumple, imprimir un mensaje afirmativo junto con los valores de P y Q.
  • Si no se cumple, indicar que no se satisface.

Ejemplo de uso esperado

import java.util.Scanner;
import java.lang.Math; // Para usar Math.pow

public class Problema_2_2 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        
        System.out.println("Ingrese el valor entero P:");
        int P = sc.nextInt();
        
        System.out.println("Ingrese el valor entero Q:");
        int Q = sc.nextInt();
        
        // Calcular la expresión. Usamos double porque Math.pow retorna double.
        double resultado = Math.pow(P, 3) + Math.pow(Q, 4) - 2 * Math.pow(P, 2);
        
        System.out.println("Resultado de la expresión: " + resultado);

        // Evaluar la condición
        if (resultado < 680) {
            System.out.println("La expresión P³ + Q⁴ - 2*P² < 680 SÍ se cumple.");
            System.out.println("Valor de P: " + P);
            System.out.println("Valor de Q: " + Q);
        } else {
            System.out.println("La expresión P³ + Q⁴ - 2*P² < 680 NO se cumple.");
        }
    }
}

Notas rápidas

Asegúrate de:

  • Importar java.util.Scanner para la entrada de datos.
  • Usar Math.pow(base, exponente) para calcular las potencias.
  • Almacenar el resultado en una variable double, ya que Math.pow devuelve ese tipo.
  • Probar con valores que cumplan (ej. P=5, Q=3) y que no cumplan (ej. P=10, Q=10).
Tip: El problema pide imprimir P y Q solo "en caso afirmativo", por lo que el bloque else es opcional, pero útil para la depuración.
Ejemplo 3.4

Programa para obtener el total de gastos de un viaje

Este programa permite al usuario ingresar los gastos de un viaje (tipo real) y calcula el total, finalizando la entrada cuando el usuario ingresa -1.

Requisitos

  • Usar la clase Scanner para la entrada de datos.
  • Implementar un bucle while que permita ingresar múltiples gastos.
  • Calcular la suma total de los gastos ingresados.
  • Finalizar la entrada de datos cuando el usuario ingresa -1.

Ejemplo de uso esperado

import java.util.Scanner;

public class Ejemplo_3_4 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        double totalGastos = 0;

        System.out.println("Ingrese los gastos (ingrese -1 para finalizar):");
        double gasto = sc.nextDouble();

        while (gasto != -1) {
            totalGastos += gasto;
            System.out.println("Ingrese el siguiente gasto (ingrese -1 para finalizar):");
            gasto = sc.nextDouble();
        }

        System.out.println("El total de gastos del viaje es: " + totalGastos);
    }
}

Notas rápidas

Asegúrate de:

  • Probar el programa con diferentes entradas de gastos.
  • Verificar que el total se calcule correctamente.
  • El bucle while es ideal aquí porque no sabemos cuántos gastos se ingresarán.
Tip: Esta estructura de bucle con un valor centinela (-1) es muy común para terminar la entrada de datos.
Problema 3.15

Calcular costo de llamadas telefónicas

Este programa calcula el costo total de un conjunto de llamadas telefónicas. Por cada llamada, se ingresa el tipo ('I', 'N', 'L') y la duración en minutos. La entrada de datos termina cuando se ingresa '-1' como tipo.

Criterios de Costo

  • Internacional ('I'): 3 primeros minutos $7.59. Cada minuto adicional $3.03.
  • Nacional ('N'): 3 primeros minutos $1.20. Cada minuto adicional $0.48.
  • Local ('L'): Las primeras 50 llamadas locales no se cobran. A partir de la 51, cada llamada cuesta $0.60 (la duración no importa).

Ejemplo de uso esperado

import java.util.Scanner;
import java.util.Locale;

public class Problema_3_15 {
    public static void main(String[] args) {
        // Usar Locale.US para asegurar que el Scanner lea decimales con '.'
        Scanner sc = new Scanner(System.in).useLocale(Locale.US);
        
        double costoTotal = 0;
        int contadorLocales = 0;

        System.out.println("Ingrese tipo de llamada ('I', 'N', 'L') o '-1' para terminar:");
        String tipoStr = sc.next();

        while (!tipoStr.equals("-1")) {
            char tipo = tipoStr.toUpperCase().charAt(0);
            
            System.out.println("Ingrese duración en minutos:");
            int dur = sc.nextInt();
            
            double costoLlamada = 0;

            switch (tipo) {
                case 'I':
                    if (dur > 3) {
                        costoLlamada = 7.59 + (dur - 3) * 3.03;
                    } else {
                        costoLlamada = 7.59;
                    }
                    break;
                case 'N':
                    if (dur > 3) {
                        costoLlamada = 1.20 + (dur - 3) * 0.48;
                    } else {
                        costoLlamada = 1.20;
                    }
                    break;
                case 'L':
                    contadorLocales++;
                    if (contadorLocales > 50) {
                        costoLlamada = 0.60;
                    }
                    // Si es 50 o menos, costoLlamada permanece 0
                    break;
                default:
                    System.out.println("Tipo no válido. No se cobra.");
            }
            
            costoTotal += costoLlamada;
            System.out.printf("Costo de esta llamada: $%.2f%n", costoLlamada);
            
            // Leer el siguiente tipo para la próxima iteración
            System.out.println("\nIngrese tipo de llamada ('I', 'N', 'L') o '-1' para terminar:");
            tipoStr = sc.next();
        }

        System.out.println("\n---------------------------------");
        System.out.println("Cálculo finalizado.");
        System.out.printf("El costo total de todas las llamadas es: $%.2f%n", costoTotal);
        System.out.println("Total de llamadas locales realizadas: " + contadorLocales);
    }
}

Notas rápidas

Puntos clave:

  • Se necesita un acumulador (costoTotal) para la suma total.
  • Se necesita un contador (contadorLocales) específico para las llamadas locales.
  • La duración (DUR) es irrelevante para el costo de las llamadas locales.
  • Usar toUpperCase() hace la entrada de tipo más robusta (acepta 'i' o 'I').
  • El bucle se controla con un valor centinela ("-1"), leído como String.
Tip: Usa System.out.printf("El costo es: $%.2f%n", variable) para formatear la salida de dinero a dos decimales.
Problema 4.2

Eliminar elementos repetidos de un arreglo

Este programa recibe un arreglo unidimensional (vector) de enteros desordenado, que puede contener valores repetidos (VEC[1..N], con N <= 500). El objetivo es procesar este arreglo y obtener como salida el mismo vector, pero sin repeticiones.

Requisitos

  • Leer un entero N que representa el tamaño del arreglo (1 <= N <= 500).
  • Leer N enteros en un arreglo o lista (VEC).
  • Implementar una lógica para filtrar los elementos duplicados.
  • Mostrar el arreglo resultante sin los elementos repetidos.

Ejemplo de uso esperado (Solución con LinkedHashSet)

import java.util.Scanner;
import java.util.ArrayList;
import java.util.LinkedHashSet; // Importante para mantener el orden
import java.util.Set;

public class Problema_4_2 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.println("Ingrese el tamaño del vector (N <= 500):");
        int N = sc.nextInt();

        if (N < 1 || N > 500) {
            System.out.println("Tamaño fuera de rango (1 <= N <= 500).");
            return;
        }

        // Usamos un ArrayList para leer los datos fácilmente
        ArrayList VEC = new ArrayList<>();
        System.out.println("Ingrese los " + N + " elementos del vector:");
        
        for (int i = 0; i < N; i++) {
            System.out.print("Elemento " + (i + 1) + ": ");
            VEC.add(sc.nextInt());
        }

        System.out.println("Vector original: " + VEC);

        // 1. Usar un LinkedHashSet para eliminar duplicados
        //    LinkedHashSet mantiene el orden de inserción (el orden de la primera aparición)
        Set setSinRepetir = new LinkedHashSet<>(VEC);

        // 2. Convertir el set de vuelta a una lista (opcional, se puede imprimir el set)
        ArrayList vecSinRepetir = new ArrayList<>(setSinRepetir);

        System.out.println("Vector sin repeticiones: " + vecSinRepetir);
    }
}

Notas rápidas

Puntos clave:

  • La forma más simple en Java de eliminar duplicados es usar un Set.
  • Se usa LinkedHashSet porque, a diferencia de HashSet, garantiza que se mantenga el orden de inserción (el orden en que apareció cada elemento por primera vez).
  • El problema no especifica qué "copia" guardar (la primera, la última). Esta solución guarda la primera aparición.
  • Alternativa algorítmica: Se puede resolver sin Set usando bucles anidados: crear un nuevo ArrayList (vecSinRepetir) e iterar sobre VEC. Por cada elemento, verificar si vecSinRepetir.contains(elemento) es false antes de agregarlo.
Tip: Si el orden de los elementos no importara en la salida, se podría usar HashSet, que es ligeramente más rápido en algunas operaciones que LinkedHashSet.
Problema 4.15

Análisis de Ventas Anuales por Sucursal

Programa para manejar los montos de ventas de N sucursales a lo largo de M años, almacenados en una matriz (arreglo bidimensional). El programa debe calcular:
a) La sucursal con más ventas.
b) El promedio de ventas por año.
c) El año con el mayor promedio de ventas.

Requisitos y Datos

  • Leer M (años, $1 \le M \le 10$) y N (sucursales, $1 \le N \le 35$).
  • Leer la matriz MONTO[M][N] de tipo double con las ventas.
  • a) Sucursal con más ventas: Sumar las ventas de cada columna (sucursal) y encontrar la columna con la suma máxima.
  • b) Promedio de ventas por año: Sumar las ventas de cada fila (año) y dividirlas entre N.
  • c) Año con mayor promedio: Encontrar la fila (año) con el promedio máximo calculado en el paso anterior.

Ejemplo de uso esperado

import java.util.Scanner;
import java.util.Locale;

public class Problema_4_15 {
    public static void main(String[] args) {
        // Usar Locale.US para asegurar que el Scanner lea decimales con '.'
        Scanner sc = new Scanner(System.in).useLocale(Locale.US);

        System.out.println("Ingrese el número de años (M, max 10):");
        int M = sc.nextInt();
        System.out.println("Ingrese el número de sucursales (N, max 35):");
        int N = sc.nextInt();

        if (M < 1 || M > 10 || N < 1 || N > 35) {
            System.out.println("Error: M debe estar entre 1-10 y N entre 1-35.");
            return;
        }

        double[][] ventas = new double[M][N];
        double[] totalPorAnio = new double[M];
        double[] totalPorSucursal = new double[N];

        // --- Lectura de datos y cálculo de totales ---
        System.out.println("Ingrese los montos de ventas:");
        for (int i = 0; i < M; i++) { // i = año
            System.out.println("--- Año " + (i + 1) + " ---");
            for (int j = 0; j < N; j++) { // j = sucursal
                System.out.print("  Sucursal " + (j + 1) + ": ");
                ventas[i][j] = sc.nextDouble();
                
                // Acumulamos en los totales
                totalPorAnio[i] += ventas[i][j];
                totalPorSucursal[j] += ventas[i][j];
            }
        }
        
        System.out.println("\n--- RESULTADOS ---");

        // --- a) Sucursal con más ventas ---
        double maxVentaSuc = -1.0;
        int idxMaxSuc = -1;
        for (int j = 0; j < N; j++) {
            if (totalPorSucursal[j] > maxVentaSuc) {
                maxVentaSuc = totalPorSucursal[j];
                idxMaxSuc = j;
            }
        }
        // Se suma 1 al índice para mostrarlo (Sucursal 1 en lugar de 0)
        System.out.printf("a) Sucursal con más ventas: %d (Total: $%.2f)%n", (idxMaxSuc + 1), maxVentaSuc);


        // --- b) Promedio de ventas por año ---
        double[] promedioPorAnio = new double[M];
        double maxPromedioAnio = -1.0;
        int idxMaxAnio = -1;
        
        System.out.println("b) Promedio de ventas por año:");
        for (int i = 0; i < M; i++) {
            promedioPorAnio[i] = totalPorAnio[i] / N;
            System.out.printf("   Año %d: $%.2f%n", (i + 1), promedioPorAnio[i]);
            
            // --- c) Año con mayor promedio (se calcula aquí mismo) ---
            if (promedioPorAnio[i] > maxPromedioAnio) {
                maxPromedioAnio = promedioPorAnio[i];
                idxMaxAnio = i;
            }
        }
        
        System.out.printf("c) Año con mayor promedio de ventas: %d (Promedio: $%.2f)%n", (idxMaxAnio + 1), maxPromedioAnio);
    }
}

Notas rápidas

Puntos clave:

  • Este problema es un ejercicio clásico de procesamiento de matrices (arreglos 2D).
  • La matriz es ventas[M][N], donde M son las filas (años) y N son las columnas (sucursales).
  • Para el punto (a), se suman las columnas.
  • Para el punto (b), se suman las filas.
  • Es eficiente calcular los totales por año y por sucursal en el mismo bucle de lectura de datos.
Tip: Recuerda que los índices de los arreglos en Java empiezan en 0. Si el problema se refiere al "Año 1" o "Sucursal 1", deberás sumar 1 a tus variables de índice (i o j) al momento de imprimir los resultados.
Problema 5.3

Procesamiento de Información de Profesores

Programa para almacenar y procesar la información de N profesores ($1 \le N \le 200$) guardada en un arreglo de registros (clases en Java). Cada profesor tiene datos personales y un arreglo de 12 salarios mensuales.

Información Requerida

  • a) Número, nombre y nacionalidad del profesor que más ganó el año anterior.
  • b) Monto total pagado en el año a los profesores de un departamento "X" (dado por el usuario).
  • c) Monto total pagado a profesores extranjeros (nacionalidad distinta a "México").
  • d) Nombre del profesor del departamento "Y" (dado por el usuario) que más ganó en el año.

Ejemplo de uso esperado (Solución con Clases)

import java.util.Scanner;
import java.util.Locale;

// (Clase interna para simular el registro/struct)
class Profesor {
    int num;
    String nom;
    String dep;
    String grado;
    String nac;
    double[] salario = new double[12]; // Salario mensual

    // Constructor vacío
    public Profesor() {}

    // Método para calcular el salario anual total
    public double getSalarioAnual() {
        double total = 0;
        for (double s : salario) {
            total += s;
        }
        return total;
    }
}

public class Problema_5_3 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in).useLocale(Locale.US);

        System.out.println("Ingrese el número de profesores (N, max 200):");
        int N = sc.nextInt();
        sc.nextLine(); // Consumir el salto de línea

        if (N < 1 || N > 200) {
            System.out.println("Número fuera de rango.");
            return;
        }

        Profesor[] profesores = new Profesor[N];

        // --- Lectura de Datos ---
        for (int i = 0; i < N; i++) {
            profesores[i] = new Profesor();
            System.out.println("\n--- Profesor " + (i + 1) + " ---");
            System.out.print("Número de empleado: ");
            profesores[i].num = sc.nextInt();
            sc.nextLine(); // Consumir salto de línea
            
            System.out.print("Nombre: ");
            profesores[i].nom = sc.nextLine();
            
            System.out.print("Departamento: ");
            profesores[i].dep = sc.nextLine();
            
            System.out.print("Grado Académico: ");
            profesores[i].grado = sc.nextLine();
            
            System.out.print("Nacionalidad: ");
            profesores[i].nac = sc.nextLine();
            
            System.out.println("Ingrese los 12 salarios mensuales:");
            for (int j = 0; j < 12; j++) {
                System.out.print("  Mes " + (j + 1) + ": ");
                profesores[i].salario[j] = sc.nextDouble();
            }
            sc.nextLine(); // Consumir salto de línea
        }

        // Leer datos para los incisos b) y d)
        System.out.print("\nIngrese el departamento 'X' (para inciso b): ");
        String deptoX = sc.nextLine();
        System.out.print("Ingrese el departamento 'Y' (para inciso d): ");
        String deptoY = sc.nextLine();

        // --- Procesamiento de Datos ---
        double maxSalarioGlobal = -1.0;
        Profesor profMaxSalario = null;
        double totalDeptoX = 0.0;
        double totalExtranjeros = 0.0;
        double maxSalarioDeptoY = -1.0;
        String nomProfMaxDeptoY = "No encontrado";

        for (Profesor prof : profesores) {
            double salarioAnual = prof.getSalarioAnual();

            // a) Profesor con mayor salario anual
            if (salarioAnual > maxSalarioGlobal) {
                maxSalarioGlobal = salarioAnual;
                profMaxSalario = prof;
            }

            // b) Total pagado a depto X
            if (prof.dep.equalsIgnoreCase(deptoX)) {
                totalDeptoX += salarioAnual;
            }

            // c) Total pagado a extranjeros
            if (!prof.nac.equalsIgnoreCase("mexico") && !prof.nac.equalsIgnoreCase("mexicana")) {
                totalExtranjeros += salarioAnual;
            }

            // d) Profesor con mayor salario en depto Y
            if (prof.dep.equalsIgnoreCase(deptoY)) {
                if (salarioAnual > maxSalarioDeptoY) {
                    maxSalarioDeptoY = salarioAnual;
                    nomProfMaxDeptoY = prof.nom;
                }
            }
        }

        // --- Impresión de Resultados ---
        System.out.println("\n--- RESULTADOS DEL ANÁLISIS ---");
        
        // a)
        if (profMaxSalario != null) {
            System.out.println("a) Profesor con mayor ingreso anual:");
            System.out.printf("   Num: %d, Nombre: %s, Nac: %s (Total: $%.2f)%n",
                profMaxSalario.num, profMaxSalario.nom, profMaxSalario.nac, maxSalarioGlobal);
        }
        
        // b)
        System.out.printf("b) Total pagado a depto '%s': $%.2f%n", deptoX, totalDeptoX);
        
        // c)
        System.out.printf("c) Total pagado a profesores extranjeros: $%.2f%n", totalExtranjeros);
        
        // d)
        System.out.printf("d) Profesor con mayor ingreso en depto '%s': %s (Total: $%.2f)%n",
            deptoY, nomProfMaxDeptoY, maxSalarioDeptoY);
    }
}

Notas rápidas

Puntos clave:

  • La mejor forma de representar un "registro" en Java es usando una Clase (ej. class Profesor).

Estadísticas de Alumnos por Sexo

Programa que, para un número N de alumnos, procesa la matrícula, sexo, semestre y promedio de cada uno. Calcula el porcentaje y promedio de la población femenina, el porcentaje y promedio de la población masculina, y el promedio general.

Requisitos

  • Leer N (número de alumnos).
  • En un bucle for que se repita N veces, leer:
    • Matrícula (MAT, entero).
    • Sexo (SEX, entero: 0=Mujer, 1=Hombre).
    • Semestre (SEM, entero).
    • Promedio (PRO, real/double).

import java.util.Locale;

Calcular el producto de dos vectores

Programa que, dados dos vectores (arreglos unidimensionales) A y B de tipo entero y de tamaño N (con $1 \le N \le 50$), calcula el producto de dichos vectores. (Se asume que "producto" se refiere al producto punto o producto escalar).

Requisitos

  • Leer el tamaño N de los vectores ($1 \le N \le 50$).
  • Leer los N elementos del vector A.
  • Leer los N elementos del vector B.
  • Calcular el producto punto: $PROD = A_0 \times B_0 + A_1 \times B_1 + \dots + A_{N-1} \times B_{N-1}$.
  • Imprimir el resultado del producto punto.

Ejemplo de uso esperado

import java.util.Scanner;

public class PS_4_4 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.println("Ingrese el tamaño N de los vectores (max 50):");
        int N = sc.nextInt();

        if (N < 1 || N > 50) {
            System.out.println("Tamaño fuera de rango (1-50).");
            return;
        }

        int[] A = new int[N];
        int[] B = new int[N];

        // Leer Vector A
        System.out.println("--- Ingrese los elementos del Vector A ---");
        for (int i = 0; i < N; i++) {
            System.out.print("A[" + i + "]: ");
            A[i] = sc.nextInt();
        }

        // Leer Vector B
        System.out.println("--- Ingrese los elementos del Vector B ---");
        for (int i = 0; i < N; i++) {
            System.out.print("B[" + i + "]: ");
            B[i] = sc.nextInt();
        }

        // Calcular el producto punto
        // (Se usa long para evitar desbordamiento si los números son grandes)
        long productoPunto = 0; 
        
        for (int i = 0; i < N; i++) {
            productoPunto += (long)A[i] * B[i];
        }

        // --- Resultado ---
        System.out.println("\n---------------------------------");
        System.out.println("Vector A: " + java.util.Arrays.toString(A));
        System.out.println("Vector B: " + java.util.Arrays.toString(B));
        System.out.println("El producto punto (A · B) es: " + productoPunto);
    }
}

Notas rápidas

Puntos clave:

  • El "producto de vectores" más común en este contexto es el producto punto (escalar), que resulta en un solo número (un escalar).
  • El producto punto se calcula sumando los productos de los elementos en la misma posición: $A[i] \times B[i]$.
  • Se necesita un acumulador (productoPunto) inicializado en 0.
  • Los arreglos en Java tienen índices de 0 a N-1, a diferencia del pseudocódigo que usa 1 a N.
Tip: Es buena idea usar un tipo long para el acumulador del producto, ya que la suma de los productos (ej. $50 \times 10000 \times 10000$) podría exceder el límite de un int.
PS 4.20

Asignar valores a Matriz A(MxN) desde Vector B(N)

Programa que asigna valores a una matriz A (de M x N) a partir de un vector B (de N elementos), usando los siguientes criterios:
a) A[i, j] = B[j] si i <= j
b) A[i, j] = 0 si i > j

Requisitos

  • Leer M (filas, $1 \le M \le 30$) y N (columnas, $1 \le N \le 20$).
  • Leer el vector B de N elementos de tipo real.
  • Crear la matriz A de M x N.
  • Iterar sobre la matriz A (fila i de 0 a M-1, columna j de 0 a N-1).
  • Aplicar la condición (usando índices 0-based):
    • Si i <= j, asignar A[i][j] = B[j].
    • Si i > j, asignar A[i][j] = 0.
  • Imprimir la matriz A resultante.

Ejemplo de uso esperado

import java.util.Scanner;
import java.util.Locale;
import java.util.Arrays;

public class PS_4_20 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in).useLocale(Locale.US);

        System.out.println("Ingrese el número de filas M (max 30):");
        int M = sc.nextInt();
        System.out.println("Ingrese el número de columnas N (max 20):");
        int N = sc.nextInt();

        if (M < 1 || M > 30 || N < 1 || N > 20) {
            System.out.println("Dimensiones fuera de rango.");
            return;
        }

        double[] B = new double[N];
        double[][] A = new double[M][N];

        // Leer Vector B
        System.out.println("--- Ingrese los " + N + " elementos del Vector B ---");
        for (int j = 0; j < N; j++) {
            System.out.print("B[" + j + "]: ");
            B[j] = sc.nextDouble();
        }

        System.out.println("\nVector B: " + Arrays.toString(B));

        // Asignar valores a la Matriz A
        for (int i = 0; i < M; i++) { // i = fila
            for (int j = 0; j < N; j++) { // j = columna
                
                // Aplicar criterios (en índices 0-based de Java)
                if (i <= j) {
                    A[i][j] = B[j];
                } else { // i > j
                    A[i][j] = 0.0;
                }
            }
        }

        // --- Imprimir Matriz A Resultante ---
        System.out.println("\n--- Matriz A Resultante ---");
        for (int i = 0; i < M; i++) {
            // Imprimir la fila i
            System.out.println(Arrays.toString(A[i]));
        }
    }
}

Notas rápidas

Puntos clave:

  • Este problema genera una matriz triangular superior "modificada", donde los valores de la diagonal principal y superiores se toman del vector B.
  • El pseudocódigo (1-based) i <= j se traduce directamente a i <= j en Java (0-based).
  • Nota sobre el problema: El texto original dice A[i,j] = B[i]. Esto parece un error tipográfico, ya que i (filas) puede llegar hasta M (30) pero B solo tiene N (max 20) elementos. La solución implementa A[i,j] = B[j], que es lógicamente consistente.
Tip: La condición i > j define la parte "triangular inferior" de la matriz (debajo de la diagonal principal), la cual se llena de ceros.
PS 4.36

Actualización de Inventario de Tienda

Programa para administrar el inventario de una tienda (N <= 100 productos). Se leen dos arreglos: PRODUCTO[N] (claves de producto, ordenado) y CANTIDAD[N] (existencias). Luego, se procesan transacciones de compra ('C') o venta ('V') hasta recibir una entrada 'X', 0, 0.

Requisitos

  • Leer N (número de productos).
  • Leer el arreglo PRODUCTO (claves, N enteros) y CANTIDAD (existencias, N enteros).
  • Implementar un bucle while para leer transacciones (CLAOP, CLAPRO, CANT).
  • El bucle termina si CLAOP es 'X'.
  • Para cada transacción:
    • Buscar la clave CLAPRO en el arreglo PRODUCTO. (Se recomienda búsqueda binaria ya que está ordenado).
    • Si CLAOP == 'C' (Compra): Incrementar CANTIDAD[j] en CANT.
    • Si CLAOP == 'V' (Venta):
      • Verificar si CANTIDAD[j] >= CANT.
      • Si es verdadero, restar CANT de CANTIDAD[j].
      • Si es falso, imprimir un mensaje (ej. "Stock insuficiente").
  • Al final, imprimir los arreglos PRODUCTO y CANTIDAD actualizados.

Ejemplo de uso esperado (con Búsqueda Binaria)

import java.util.Scanner;
import java.util.Arrays; // Para Arrays.binarySearch y Arrays.toString

public class PS_4_36 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.println("Ingrese el número de productos (N <= 100):");
        int N = sc.nextInt();
        sc.nextLine(); // Consumir salto

        if (N < 1 || N > 100) {
            System.out.println("Número fuera de rango.");
            return;
        }

        int[] PRODUCTO = new int[N];
        int[] CANTIDAD = new int[N];

        System.out.println("--- Lectura de Claves de Producto (deben estar ordenadas) ---");
        for (int i = 0; i < N; i++) {
            System.out.print("Clave Producto " + (i + 1) + ": ");
            PRODUCTO[i] = sc.nextInt();
        }

        System.out.println("--- Lectura de Cantidades en Existencia ---");
        for (int i = 0; i < N; i++) {
            System.out.print("Cantidad para " + PRODUCTO[i] + ": ");
            CANTIDAD[i] = sc.nextInt();
        }
        sc.nextLine(); // Consumir salto

        System.out.println("\n--- INICIO DE TRANSACCIONES (Tipo 'X' para terminar) ---");

        System.out.print("Tipo de Operación ('C' Compra, 'V' Venta): ");
        String CLAOP_str = sc.nextLine().toUpperCase();

        while (!CLAOP_str.equals("X")) {
            char CLAOP = CLAOP_str.charAt(0);
            
            System.out.print("Clave del Producto: ");
            int CLAPRO = sc.nextInt();
            
            System.out.print("Cantidad de la transacción: ");
            int CANT = sc.nextInt();
            sc.nextLine(); // Consumir salto

            // Buscar el índice del producto usando Búsqueda Binaria
            int indice = Arrays.binarySearch(PRODUCTO, CLAPRO);

            if (indice < 0) {
                System.out.println("ERROR: Clave de producto " + CLAPRO + " no encontrada.");
            } else {
                switch (CLAOP) {
                    case 'C':
                        CANTIDAD[indice] += CANT;
                        System.out.println("COMPRA registrada. Nuevo stock " + PRODUCTO[indice] + ": " + CANTIDAD[indice]);
                        break;
                    case 'V':
                        if (CANTIDAD[indice] >= CANT) {
                            CANTIDAD[indice] -= CANT;
                            System.out.println("VENTA registrada. Nuevo stock " + PRODUCTO[indice] + ": " + CANTIDAD[indice]);
                        } else {
                            System.out.println("ERROR: Stock insuficiente para " + PRODUCTO[indice]);
                            System.out.println("  (Se requieren " + CANT + ", solo hay " + CANTIDAD[indice] + ")");
                        }
                        break;
                    default:
                        System.out.println("ERROR: Tipo de operación '" + CLAOP + "' no válido.");
                }
            }
            
            System.out.print("\nTipo de Operación ('C' Compra, 'V' Venta): ");
            CLAOP_str = sc.nextLine().toUpperCase();
        }

        System.out.println("\n--- INVENTARIO FINAL ACTUALIZADO ---");
        System.out.println("Claves:   " + Arrays.toString(PRODUCTO));
        System.out.println("Cantidad: " + Arrays.toString(CANTIDAD));
    }
}

Notas rápidas

Puntos clave:

  • El problema PS 4.36 define los arreglos PRODUCTO y CANTIDAD que se usan en el PS 4.57.
  • El hecho de que PRODUCTO esté ordenado es la clave. Permite usar Arrays.binarySearch() en Java.
  • Arrays.binarySearch() devuelve el índice si lo encuentra, o un número negativo si no.
  • Se necesita un bucle while que se detenga con un valor centinela ('X').
  • Dentro del bucle, se usa switch (o if-else) para manejar los casos 'C' y 'V'.
  • Es crucial validar la existencia (stock) en el caso 'V'.
Tip: Si Arrays.binarySearch() no estuviera permitido, tendrías que implementar tu propio algoritmo de búsqueda binaria (o una búsqueda lineal, aunque sería menos eficiente) para encontrar el índice j tal que PRODUCTO[j] == CLAPRO.
