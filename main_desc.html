Ejercicio 1.5

Prueba de Escritorio (Traza de Memoria)

Este es un ejercicio fundamental de "lápiz y papel". El objetivo es simular lo que hace la computadora paso a paso para entender cómo cambian los valores de las variables en la memoria.

Requisitos

Toma el código del ejercicio 1.5 y realiza lo siguiente (no necesitas programar):

  • Crea una tabla en una hoja de papel con columnas para cada variable: `I`, `J`, `ACUM`, `REA`, `SUM`, `CAR`, `BAND`.
  • Sigue la secuencia de 14 asignaciones, una por una.
  • Para cada paso, calcula el resultado de la derecha y anota el nuevo valor en la celda correspondiente de tu tabla.
  • Presta mucha atención a los tipos de datos: `div` es división entera (sin decimales), mientras que `/` es división real.
  • Evalúa las condiciones lógicas (`y`, `o`) para obtener `VERDADERO` o `FALSO`.
  • Identifica las líneas (13 y 14) que causan un error de tipo.

Ejemplo de seguimiento

Estado Inicial: I=indef, J=indef, ACUM=indef, REA=indef, SUM=indef, CAR=indef, BAND=indef

Paso 1. I <-- 0
   (I se vuelve 0. Valor actual en memoria: I=0)

Paso 2. I <-- I + 1
   (Usa I=0. 0 + 1 = 1. I se vuelve 1. Valor actual: I=1)

Paso 3. ACUM <-- 0
   (ACUM se vuelve 0. Valor actual: ACUM=0)

Paso 4. J <-- 5 ** 2 div 3
   (5^2 = 25. 25 div 3 = 8 (división entera). J se vuelve 8. Valor actual: J=8)

Paso 5. CAR <-- 'a'
   (CAR se vuelve 'a'. Valor actual: CAR='a')

Paso 6. ACUM <-- J div I
   (Usa J=8, I=1. 8 div 1 = 8. ACUM se vuelve 8. Valor actual: ACUM=8)

Paso 7. REA <-- ACUM / 3
   (Usa ACUM=8. 8 / 3 = 2.666... (división real). REA se vuelve 2.66... Valor actual: REA=2.66...)
   (Nota: La tabla del libro lo trunca a 2.66)

Paso 8. BAND <-- (8 > 5) y (15 < 2 ** 3)
   (P1: 8>5 es VERDADERO. P2: 2^3=8. 15<8 es FALSO. VERDADERO y FALSO = FALSO. BAND se vuelve FALSO)

Paso 9. SUM <-- ACUM * 5 / J ** 2
   (Usa ACUM=8, J=8. (8 * 5) / (8^2) = 40 / 64 = 0.625. SUM se vuelve 0.625)

Paso 10. I <-- I * 3
   (Usa I=1. 1 * 3 = 3. I se vuelve 3. Valor actual: I=3)

Paso 11. REA <-- REA / 5
   (Usa el valor de REA del paso 7. La tabla del libro usa el valor truncado 2.66. 2.66 / 5 = 0.532. REA se vuelve 0.532)

Paso 12. BAND <-- BAND o (I = J)
   (Usa BAND=FALSO, I=3, J=8. P2: (3=8) es FALSO. FALSO o FALSO = FALSO. BAND se vuelve FALSO)

Paso 13. I <-- REA
   (Usa REA=0.532. Se intenta asignar un 'real' (0.532) a un 'entero' (I). Esto es un Error de Tipo)

Paso 14. CAR <-- J
   (Usa J=8. Se intenta asignar un 'entero' (8) a un 'caracter' (CAR). Esto es un Error de Tipo)

Notas rápidas

  • El operador `**` significa potencia.
  • `div` es **división entera** (cuántas veces cabe, sin residuo).
  • `/` es **división real** (con decimales).
  • `y` (AND) solo es `VERDADERO` si ambas partes son `VERDADERO`.
  • `o` (OR) es `VERDADERO` si al menos una parte es `VERDADERO`.
Tip: Puedes crear un programa en Java (`TrazaMemoria.java`) e imprimir las variables después de cada paso. ¡Esto te ayudará a verificar tu traza manual!
Problema 1.6

Segundos en Días

Este es tu primer programa completo con la estructura **Entrada-Proceso-Salida**. Aprenderás a pedir un dato al usuario, realizar un cálculo simple y mostrar un resultado formateado.

Requisitos

Crea un programa llamado `SegundosEnDias.java` que haga lo siguiente:

  • Importa la herramienta `Scanner` para leer la entrada del teclado: `import java.util.Scanner;`
  • Crea un objeto `Scanner`: `Scanner scanner = new Scanner(System.in);`
  • Pide al usuario que ingrese un número de días (ej. "Introduce el número de días: ").
  • Lee el número y guárdalo en una variable entera: `int dias = scanner.nextInt();`
  • Calcula los segundos en una variable `double` (para números grandes): `double seg = dias * 24 * 60 * 60;`
  • Imprime el resultado de forma clara.

Ejemplo de uso esperado

Introduce el número de días: 3
En 3 días, hay 259200.0 segundos.

Notas rápidas

  • `Scanner` es la herramienta estándar de Java para leer la entrada de la consola.
  • `System.out.print()` imprime un mensaje sin saltar de línea.
  • `scanner.nextInt()` lee el siguiente número entero que el usuario teclee.
  • Usamos `double` para el resultado porque `int` podría quedarse sin espacio si el número de días es muy grande (esto se llama *overflow*).
Tip: Puedes usar `System.out.printf("En %d días, hay %.0f segundos.\n", dias, seg);` para mostrar el resultado sin decimales (`.0f`).
Problema 2.1

El Grillo como Termómetro

Aquí introduces la estructura de control más importante: la **selección**. Aprenderás a usar la sentencia `if` para tomar decisiones y ejecutar código solo si se cumple una condición específica.

Requisitos

Crea un programa `GrilloTemperatura.java` que:

  • Pida al usuario el número de sonidos por minuto (`int N`).
  • Utilice una sentencia `if` para verificar si `N` es mayor que 0: `if (N > 0) { ... }`
  • **Dentro del 'if'**, calcula la temperatura: `double T = (double)N / 4 + 40;`
  • **Dentro del 'if'**, imprime la temperatura calculada.
  • Si el usuario ingresa 0 o un número negativo, el programa no debe imprimir nada y simplemente terminar.

Ejemplo de uso esperado

Introduce el número de sonidos por minuto (N): 15
La temperatura es: 43.75 grados Fahrenheit.

--- (Si se ejecuta de nuevo) ---
Introduce el número de sonidos por minuto (N): -5
(El programa termina sin imprimir nada)

Notas rápidas

  • El rombo (`< >`) en un diagrama de flujo siempre se traduce como un `if` en Java.
  • La condición se escribe entre paréntesis: `if (N > 0)`.
  • El código que depende de la condición va entre llaves `{ ... }`.
¡Cuidado con la división entera! Si escribes `N / 4`, Java (siendo `N` un `int`) descartará los decimales. Debes forzar una división real usando `(double)N / 4`.
Ejemplo 3.3

Contar Ceros

Este ejercicio introduce tu primera **estructura repetitiva** (bucle). Aprenderás a usar el bucle `for` para repetir un bloque de código un número de veces que el usuario decida.

Requisitos

Crea un programa `ContarCeros.java` que:

  • Primero, pregunte al usuario cuántos números va a ingresar. Guarda este límite en una variable `int N`.
  • Antes de empezar a contar, inicializa un **contador** en cero: `int CUECER = 0;`
  • Crea un bucle `for` que se ejecute `N` veces. La sintaxis es: `for (int i = 1; i <= N; i++) { ... }`
  • **Dentro del bucle**, pide al usuario que ingrese un número (`int NUM`).
  • **Dentro del bucle**, usa un `if (NUM == 0)` para verificar si el número es cero.
  • Si lo es, incrementa tu contador: `CUECER = CUECER + 1;` (o `CUECER++;`).
  • **Después de que el bucle termine**, imprime el valor final del contador `CUECER`.

Ejemplo de uso esperado

¿Cuántos números enteros vas a ingresar?: 5
Ingresa el número 1: 28
Ingresa el número 2: 0
Ingresa el número 3: -15
Ingresa el número 4: 0
Ingresa el número 5: 100
-------------------------------------------
El número total de 'ceros' ingresados fue: 2

Notas rápidas

  • Un **contador** es una variable que se usa para llevar la cuenta de algo. Siempre debe inicializarse en 0.
  • Un bucle `for` es perfecto cuando sabes de antemano cuántas veces quieres que se repita el código.
  • `i++` es un atajo para `i = i + 1`.
Tip: El `System.out.println(CUECER)` debe ir *fuera* y *después* del bucle `for`. Si lo pones dentro, imprimirás el conteo en cada paso.
Problema 3.14

Taquilla del Estadio

Este problema combina bucles y condicionales. Aprenderás a usar el bucle `while` para procesar un número *indeterminado* de datos, deteniéndote con un **valor centinela**.

Requisitos

Crea un programa `EstadioPrecios.java` que:

  • Declare e inicialice en 0 todos los **acumuladores**: `AP1`...`AP5` (para boletos) y `RECAU` (para el dinero).
  • Pida al usuario que ingrese los 5 precios (`P1`...`P5`).
  • Pida la `CLAVE` y `CANT` de la primera venta. (Esto se llama "lectura cebadora").
  • Inicie un bucle `while` que se repita mientras la `CLAVE` sea diferente de -1: `while (CLAVE != -1) { ... }`
  • **Dentro del bucle**, usa un `switch (CLAVE)` para determinar qué precio usar (`P1`...`P5`) y qué acumulador (`AP1`...`AP5`) incrementar.
  • Calcula el precio de esa venta (`PRE`) e incremente la recaudación total: `RECAU = RECAU + PRE;`.
  • **Al final del bucle**, vuelve a pedir la `CLAVE` y `CANT` para la siguiente venta.
  • **Después del bucle**, imprime el reporte final con los totales de `AP1`...`AP5` y `RECAU`.

Ejemplo de uso esperado

Ingrese los 5 precios...
P1: 100
...
P5: 50
--- Ingrese la primera venta ---
Clave del boleto (1-5) o -1 para terminar: 2
Cantidad de boletos: 3
Venta procesada: Clave 2, Cant 3, Importe $...
--- Siguiente Venta ---
Clave del boleto (1-5) o -1 para terminar: -1
--- FIN DE VENTAS ---
--- REPORTE FINAL ---
CANTIDAD BOLETOS TIPO 1: 0
CANTIDAD BOLETOS TIPO 2: 3
...
RECAUDACION TOTAL DEL ESTADIO: $...

Notas rápidas

  • Un **valor centinela** (como -1) es una señal para que un bucle `while` sepa cuándo detenerse.
  • Un **acumulador** es una variable que "suma" valores, no solo cuenta de 1 en 1.
  • Un `switch` es una forma limpia de manejar múltiples `if` basados en el valor de una sola variable.
Tip: El patrón de "leer antes del bucle" y "volver a leer al final del bucle" es fundamental para los bucles `while` controlados por centinela.
Problema 4.1

Lista Sin Repeticiones

Introduce las **estructuras de datos: arreglos (arrays)**. Aprenderás a declarar un arreglo, llenarlo con datos y procesarlo usando **bucles anidados** (un bucle dentro de otro).

Requisitos

Crea un programa `ListaSinRepeticiones.java` que:

  • Pida al usuario el tamaño del arreglo (`int N`).
  • Cree el arreglo: `int[] VEC = new int[N];`
  • Llene el arreglo usando un bucle `for` (de `i = 0` hasta `N-1`).
  • Imprima el encabezado "Lista de números sin repeticiones".
  • Use un bucle `while` para recorrer el arreglo (con un índice `I = 0`).
  • **Dentro del `while`**:
    1. Imprime el valor actual: `System.out.println(VEC[I]);`
    2. Guarda ese valor: `int REPET = VEC[I];`
    3. Inicia un **bucle anidado**: `while (I < N && REPET == VEC[I]) { ... }`
    4. Lo único dentro del bucle anidado es: `I++;`. Esto "saltará" todos los duplicados.

Ejemplo de uso esperado

Ingresa número de elementos: 7
Ingrese valor 1: 5
Ingrese valor 2: 5
Ingrese valor 3: 5
Ingrese valor 4: 8
Ingrese valor 5: 9
Ingrese valor 6: 9
Ingrese valor 7: 10

--- Lista de números sin repeticiones ---
5
8
9
10

Notas rápidas

  • Los arreglos en Java y muchos lenguajes usan **índice base 0**. El primer elemento está en `VEC[0]`, el segundo en `VEC[1]`, etc.
  • El último elemento está en `VEC[N-1]`.
  • Un bucle anidado es un bucle que se ejecuta completamente dentro de una iteración de otro bucle.
Tip: El algoritmo funciona porque el arreglo está ordenado. El bucle externo imprime un número, y el bucle interno avanza el índice `I` hasta que encuentra un número *diferente*.
Problema 4.14

Producción por Departamentos

Introduce los **arreglos bidimensionales (matrices)**. Aprenderás a almacenar y procesar datos en una cuadrícula (filas y columnas) para responder preguntas analíticas.

Requisitos

Crea un programa `ProduccionDepartamentos.java` que:

  • Declare una matriz de 12x3: `double[][] prod = new double[12][3];` (12 meses, 3 deptos).
  • Use bucles anidados (`for i...` y `for j...`) para llenar la matriz con 36 datos.
  • **Inciso a):** Use un bucle `for` (de `i = 0` a 11) para recorrer la **columna 0** (`prod[i][0]`) y encontrar el costo más alto (`MAYDUL`) y el mes (`MES`) en que ocurrió.
  • **Inciso b):** Use un bucle `for` (de `i = 0` a 11) para sumar todos los valores de la **columna 1** (`prod[i][1]`) y calcular el promedio.
  • **Inciso c):** Combine la lógica del inciso 'a' para encontrar el máximo y el mínimo de la **columna 1** (`prod[i][1]`) y sus respectivos meses.
  • **Inciso d):** Use un bucle `for` (de `j = 0` a 2) para recorrer la **fila 11** (`prod[11][j]`) y encontrar el costo más bajo (`MENOR`) y el depto (`DEP`) en que ocurrió.

Ejemplo de uso esperado

--- Ingrese los costos de producción ---
Mes 1, Depto 1: 100
Mes 1, Depto 2: 150
...
Mes 12, Depto 3: 200

--- Resultados del Análisis ---
En el mes 5, se registró el mayor costo de producción de dulces.
Promedio anual de costos de producción de bebidas: 180.50
En el mes 8, se registró el mayor costo de ... y en el mes 2, el menor costo.
El departamento 3 tuvo el menor costo en diciembre.

Notas rápidas

  • Una matriz se declara como `tipo[][] nombre;`.
  • Se accede a un elemento con `nombre[fila][columna]`.
  • En Java, las filas y columnas empiezan en el índice 0.
  • Recorrer una **columna** significa mantener la `j` fija y mover la `i`.
  • Recorrer una **fila** significa mantener la `i` fija y mover la `j`.
Tip: Ten cuidado con los índices. El mes "Enero" (mes 1) es la fila `[0]`. El "Depto 1" es la columna `[0]`. "Diciembre" (mes 12) es la fila `[11]`.
Problema 5.2

Gestión de Empleados (Registros)

Este es un ejercicio avanzado que introduce los **Arreglos de Registros**. En Java, esto se implementa creando una **Clase** (un molde) y luego creando un **Arreglo de Objetos** de esa clase.

Requisitos

  1. Crea una **clase `Empleado`** (en el mismo archivo o en uno nuevo) que sirva como "registro". Debe tener los atributos: `int numero;`, `String nombre;`, `double salario;`, `double[] ventas;`.
  2. En el constructor de la clase `Empleado`, inicializa el arreglo: `ventas = new double[12];`
  3. En tu programa principal (`EmpleadosTienda.java`), crea un arreglo de estos objetos: `Empleado[] empleados = new Empleado[N];`
  4. Usa un bucle (`for i...`) para llenar el arreglo. ¡Recuerda crear el objeto en cada posición: `empleados[i] = new Empleado();`!
  5. Dentro de ese bucle, usa un **bucle anidado** (`for j...`) para leer las 12 ventas de `empleados[i].ventas[j]`.
  6. Crea un menú con un bucle `do-while` y un `switch` para las opciones (1, 2, 3, 4).
  7. Implementa la lógica para cada inciso (Venta Máxima, Incremento, Ventas Mínimas) recorriendo el arreglo de empleados.

Ejemplo de uso esperado

Ingrese número de empleados: 2
--- Datos del Empleado 1 ---
Número: 10
Nombre: Ana
...
--- MENÚ DE OPCIONES ---
(1) Empleado con mayor venta
...
(4) Terminar
Elija una opción: 1

--- Empleado con Mayores Ventas ---
Nombre: Ana
Número de empleado: 10
...
Elija una opción: 4

Notas rápidas

  • Un **Registro** (en pseudocódigo) es una **Clase** (en Java).
  • Un **Objeto** es una instancia de una Clase.
  • `empleados[i]` te da el objeto `Empleado` en la posición `i`.
  • `empleados[i].nombre` te da el nombre de ese empleado.
  • `empleados[i].ventas[j]` te da la venta del mes `j` del empleado `i`.
Tip: Es una excelente práctica separar la lógica de cada inciso del menú en su propia **función** (método estático). Por ejemplo: `public static void encontrarVentaMaxima(Empleado[] empleados) { ... }`
Problema PS 2.1

Calcular Tangente

Este ejercicio refuerza el uso de la estructura `if-else` para la **validación de datos**. Aprenderás a prevenir un error matemático común: la división por cero.

Requisitos

Crea un programa `CalcularTangente.java` que:

  • Pida al usuario dos valores: `double seno` y `double coseno`.
  • Verifique si el coseno es diferente de cero: `if (coseno != 0) { ... }`
  • **Si es diferente de 0**, calcula la tangente: `double tangente = seno / coseno;` e imprime el resultado.
  • **Si es igual a 0**, usa un bloque `else` para imprimir un mensaje de error: `else { System.out.println("Error: El coseno es 0..."); }`

Ejemplo de uso esperado

Ingrese el valor del Seno: 0.866
Ingrese el valor del Coseno: 0.5
La tangente es: 1.7320

--- (Si se ejecuta de nuevo) ---
Ingrese el valor del Seno: 1.0
Ingrese el valor del Coseno: 0
Error: El coseno es 0.
La tangente no está definida (división por cero).

Notas rápidas

  • `!=` significa "diferente de".
  • `==` significa "igual a".
  • La estructura `if-else` es perfecta para manejar dos caminos mutuamente excluyentes (un cálculo exitoso o un error).
Tip: Esto se llama "programación defensiva". Anticipas los errores (como la división por cero) y los manejas antes de que rompan tu programa.
Problema PS 2.2

Calcular Cotangente

Similar al ejercicio anterior, este problema refuerza la validación de datos con `if-else`, pero esta vez debes validar una variable diferente (el seno) para la fórmula de la cotangente.

Requisitos

Crea un programa `CalcularCotangente.java` que:

  • Pida al usuario `double seno` y `double coseno`.
  • Verifique si el **seno** es diferente de cero: `if (seno != 0) { ... }`
  • **Si es diferente de 0**, calcula la cotangente: `double cotangente = coseno / seno;` e imprime el resultado.
  • **Si es igual a 0**, usa un bloque `else` para imprimir un mensaje de error.

Ejemplo de uso esperado

Ingrese el valor del Seno: 0.5
Ingrese el valor del Coseno: 0.866
La cotangente es: 1.7320

--- (Si se ejecuta de nuevo) ---
Ingrese el valor del Seno: 0
Ingrese el valor del Coseno: 1.0
Error: El seno es 0.
La cotangente no está definida (división por cero).

Notas rápidas

  • La lógica es idéntica al ejercicio de la tangente, pero el denominador ha cambiado.
  • El objetivo es que aprendas a identificar qué variable *específica* necesitas validar en una fórmula.
Tip: Siempre analiza tus fórmulas. Cualquier variable que esté en un denominador (dividiendo) es un candidato para una validación con `if`.
Problema PS 3.23

Promedio de Alumnos (con Ciclo)

Este ejercicio te enseña a usar **bucles anidados** (un `for` dentro de otro `for`) para procesar datos de forma estructurada. Calcularás el promedio de 35 alumnos, leyendo sus 5 calificaciones una por una.

Requisitos

Crea un programa `PromediosAlumnosCiclo.java` que:

  • Cree un bucle `for` externo que se repita 35 veces (para los alumnos).
  • **Dentro del bucle de alumnos**:
    1. Pide la matrícula del alumno.
    2. Inicializa un acumulador: `double suma = 0;`
    3. Crea un bucle `for` **interno** que se repita 5 veces (para las calificaciones).
    4. **Dentro del bucle interno**: Pide la calificación y súmala al acumulador: `suma = suma + calificacion;`
    5. **Después del bucle interno**, calcula el promedio: `double promedio = suma / 5;`
    6. Imprime la matrícula y el promedio de *ese* alumno.

Ejemplo de uso esperado

Ingrese la matrícula del alumno 1: 1001
Ingrese las 5 calificaciones del alumno 1001:
  Calificación 1: 80
  Calificación 2: 90
  Calificación 3: 100
  Calificación 4: 70
  Calificación 5: 80
-> El promedio del alumno 1001 es: 84.00

Ingrese la matrícula del alumno 2: 1002
... (y así 35 veces)

Notas rápidas

  • El bucle externo maneja a los "alumnos".
  • El bucle interno maneja las "calificaciones".
  • El acumulador `suma` **debe reiniciarse a 0** por cada nuevo alumno (al inicio del bucle externo).
Tip: Usar bucles anidados es mucho más eficiente que declarar 5 variables (`cal1`, `cal2`...). Si te pidieran 100 calificaciones, solo cambiarías el límite del bucle interno.
Problema PS 3.24

Mejor y Peor Promedio

Este ejercicio se basa en el anterior (PS 3.23), pero añade el algoritmo de **búsqueda de máximo y mínimo**. Aprenderás a "recordar" el mejor y peor valor mientras recorres una lista de datos.

Requisitos

Crea un programa `PromedioMaxMin.java` que:

  • **Antes del bucle** de 35 alumnos, inicializa 4 variables:
    • `double mejorProm = -1.0;` (un valor muy bajo)
    • `int matMejor = 0;`
    • `double peorProm = 101.0;` (un valor muy alto)
    • `int matPeor = 0;`
  • Usa la misma estructura de bucles anidados del PS 3.23 para calcular el `promedio` de cada alumno.
  • **Dentro del bucle de alumnos** (después de calcular el promedio):
    1. Compara con el máximo: `if (promedio > mejorProm) { ... }`
    2. Si es un nuevo máximo, actualiza `mejorProm = promedio;` y `matMejor = matricula;`.
    3. Compara con el mínimo: `if (promedio < peorProm) { ... }`
    4. Si es un nuevo mínimo, actualiza `peorProm = promedio;` y `matPeor = matricula;`.
  • **Después de que el bucle de 35 alumnos termine**, imprime los valores finales de `matMejor`, `mejorProm`, `matPeor` y `peorProm`.

Ejemplo de uso esperado

(El programa pide los datos de los 35 alumnos...)

-> Promedio del alumno 1001: 84.00
...
-> Promedio del alumno 1035: 91.00

--- Procesamiento Terminado ---
--- RESULTADOS FINALES ---
Mejor Alumno: Matrícula 1035 con Promedio 91.00
Peor Alumno:  Matrícula 1001 con Promedio 84.00

Notas rápidas

  • Este algoritmo compara el valor *actual* con el "campeón" guardado.
  • Si el actual es mejor, se convierte en el nuevo "campeón".
  • Inicializar los "campeones" con valores centinela (`-1` y `101`) asegura que el primer alumno real siempre gane.
Tip: La impresión de los resultados finales debe estar *fuera* del bucle principal. Solo quieres imprimir el resultado una vez al final.
Problema PS 3.25

Aptitudes para Básquetbol

Este problema combina varias habilidades: un bucle `while` controlado por **centinela**, múltiples contadores, y condiciones lógicas complejas usando el operador **Y** (`&&`).

Requisitos

Crea un programa `AptitudesBasquet.java` que:

  • Inicialice 4 contadores en 0: `totalMujeres`, `aptasMujeres`, `totalHombres`, `aptosHombres`.

    1. Pide `SEXO`, `EDAD`, `PESO`, `ALTURA`.
    2. Usa un `if (sexo == 'F')`... `else if (sexo == 'M')` para separar la lógica.
    3. **Si es 'F'**: incrementa `totalMujeres`. Luego, con un `if` anidado, revisa la condición (a): `if (altura >= 1.73 && peso <= 90)` e incrementa `aptasMujeres`.
    4. **Si es 'M'**: incrementa `totalHombres`. Luego, con un `if` anidado, revisa la condición (c): `if (altura >= 1.83 && peso <= 110)` e incrementa `aptosHombres`.
    5. **Al final del bucle**, vuelve a pedir el `nombre` para la siguiente iteración.
  • **Después del bucle**, calcula los porcentajes (b) y (d).

Notas rápidas

  • El operador "Y" en Java se escribe `&&`.
  • `if (condicion1 && condicion2)`: Ambas deben ser verdaderas.

Problema PS 4.3

Contar Positivos, Negativos y Nulos

Un ejercicio clásico de procesamiento de arreglos. Aprenderás a "barrer" un arreglo y clasificar cada elemento usando contadores y una estructura `if-else if-else`.

Requisitos

Crea un programa `ContarNumerosArreglo.java` que:

  • Pida al usuario el tamaño del arreglo (`int N`), validando que sea menor o igual a 300.
  • Inicialice 3 contadores en 0: `cpos`, `cneg`, `cnul`.
  • Cree el arreglo: `int[] ARRE = new int[N];`
  • Cree un **único bucle `for`** (de `i = 0` a `N-1`) que haga dos cosas:
    1. Pida el número y lo guarde en el arreglo: `ARRE[i] = scanner.nextInt();`
    2. Inmediatamente, clasifique ese número:
      • `if (ARRE[i] > 0) { cpos++; }`
      • `else if (ARRE[i] < 0) { cneg++; }`
      • `else { cnul++; }`
  • **Después del bucle**, imprima los 3 contadores.

Ejemplo de uso esperado

¿Cuántos números va a ingresar? (Máx. 300): 4
Ingrese los 4 números enteros:
Número 1: 10
Número 2: -5
Número 3: 0
Número 4: -2

--- Conteo Final ---
Números Positivos: 1
Números Negativos: 2
Números Nulos (cero): 1

Notas rápidas

  • La estructura `if-else if-else` es perfecta para clasificar algo en 3 o más categorías mutuamente excluyentes.
  • Es más eficiente llenar y procesar el arreglo en el mismo bucle (si es posible) que recorrerlo dos veces.
Tip: El bloque `else` final no necesita condición. Si el número no es `> 0` y no es `< 0`, lógicamente la única opción que queda es que sea `== 0`.
Problema PS 4.19

Análisis de Calificaciones (Matriz)

Un ejercicio completo de **procesamiento de matrices**. Aprenderás a recorrer una matriz por filas (para promedios de alumnos) y por columnas (para promedios de exámenes).

Requisitos

Crea un programa `CalificacionesGrupo.java` que:

  • Declare una matriz de 30x6: `double[][] calificaciones = new double[30][6];`
  • Use bucles anidados (`for i...` y `for j...`) para llenar la matriz.
  • **Inciso (a) y (c):** Promedio por Examen (recorrido por columnas).
    • Crea un bucle `for j...` (externo, para columnas/exámenes).
    • **Dentro**, inicializa `sumaExamen = 0;`.
    • Crea un bucle `for i...` (interno, para filas/alumnos).
    • Acumula `sumaExamen += calificaciones[i][j];`
    • Calcula e imprime el `promedioExamen`.
    • Compara este promedio con `mejorPromedioExamen` para resolver el inciso (c).
  • **Inciso (b):** Promedio por Alumno (recorrido por filas).
    • Crea un bucle `for i...` (externo, para filas/alumnos).
    • **Dentro**, inicializa `sumaAlumno = 0;`.
    • Crea un bucle `for j...` (interno, para columnas/exámenes).
    • Acumula `sumaAlumno += calificaciones[i][j];`
    • Calcula e imprime el `promedioAlumno`.

Ejemplo de uso esperado

(Pide las 180 calificaciones...)

--- Procesamiento de Datos ---

a) Promedio de calificaciones por examen:
   Promedio Examen 1: 85.30
   ...
   Promedio Examen 6: 79.50

b) Promedio de calificaciones por alumno:
   Promedio Alumno 1: 82.50
   ...
   Promedio Alumno 30: 88.00

c) Examen con el mayor promedio:
   El Examen 1 tuvo el mayor promedio: 85.30

Notas rápidas

  • Para recorrer **por columnas** (inciso a), el bucle de las columnas (`j`) va por fuera.
  • Para recorrer **por filas** (inciso b), el bucle de las filas (`i`) va por fuera.
  • `[i][j]` siempre es `[fila][columna]`.
Tip: Piensa en los bucles anidados como un reloj. El bucle externo es el horario (avanza lento) y el interno es el minutero (da una vuelta completa por cada hora).
Problema PS 4.35

Directorio Telefónico

Este problema introduce los **arreglos paralelos** (dos arreglos conectados por el mismo índice) y un **algoritmo de búsqueda secuencial** para encontrar o agregar contactos.

Requisitos

Crea un programa `DirectorioTelefonico.java` que:

  • Declare dos arreglos (`String[] nombre`, `String[] telefono`) de tamaño 1000.
  • Declare un contador para los contactos actuales: `int numContactosActuales = 0;`
  • Cree un bucle `while(true)` o `do-while` para el menú principal.
  • Pida al usuario un nombre a buscar (o "SALIR" para terminar).
  • Use una "bandera" `boolean encontrado = false;` y un bucle `for` (de `i = 0` a `numContactosActuales`) para **buscar** el nombre.
  • Si lo encuentra, imprime `telefono[i]` y marca `encontrado = true`.
  • **Si `encontrado` es falso**:
    1. Verifica si hay espacio: `if (numContactosActuales < N_MAX) { ... }`
    2. Si hay espacio, pide el teléfono y agrégalo: `nombre[numContactosActuales] = nombreBuscado;` y `telefono[numContactosActuales] = nuevoTelefono;`
    3. Incrementa el contador: `numContactosActuales++;`
    4. Si no hay espacio, imprime "Directorio lleno".

Ejemplo de uso esperado

Ingrese un nombre a buscar (o 'SALIR' para terminar): Ana
-> Nombre no encontrado.
Agregando nuevo contacto...
Ingrese el teléfono para Ana: 55123456
-> Contacto agregado exitosamente.

-> Teléfono encontrado: 55123456

Ingrese un nombre a buscar (o 'SALIR' para terminar): SALIR
--- Directorio cerrado ---

Notas rápidas

  • **Arreglos Paralelos:** `nombre[5]` y `telefono[5]` pertenecen a la misma persona.
  • **Búsqueda Secuencial:** Recorrer un arreglo uno por uno (de `0` a `N`) hasta encontrar algo.
  • `numContactosActuales` es la variable clave: te dice dónde agregar el próximo contacto (en el índice `N`) y hasta dónde buscar.
