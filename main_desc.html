Ejercicio 1.3: Operadores Lógicos

Evaluación de expresiones aritméticas y lógicas complejas con tipos primitivos.

Código Java

public class EjemploLogico {
    public static void main(String[] args) {
        int A = 5;
        int B = 16;
        boolean casoA = (Math.pow(A, 2) > (B / 2));
        System.out.println("Caso A: " + casoA);
        
        double x = 6;
        double b = 7.8;
        double izquierdaB = ((x * 5) + (b * 5)) / 4;
        double derechaB = ((x * 3) / b) / 5;
        boolean casoB = izquierdaB <= derechaB;
        System.out.println("Caso B: " + casoB);
        
        int izquierdaC1 = (1580 % 6) * 2 - 7;
        int izquierdaC2 = (7 + 8 * 3 - 4);
        boolean comparaIzq = izquierdaC1 > izquierdaC2;
        boolean comparaDer = (15 / 2) == (60 * 2 / 4);
        
        int boolIzq = comparaIzq ? 1 : 0;
        int boolDer = comparaDer ? 1 : 0;
        boolean resultadoFinal = boolIzq > boolDer;
        System.out.println("Caso C: " + resultadoFinal);
    }
}

Conceptos Clave

  • Precedencia de operadores.
  • Operador ternario ? :.
  • Diferencia entre división entera y double.
Nota: 15 / 2 en Java resulta en 7 (entero), no 7.5.

import java.util.Scanner;

}

Ejemplo 3.1: Nómina de Empleados

Uso básico de arreglos unidimensionales para almacenar sueldos y calcular totales.

Código Java

package Programas;
import java.util.Scanner;

public class Ejemplo_3_1 {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.println("Ingrese los sueldos de los 10 trabajadores:");
        double[] sueldos = new double[10];
        
        for (int i = 0; i < sueldos.length; i++) {
            System.out.print("Sueldo del trabajador " + (i + 1) + ": $");
            sueldos[i] = input.nextDouble();
        }
        
        double NOMINA = 0;
        for (double sueldo : sueldos) {
            NOMINA += sueldo;
        }
        System.out.println("Total de la nómina: $" + NOMINA);
    }
}

Conceptos Clave

  • Declaración de arrays new double[10].
  • Bucle for tradicional para llenado.
  • Bucle for-each para recorrido.

Problema 3.12: Búsqueda del Mayor

Algoritmo para encontrar el valor máximo dentro de un conjunto de datos ingresados dinámicamente.

Código Java

package com.mycompany.mavenproject1;
import java.util.Scanner;

public class MayorSueldo {
    public static void main(String[] args) {
        int numEmp, maNum = 0;
        float sue, maSue = 0;
        Scanner dato = new Scanner(System.in);
        
        System.out.println("Ingresar el numero de empleados");
        int n = dato.nextInt();
        
        for (int i = 1; i <= n; i++) {
            System.out.println("Ingrese el numero de empleado");
            numEmp = dato.nextInt();
            System.out.println("Ingrese el sueldo");
            sue = dato.nextFloat();
            
            if (sue > maSue) {
                maSue = sue;
                maNum = numEmp;
            }
        }
        
        System.out.println("Mayor numero de empleado: " + maNum);
        System.out.println("Mayor sueldo: " + maSue);
    }
}

Conceptos Clave

  • Inicialización de variables acumuladoras.
  • Comparación condicional dentro de un bucle.
  • Entrada dinámica de n elementos.

Ejemplo 4.9: Matriz de Cadenas

Manipulación de arreglos bidimensionales (Matrices) y aritmética de caracteres.

Código Java

public class ArregloBidimensional {
    public static void main(String[] args) {
        String[][] CADENA = new String[26][13];
        int NTE = (int) ('z' - 'a' + 1) * (7 - (-5) + 1); 
        
        for (int i = 0; i < CADENA.length; i++) {
            for (int j = 0; j < CADENA[i].length; j++) {
                char letra = (char) ('a' + i);
                int numero = j - 5;
                CADENA[i][j] = letra + "" + numero;
            }
        }
        
        String elemento1 = CADENA['b' - 'a'][-3 - (-5)];
        String elemento2 = CADENA['e' - 'a'][4 - (-5)];
        String elemento3 = CADENA['z' - 'a'][7 - (-5)];
        
        System.out.println("Elemento 1: " + elemento1);
        System.out.println("Elemento 2: " + elemento2);
        System.out.println("Elemento 3: " + elemento3);
        System.out.println("NTE: " + NTE);
    }
}

Conceptos Clave

  • Aritmética char ('a' + 1).
  • Índices calculados.
  • Casting de tipos (int) y (char).
Curiosidad: En Java, los caracteres (char) se pueden tratar como números enteros pequeños (ASCII/Unicode) para operaciones matemáticas.

Problema 4.12: Matriz Simétrica

Algoritmo para verificar si una matriz cuadrada es igual a su transpuesta (simétrica).

Código Java

package programas;
import java.util.Scanner;

public class Problema_4_12 {
    public static void main(String[] args) {
        int N, I, J, BAND;
        int[][] A;
        Scanner scanner = new Scanner(System.in);
        System.out.println("Ingrese dimensión del arreglo:");
        N = scanner.nextInt();
        
        if (N >= 1 && N <= 50) {
            A = new int[N][N];
            for (I = 0; I < N; I++) {
                for (J = 0; J < N; J++) {
                    System.out.println("Elemento " + (I + 1) + "," + (J + 1) + ":");
                    A[I][J] = scanner.nextInt();
                }
            }
            
            BAND = 1;
            I = 0;
            while (I < N && BAND == 1) {
                J = 0;
                while (J <= I && BAND == 1) {
                    if (A[I][J] != A[J][I]) {
                        BAND = 0; // No es simétrica
                    }
                    J++;
                }
                I++;
            }
            
            if (BAND == 1) {
                System.out.println("La matriz es simétrica");
            } else {
                System.out.println("La matriz no es simétrica");
            }
        } else {
            System.out.println("Dimensión incorrecta");
        }
    }
}

Conceptos Clave

  • Recorrido parcial con while (eficiencia).
  • Uso de "bandera" (flag) para detener búsqueda.
  • Propiedad simétrica: A[i][j] == A[j][i].

PS 1.12: Área de Triángulo

Cálculo del área de un triángulo a partir de las coordenadas (x,y) de sus vértices.

Código Java

package com.ITSOEH.programasjava.PS_1_12;
import java.util.Scanner;

public class CalcularAreaTriangulo {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        System.out.println("Ingrese coordenadas (x,y) de los 3 vértices:");
        
        System.out.print("P1 - X: "); double x1 = scanner.nextDouble();
        System.out.print("P1 - Y: "); double y1 = scanner.nextDouble();
        
        System.out.print("P2 - X: "); double x2 = scanner.nextDouble();
        System.out.print("P2 - Y: "); double y2 = scanner.nextDouble();
        
        System.out.print("P3 - X: "); double x3 = scanner.nextDouble();
        System.out.print("P3 - Y: "); double y3 = scanner.nextDouble();
        
        double area = calcularAreaTriangulo(x1, y1, x2, y2, x3, y3);
        System.out.println("\nEl área del triángulo es: " + area);
    }

    static double calcularAreaTriangulo(double x1, double y1, double x2, double y2, double x3, double y3) {
        double area = 0.5 * (x1 * (y2 - y3) + x2 * (y3 - y1) + x3 * (y1 - y2));
        return Math.abs(area);
    }
}

Conceptos Clave

  • Métodos estáticos con parámetros.
  • Uso de Math.abs (valor absoluto).
  • Geometría analítica en programación.

PS 3.21: Candidatos Facultad

Evaluación de múltiples condiciones para filtrar alumnos aptos para diferentes carreras.

Código Java

package Ejercicios_Libros;
import java.util.Scanner;

public class PS_3_21 {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        System.out.print("Ingrese el número de alumnos: ");
        int N = scanner.nextInt();
        
        // Arreglos paralelos para datos
        int[] matriculas = new int[N];
        int[] carreras = new int[N];
        int[] semestres = new int[N];
        double[] promedios = new double[N];
        
        for (int i = 0; i < N; i++) {
            System.out.println("--- Alumno " + (i + 1) + " ---");
            System.out.print("Matrícula: "); matriculas[i] = scanner.nextInt();
            System.out.print("Carrera (1-4): "); carreras[i] = scanner.nextInt();
            System.out.print("Semestre: "); semestres[i] = scanner.nextInt();
            System.out.print("Promedio: "); promedios[i] = scanner.nextDouble();
        }

        System.out.println("\n--- Candidatos Aceptados ---");
        for (int i = 0; i < N; i++) {
            boolean esCandidato = false;
            if (carreras[i] == 1 && semestres[i] > 5 && promedios[i] > 8.5) esCandidato = true;
            else if (carreras[i] == 2 && semestres[i] > 6 && promedios[i] > 8.8) esCandidato = true;
            else if (carreras[i] == 3 && semestres[i] > 6 && promedios[i] > 8.5) esCandidato = true;
            else if (carreras[i] == 4 && semestres[i] > 6 && promedios[i] > 8.8) esCandidato = true;
            
            if (esCandidato) {
                System.out.println("Matrícula: " + matriculas[i] + " (" + obtenerNombreCarrera(carreras[i]) + ")");
            }
        }
    }

    public static String obtenerNombreCarrera(int codigo) {
        switch (codigo) {
            case 1: return "Economía";
            case 2: return "Administración";
            case 3: return "Contabilidad";
            case 4: return "Computación";
            default: return "Desconocida";
        }
    }
}

Conceptos Clave

  • Condicionales compuestos (AND/OR).
  • Manejo de estados con banderas booleanas.
  • Uso de switch para mapear códigos.

package Ejercicios_Libros;
import javax.swing.JOptionPane;

public class Problema_4_1 {
    public static void main(String[] args) {
        String input = JOptionPane.showInputDialog("Ingresa la cantidad de valores:");
        int valorArray = Integer.parseInt(input);
        
        if (valorArray >= 1 && valorArray <= 500) {
            int[] array = new int[valorArray];
            
            // Llenado con aleatorios
            for (int i = 0; i < array.length; i++) {
                array[i] = (int) (Math.random() * 100) + 1;
            }
            
            // Impresión
            for (int i = 0; i < array.length; i++) {
                System.out.print(array[i] + ", ");
            }
            System.out.println();
        } else {
            System.out.println("La cantidad debe estar entre 1 y 500.");
        }
    }
}

Conceptos Clave

public class TablaMultiplicar {
    public static void main(String[] args) {
        System.out.println("Tabla de multiplicar del 1 al 10:");
        for (int i = 1; i <= 10; i++) {
            for (int j = 1; j <= 10; j++) {
                int resultado = i * j;
                // Formato: %2d reserva 2 espacios para el número
                System.out.printf("%2d x %2d = %3d    ", i, j, resultado);
            }
            System.out.println(); // Salto de línea por cada fila
        }
    }
}
