Ejemplo 1.14

Calculadora de Cuadrado y Cubo

¡Tu primer programa interactivo! Escribe un programa que pida al usuario un número entero y luego muestre en pantalla el cuadrado y el cubo de ese número.

Requisitos

Todo el código debe estar dentro del método main.

  • Pide al usuario que introduzca un número con el texto exacto: Introduce un número entero: .
  • Usa la clase Scanner para leer el número que el usuario escriba.
  • Calcula el cuadrado (num * num) y el cubo (num * num * num).
  • Imprime el resultado del cuadrado con el formato: "El cuadrado de [num] es: [cua]".
  • Imprime el resultado del cubo con el formato: "El cubo de [num] es: [cub]".

Ejemplo de uso esperado

Introduce un número entero: 5
El cuadrado de 5 es: 25.0
El cubo de 5 es: 125.0

Introduce un número entero: 0
El cuadrado de 0 es: 0.0
El cubo de 0 es: 0.0

Introduce un número entero: -2
El cuadrado de -2 es: 4.0
El cubo de -2 es: -8.0

Notas para tus Pruebas

Tu código se prueba de forma automática para revisar que la salida sea correcta. Por eso, ¡presta atención a estos detalles!

  • El texto que tu programa imprime debe ser idéntico al de los ejemplos de uso, incluyendo mayúsculas, espacios y los dos puntos (:).
  • Los resultados (el cuadrado y el cubo) deben ser números decimales de tipo double.
Tip: El Punto Decimal

En algunos países se usa una coma (,) para los decimales, pero en programación casi siempre se usa un punto (.).

Las pruebas automáticas esperan que uses un punto, como en 25.0. Usar variables de tipo double te ayudará a lograrlo.

Ejemplo 2.6

Selector de Acciones

Escribe un programa que pida al usuario un número entero y realice una acción diferente dependiendo del número, usando la estructura if-else if-else.

Requisitos

  • Pide al usuario un número con el texto: "Introduce un número selector (entero): ".
  • Usa Scanner para leer el número.
  • Si el número es 1 o 2, imprime "Realizando acción 1".
  • Si el número está entre 3 y 5 (ambos incluidos), imprime "Realizando acción 2".
  • Para cualquier otro número, imprime "Realizando acción 3".
  • Al final, sin importar la condición, imprime siempre "Realizando acción X".

Ejemplo de uso esperado

Introduce un número selector (entero): 1
Realizando acción 1
Realizando acción X

Introduce un número selector (entero): 4
Realizando acción 2
Realizando acción X

Introduce un número selector (entero): 8
Realizando acción 3
Realizando acción X

Notas para tus Pruebas

Recuerda que las pruebas automáticas revisarán que tu programa imprima los mensajes exactos que se piden en los requisitos.

Tip: if-else if-else vs switch

Para este ejercicio, la estructura if-else if-else es ideal porque te permite comprobar un rango de números (selector >= 3 && selector <= 5) de forma muy clara.

La estructura switch es útil cuando tienes muchos casos para valores específicos (ej: 1, 2, 3, 4, 5), pero no es tan directa para manejar rangos.

Problema 2.10

¿Cuál es el mayor de tres?

Escribe un programa que pida tres números decimales (A, B y C) e imprima en pantalla cuál es el mayor o si hay números iguales que sean los mayores.

Requisitos

  • Pide al usuario cada uno de los tres números (A, B y C).
  • Usa la clase Scanner para leer los tres números de tipo double.
  • Compara los números para encontrar el mayor o los mayores.
  • Imprime el resultado usando los mensajes exactos que se ven en los ejemplos.

Ejemplo de uso esperado

Introduce el primer número (A): 10
Introduce el segundo número (B): 5
Introduce el tercer número (C): 0
A es el mayor.

Introduce el primer número (A): 10
Introduce el segundo número (B): 5
Introduce el tercer número (C): 10
A y C son los mayores.

Introduce el primer número (A): 10
Introduce el segundo número (B): 10
Introduce el tercer número (C): 10
A, B y C son iguales.

Notas para tus Pruebas

La lógica de comparación es la clave aquí. ¡Asegúrate de que tu programa funcione para todos los casos de los ejemplos!

Tip: Orden de las condiciones

Una buena estrategia es comprobar primero el caso más simple: si los tres números son iguales (a == b && b == c).

Luego, puedes usar else if para los otros casos. Esto hace que tu código sea más ordenado y fácil de depurar.

Problema 3.7

Clasificador de Ventas

Escribe un programa que procese una serie de ventas. Primero, debe preguntar cuántas ventas se van a introducir. Luego, pedirá el monto de cada una y, al final, mostrará un resumen de cuántas ventas fueron chicas, medianas y grandes.

Requisitos

  • Define tres contadores: ventasChicas, ventasMedianas, ventasGrandes.
  • Pide al usuario la cantidad total de ventas a procesar.
  • Usa un bucle for que se repita esa cantidad de veces.
  • Dentro del bucle, pide el monto de cada venta.
  • Clasifica cada monto y aumenta el contador correspondiente:
    • Chicas: si el monto es menor o igual a 200.
    • Medianas: si es mayor a 200 pero menor a 400.
    • Grandes: si es mayor or igual a 400.
  • Al final del bucle, imprime el total de cada categoría.

Ejemplo de uso esperado

Introduce la cantidad de ventas a procesar: 5
Introduce el monto de la venta #1: 150
Introduce el monto de la venta #2: 300.50
Introduce el monto de la venta #3: 400
Introduce el monto de la venta #4: 199.99
Introduce el monto de la venta #5: 550
Resumen de ventas:
Ventas chicas (<= 200): 2
Ventas medianas (< 400): 1
Ventas grandes (>= 400): 2

Concepto Clave: Bucles

Este ejercicio introduce los bucles (o ciclos). Un bucle for es perfecto para repetir una acción un número conocido de veces, como pedir el monto de cada venta.

Tip: Operador de Incremento

Dentro del bucle, para aumentar un contador, puedes usar el operador de incremento ++.

Escribir ventasChicas++; es un atajo muy común para ventasChicas = ventasChicas + 1;. ¡Es más corto y fácil de leer!

Ejemplo 4.4.1

Eliminar Elemento (Arreglo Desordenado)

Escribe un programa que pida al usuario una lista de números (un arreglo), y luego le permita eliminar un número específico de esa lista.

Requisitos

Todo el código debe estar dentro del método main.

  • Pide el tamaño del arreglo con el texto: "Ingrese el tamaño del arreglo (N): ".
  • Pide los elementos del arreglo con el texto: "Ingrese los [n] elementos del arreglo:".
  • Pide el elemento a eliminar con el texto: "Ingrese el elemento a eliminar (X): ".
  • Busca la primera aparición del elemento a eliminar en el arreglo.
  • Si lo encuentras, "elimínalo" desplazando los elementos que están a su derecha una posición a la izquierda.
  • Imprime el mensaje de confirmación: "Elemento eliminado. Arreglo resultante:".
  • Si no lo encuentras, imprime el mensaje: "Elemento no encontrado. El arreglo no ha cambiado:".
  • Al final, imprime los elementos del arreglo resultante en una sola línea, separados por espacios.

Ejemplo de uso esperado

Ingrese el tamaño del arreglo (N): 5
Ingrese los 5 elementos del arreglo:
10
20
30
40
50
Ingrese el elemento a eliminar (X): 30
Elemento eliminado. Arreglo resultante:
10 20 40 50 

Ingrese el tamaño del arreglo (N): 3
Ingrese los 3 elementos del arreglo:
1
2
3
Ingrese el elemento a eliminar (X): 99
Elemento no encontrado. El arreglo no ha cambiado:
1 2 3

Notas para tus Pruebas

Las pruebas automáticas son muy estrictas con el texto que tu programa imprime. ¡Asegúrate de que sea idéntico al de los ejemplos!

  • Los mensajes de entrada y salida deben ser exactos, incluyendo espacios y dos puntos.
  • El arreglo final se debe imprimir en una sola línea, con un espacio después de cada número.
Tip: ¿Cómo "eliminar" un elemento?

En un arreglo básico, no puedes simplemente "borrar" un espacio. La técnica consiste en sobrescribir el elemento que quieres eliminar con el que le sigue, y así sucesivamente hasta el final.

No olvides reducir el tamaño lógico de tu arreglo (la variable n) para que al imprimirlo al final, no se muestre el último elemento duplicado.

Ejemplo 4.4.2

Eliminar Elemento (Arreglo Ordenado)

Escribe un programa que elimine un elemento de un arreglo que ya está ordenado. Para hacerlo más eficiente, deberás usar el algoritmo de búsqueda binaria.

Requisitos

Todo el código debe estar dentro del método main.

  • Pide el tamaño del arreglo con: "Ingrese el tamaño del arreglo (N): ".
  • Pide los elementos con: "Ingrese los [n] elementos del arreglo (deben estar ordenados):".
  • Pide el elemento a eliminar con: "Ingrese el elemento a eliminar (X): ".
  • Usa búsqueda binaria para encontrar la posición del elemento.
  • Si lo encuentras, elimínalo y muestra: "Elemento eliminado. Arreglo resultante:".
  • Si no lo encuentras, muestra: "Elemento no encontrado. El arreglo no ha cambiado:".
  • Al final, imprime el arreglo resultante en una sola línea, con elementos separados por espacios.

Ejemplo de uso esperado

Ingrese el tamaño del arreglo (N): 5
Ingrese los 5 elementos del arreglo (deben estar ordenados):
10
20
30
40
50
Ingrese el elemento a eliminar (X): 30
Elemento eliminado. Arreglo resultante:
10 20 40 50 

Ingrese el tamaño del arreglo (N): 4
Ingrese los 4 elementos del arreglo (deben estar ordenados):
10
20
40
50
Ingrese el elemento a eliminar (X): 30
Elemento no encontrado. El arreglo no ha cambiado:
10 20 40 50

Concepto Clave: Búsqueda Binaria

La búsqueda binaria es un algoritmo muy rápido para encontrar un elemento en un arreglo ordenado. Funciona dividiendo repetidamente el arreglo a la mitad hasta encontrar el elemento o determinar que no existe.

Tip para la Búsqueda Binaria

Necesitarás tres variables: bajo (inicio), alto (fin) y central. En cada paso del bucle, calculas central = (bajo + alto) / 2 y comparas el valor en esa posición con el que buscas. Si es mayor, ajustas alto; si es menor, ajustas bajo.

Ejemplo 4.4.3

Insertar Elemento (Arreglo Ordenado)

Escribe un programa que inserte un nuevo número en un arreglo que ya está ordenado, asegurándose de que el arreglo se mantenga ordenado después de la inserción.

Requisitos

Todo el código debe estar dentro del método main.

  • Pide la cantidad inicial de elementos con: "Ingrese la cantidad de elementos iniciales (N < 100): ".
  • Pide los elementos ordenados con: "Ingrese los [n] elementos del arreglo (ordenados):".
  • Pide el elemento a insertar con: "Ingrese el elemento a insertar (X): ".
  • Busca la posición correcta donde debe ir el nuevo elemento.
  • Si el elemento ya existe, muestra el mensaje: "No se pudo insertar el elemento (ya existe)." y el arreglo sin cambios.
  • Si el elemento no existe, desplaza los elementos necesarios a la derecha, inserta el nuevo número y muestra: "Elemento insertado exitosamente." seguido de "Arreglo resultante:".
  • Imprime siempre el estado final del arreglo en una sola línea, con elementos separados por espacios.

Ejemplo de uso esperado

Ingrese la cantidad de elementos iniciales (N < 100): 4
Ingrese los 4 elementos del arreglo (ordenados):
10
20
40
50
Ingrese el elemento a insertar (X): 30
Elemento insertado exitosamente.
Arreglo resultante:
10 20 30 40 50 

Ingrese la cantidad de elementos iniciales (N < 100): 3
Ingrese los 3 elementos del arreglo (ordenados):
10
20
30
Ingrese el elemento a insertar (X): 20
No se pudo insertar el elemento (ya existe).
10 20 30

Notas para tus Pruebas

Los mensajes que tu programa imprime deben ser exactos a los de los ejemplos para que las pruebas automáticas funcionen.

Tip: Desplazar a la Derecha

Para hacer espacio para el nuevo elemento, necesitas mover los números que son más grandes que él una posición a la derecha.

La clave es hacerlo con un bucle for que vaya desde el final hacia el principio (for (int i = n; i > pos; i--)). Si lo haces al revés, ¡sobrescribirás tus propios datos!

Ejemplo 4.4.4

Insertar Elemento (Arreglo Desordenado)

Escribe un programa que permita al usuario añadir números a un arreglo uno por uno. El programa debe continuar pidiendo números hasta que el usuario decida parar o el arreglo se llene.

Requisitos

Todo el código debe estar dentro del método main.

  • Usa un arreglo con una capacidad fija (ej. 5 o 10).
  • Dentro de un bucle while, pide un número con: "Ingrese el elemento a insertar: ".
  • Inserta el número al final del arreglo y muestra: "Elemento insertado correctamente.".
  • Muestra el estado actual del arreglo con: "Arreglo actual: [num1] [num2] ...".
  • Pregunta al usuario si quiere continuar con: "¿Desea insertar otro elemento? (s/n)".
  • El bucle debe terminar si el usuario responde algo diferente a 's' o 'S', o si el arreglo se llena.
  • Si el arreglo se llena, muestra el mensaje: "No hay más espacio para insertar elementos.".
  • Al final de todo, imprime: "Proceso finalizado.".

Ejemplo de uso esperado

Ingrese el elemento a insertar: 10
Elemento insertado correctamente.
Arreglo actual: 10 

¿Desea insertar otro elemento? (s/n)
s
Ingrese el elemento a insertar: 20
Elemento insertado correctamente.
Arreglo actual: 10 20 

¿Desea insertar otro elemento? (s/n)
n
Proceso finalizado.

Concepto Clave: Bucles Condicionales

A diferencia de un bucle for, un bucle while es perfecto cuando no sabes cuántas veces se repetirá una acción. Se ejecuta "mientras" una condición sea verdadera.

Tip: Condición del Bucle while

Tu bucle necesita dos condiciones para continuar: que haya espacio en el arreglo (n < a.length) Y que el usuario quiera continuar (continuar == 's').

Puedes unir estas condiciones con el operador && (Y lógico).

Concepto Clave: Banderas (Flags)

Una "bandera" (o flag) es una variable, usualmente de tipo booleano (true/false), que usas para señalar que un evento ha ocurrido. Es muy útil para controlar el flujo de tu programa.

Tip: Usando una Bandera

Crea una variable boolean encontrado = false;. Cuando encuentres el número que buscas, cámbiala a true.

Puedes usar esta bandera para dos cosas: 1) para detener el bucle de búsqueda una vez que ya encontraste el elemento, y 2) para decidir al final si imprimes el arreglo modificado o el mensaje de "no encontrado".

Ejemplo 5.1

Creando tu Primera Clase: Alumno

¡Bienvenido a la Programación Orientada a Objetos! En este ejercicio, crearás una "plantilla" (una clase) para representar a un Alumno. Luego, tu programa pedirá los datos de un alumno al usuario y los usará para crear un "objeto" Alumno.

Requisitos

El programa se divide en dos partes: la **clase** y el **método `main`**.

Parte 1: La Clase `P14_7_ej_5_1`
  • Debe tener atributos privados: nombre, direccion, carrera (String) y matricula (int).
  • Debe tener un **constructor** que reciba y asigne todos estos atributos.
  • Debe tener métodos `get` y `set` para cada uno de los atributos.
Parte 2: El Método `main`
  • Pide al usuario los datos de un alumno (nombre, dirección, carrera y matrícula).
  • Crea un nuevo objeto de la clase `P14_7_ej_5_1` usando los datos introducidos.
  • Imprime un reporte final con los datos del objeto creado.

Ejemplo de uso esperado

Introduce el nombre del alumno: Juan Perez
Introduce la dirección: Avenida Siempre Viva 742
Introduce la carrera: Sistemas Computacionales
Introduce la matrícula: 123456

--- Datos del Alumno Registrado ---
Nombre: Juan Perez
Matrícula: 123456
Dirección: Avenida Siempre Viva 742
Carrera: Sistemas Computacionales

Concepto Clave: Clases y Objetos

Una clase es como un plano o un molde. Define las propiedades (atributos) y los comportamientos (métodos) que algo tendrá. Un objeto es una instancia de esa clase, es decir, una "cosa" real creada a partir de ese molde.

Tip: El Constructor

El constructor es un método especial que se llama automáticamente cuando creas un nuevo objeto (new P14_7_ej_5_1(...)). Su trabajo es inicializar los atributos del objeto con los valores que le pasas.

Problema Suplementario 1.7

Calculadora de Plan de Pagos

Una agencia de autos vende vehículos a crédito. El plan consiste en dar un enganche del 35% del precio del vehículo y pagar el resto en 36 mensualidades fijas. Escribe un programa que calcule y muestre el monto del enganche y de cada mensualidad.

Requisitos

Todo el código debe estar dentro del método main.

  • Pide al usuario el precio del vehículo con el texto: "Introduce el precio del vehículo: ".
  • Calcula el enganche, que es el 35% del precio (precio * 0.35).
  • Calcula el monto restante a pagar (precio - enganche).
  • Calcula la mensualidad dividiendo el resto entre 36.
  • Imprime un reporte final con los resultados formateados a dos decimales.

Ejemplo de uso esperado

Introduce el precio del vehículo: 250000

--- Plan de Pagos ---
Enganche (35%): $87500.00
Pago mensual (36 meses): $4513.89

Formato de Moneda

Para mostrar los resultados como si fueran dinero (con dos decimales), es ideal usar System.out.printf().

Tip: Usando printf

El método System.out.printf() te permite formatear texto. Para imprimir un número de tipo double con dos decimales, usa el especificador %.2f.

Ejemplo: System.out.printf("Enganche: $%.2f\n", miVariableEnganche);

El \n al final es importante para que la siguiente línea se imprima abajo.

Problema Suplementario 3.6

Aumento de Sueldo Condicional

Una empresa aplica un aumento de sueldo del 15% a todos sus trabajadores cuyo sueldo actual es inferior a $800. Escribe un programa que pida los sueldos de N trabajadores y muestre el nuevo sueldo de cada uno.

Requisitos

Todo el código debe estar dentro del método main.

  • Pide al usuario el número de empleados con: "Introduce el número de empleados: ".
  • Usa un bucle for para procesar cada empleado.
  • Dentro del bucle, pide el sueldo de cada uno con: "Sueldo del empleado #[num]: ".
  • Si el sueldo es menor a 800, aplícale un aumento del 15% (sueldo * 1.15).
  • Imprime inmediatamente el nuevo sueldo de ese empleado, formateado a dos decimales, con el texto: " -> Nuevo sueldo: $[sueldo]".

Ejemplo de uso esperado

Introduce el número de empleados: 3
--- Introduce los sueldos ---
Sueldo del empleado #1: 500
 -> Nuevo sueldo: $575.00
Sueldo del empleado #2: 800
 -> Nuevo sueldo: $800.00
Sueldo del empleado #3: 1000
 -> Nuevo sueldo: $1000.00

Condición Clave

La condición para el aumento es estricta: sueldo < 800. Esto significa que un sueldo de exactamente 800.00 no recibe aumento.

Tip: Usando printf

Para mostrar el sueldo con formato de moneda (dos decimales), es ideal usar System.out.printf().

Ejemplo: System.out.printf(" -> Nuevo sueldo: $%.2f\n", nuevoSueldo);

El \n al final asegura que la siguiente petición de sueldo aparezca en una nueva línea.

Problema Suplementario 3.7

Calculadora de Nómina con Aumentos por Rango

Una empresa desea calcular su nómina total después de aplicar aumentos de sueldo. Los aumentos se basan en el sueldo actual del empleado: 10% si ganan menos de $10,000; 7% si ganan entre $10,000 y $25,000; y 8% si ganan más de $25,000.

Requisitos

Todo el código debe estar dentro del método main.

  • Pide al usuario el número de empleados con: "Introduce el número de empleados: ".
  • Usa un bucle for para procesar cada empleado.
  • Dentro del bucle, pide el sueldo de cada uno con: "Sueldo del empleado #[num]: ".
  • Usa una estructura if-else if-else para calcular el nuevo sueldo según el rango.
  • Imprime el nuevo sueldo de ese empleado, formateado a dos decimales: " -> Nuevo sueldo: $[sueldo]".

Rangos y Condiciones

Presta atención a los límites de los rangos. El rango intermedio incluye el 10,000 y el 25,000 (sueldo <= 25000).

Tip: Acumuladores

Un "acumulador" es una variable que usas para llevar una suma continua. Declara una variable double totalNomina = 0; antes del bucle.

Problema Suplementario 3.40

Análisis de Conductividad de Elementos

Escribe un programa que lea el nombre, la conductividad eléctrica y la conductividad térmica de varios elementos. El programa debe detenerse cuando el usuario ingrese "NN" como nombre. Al final, debe reportar cuál es el mejor y peor conductor eléctrico, y el mejor y peor conductor térmico.

Requisitos

Todo el código debe estar dentro del método main.

  • Usa un bucle do-while para pedir datos hasta que el usuario ingrese "NN".
  • Dentro del bucle, pide el nombre, la conductividad eléctrica y la conductividad térmica.
  • Guarda estos datos en tres arreglos paralelos (uno para nombres, uno para cond. eléctrica y otro para cond. térmica).
  • Después de que el usuario termine de ingresar datos, usa bucles for para encontrar los elementos con los valores máximos y mínimos para cada tipo de conductividad.
  • Imprime un reporte final con los resultados.

Concepto Clave: Arreglos Paralelos

Los arreglos paralelos son una técnica donde usas múltiples arreglos y el índice `i` se refiere a la misma entidad en todos ellos. Por ejemplo, `nombres[i]`, `condElectrica[i]` y `condTermica[i]` contienen toda la información del i-ésimo elemento.

Tip: Encontrando el Máximo/Mínimo

Para encontrar el valor máximo en un arreglo, inicializa una variable `max` con el primer valor del arreglo. Luego, recorre el resto del arreglo con un bucle `for`. Si encuentras un valor mayor que `max`, actualiza `max` con ese nuevo valor. Haz lo mismo para el mínimo.

Problema Suplementario 4.28

Verificador de Cuadrado Mágico

Un "cuadrado mágico" es una matriz cuadrada donde la suma de los números de cada fila, cada columna y ambas diagonales principales es la misma. Escribe un programa que determine si una matriz ingresada por el usuario es un cuadrado mágico.

Requisitos

Todo el código debe estar dentro del método main.

  • Pide al usuario el tamaño de la matriz cuadrada (N).
  • Usa bucles anidados para pedir al usuario cada uno de los elementos de la matriz.
  • Calcula la suma de la primera fila y úsala como la "suma de referencia".
  • Verifica que la suma de todas las demás filas, todas las columnas y ambas diagonales sea igual a la suma de referencia.
  • Si todas las sumas son iguales, imprime: "La matriz es un cuadrado mágico".
  • Si encuentras una sola suma que sea diferente, imprime: "La matriz no es un cuadrado mágico".

Ejemplo de uso esperado

Introduce el tamaño de la matriz cuadrada (N): 3
Introduce los elementos de la matriz:
Elemento [0][0]: 8
Elemento [0][1]: 1
Elemento [0][2]: 6
Elemento [1][0]: 3
Elemento [1][1]: 5
Elemento [1][2]: 7
Elemento [2][0]: 4
Elemento [2][1]: 9
Elemento [2][2]: 2
La matriz es un cuadrado mágico

Concepto Clave: Matrices

Una matriz (o arreglo bidimensional) es como una tabla o una cuadrícula. Se declara con dos pares de corchetes: int[][] matriz = new int[N][N];. Para acceder a un elemento, necesitas dos índices: uno para la fila y otro para la columna (matriz[fila][columna]).

Tip: Usando una Bandera

Crea una variable boolean esMagico = true; al principio. Dentro de tus bucles de verificación, si encuentras una suma que no coincide con la de referencia, simplemente cambia la bandera a false.

Al final, solo necesitas un if (esMagico) para decidir qué mensaje imprimir. Esto es más limpio que tener múltiples mensajes de error y salidas del programa.
