Evaluación de Expresiones Lógicas (Operadores)

Este ejemplo demuestra la jerarquía de operadores y la evaluación paso a paso de expresiones lógicas (booleanas) complejas, combinando operadores aritméticos, relacionales y lógicos (Y, O, NO).

Requisitos

  • Evaluar el resultado de tres expresiones lógicas complejas.
  • Aplicar correctamente la jerarquía de operadores (aritméticos, relacionales y lógicos)
  • Caso a: `NO(15 >= 7**2) O (43 - 8 * 2 div 4 <> 3 * 2 div 2).
  • Caso b: `(15 >= 7*3**2 Y 8 > 3 Y 15 > 6) O NO(7*3 < 5 + 12*2 div 3**2).
  • Caso c: Demostrar un error de tipo al comparar un valor lógico con uno numérico.

Ejemplo de uso esperado (Java)

public class EvaluacionExpresiones {
    public static void main(String[] args) {

        // --- Caso a) ---
        // Pseudocódigo: NO(15 >= 7**2) O (43 - 8 * 2 div 4 <> 3 * 2 div 2) 
        // 'div' es división entera
        boolean casoA = !(15 >= Math.pow(7, 2)) || (43 - (8 * 2 / 4) != (3 * 2 / 2));
        System.out.println("Caso a) Resultado: " + casoA); // Esperado: true 

        // --- Caso b) ---
        // Pseudocódigo: (15 >= 7*3**2 Y 8 > 3 Y 15 > 6) O NO(7*3 < 5 + 12*2 div 3**2) 
        // 12*2 div 3**2 = 24 div 9 = 2
        boolean parteB1 = (15 >= (7 * Math.pow(3, 2))) && (8 > 3) && (15 > 6);
        boolean parteB2 = !( (7 * 3) < (5 + (12 * 2 / (int)Math.pow(3, 2))) );
        boolean casoB = parteB1 || parteB2;
        System.out.println("Caso b) Resultado: " + casoB); // Esperado: true 
        
        // --- Caso c) ---
        // Pseudocódigo: NO( (7*3 div 2 * 4) > (15/2 * 6 >= 15*2 / 17 = 15) ) 
        // El libro identifica esto como un error.
        // La expresión (15/2 * 6 >= 15*2 / 17) da VERDADERO.
        // La expresión (VERDADERO = 15) es un error de tipos.
        
        // En Java, esto ni siquiera compila, demostrando el error de tipos:
        // boolean error = (true == 15); // <-- Error: incomparable types: boolean and int
        System.out.println("Caso c) Produce un error de tipos al comparar VERDADERO con 15, como se indica en el libro.");
    }
}

Notas rápidas

Conversión de pseudocódigo a Java:

  • ** (potencia) es Math.pow()
  • div (div. entera) es / (con operandos int)
  • O (OR) es ||
  • Y (AND) es &&
  • NO (NOT) es !
  • <> (diferente) es !=

Calcular Área y Volumen de un Cilindro

Construya un diagrama de flujo tal que dado como datos el radio y la altura de un cilindro, calcule e imprima el área y su volumen.

Requisitos

  • Datos: RADIO, ALTU (variables de tipo real).
  • Calcular el volumen con la fórmula: $Volumen = \pi \cdot radio^2 \cdot altura$.
  • Calcular el área (lateral) con la fórmula: $Area = 2 \cdot \pi \cdot radio \cdot altura$.
  • Imprimir ambos resultados.

Diagrama de Flujo

Ejemplo de uso esperado (Java)

import java.util.Scanner;

public class Cilindro {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Ingrese el radio del cilindro: ");
        double radio = scanner.nextDouble();

        System.out.print("Ingrese la altura del cilindro: ");
        double altura = scanner.nextDouble();

        // Usar Math.PI para precisión
        double volumen = Math.PI * Math.pow(radio, 2) * altura;
        double area = 2 * Math.PI * radio * altura;

        System.out.println("--- Resultados ---");
        System.out.printf("Volumen: %.4f\n", volumen);
        System.out.printf("Área: %.4f\n", area);
        
        scanner.close();
    }
}

Notas rápidas

Este problema introduce:

  • Lectura de datos (entrada).
  • Procesamiento (cálculos matemáticos).
  • Escritura de datos (salida).
  • Uso de constantes como $\pi$.

Ordenar Tres Números en Forma Descendente

Dados los datos A, B y C que representan números enteros diferentes, construya un diagrama de flujo para escribir estos números en forma descendente.

Requisitos

  • Datos: A, B, C (variables de tipo entero).
  • Se asume que los números son diferentes.
  • Imprimir los tres números ordenados del mayor al menor.
  • Utilizar estructuras selectivas en cascada (anidadas).

Diagrama de Flujo

Ejemplo de uso esperado (Java)

import java.util.Scanner;

public class OrdenarNumeros {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Ingrese el número A: ");
        int a = scanner.nextInt();
        System.out.print("Ingrese el número B: ");
        int b = scanner.nextInt();
        System.out.print("Ingrese el número C: ");
        int c = scanner.nextInt();

        System.out.print("Orden descendente: ");

        // Lógica del Diagrama de Flujo 2.15
        if (a > b) {
            if (a > c) {
                if (b > c) {
                    System.out.println(a + ", " + b + ", " + c); // A, B, C
                } else {
                    System.out.println(a + ", " + c + ", " + b); // A, C, B
                }
            } else {
                System.out.println(c + ", " + a + ", " + b); // C, A, B
            }
        } else { // B >= A
            if (b > c) {
                if (a > c) {
                    System.out.println(b + ", " + a + ", " + c); // B, A, C
                } else {
                    System.out.println(b + ", " + c + ", " + a); // B, C, A
                }
            } else {
                System.out.println(c + ", " + b + ", " + a); // C, B, A
            }
        }
        
        scanner.close();
    }
}

Notas rápidas

  • Este ejercicio es clave para entender las estructuras selectivas anidadas (if-else dentro de if-else).
  • La lógica de árbol de decisión cubre todas las permutaciones posibles de orden.

Calcular Nómina con Estructura Repetitiva

Solución al problema de calcular la nómina total de 10 trabajadores de una empresa, utilizando una estructura algorítmica repetitiva (repetir o FOR).

Requisitos

  • Datos: SUEi (variable de tipo real que representa el sueldo del trabajador i, con $1 \le i \le 10$).
  • Utilizar una variable acumuladora (NOMINA) para sumar los sueldos.
  • Utilizar una variable contadora (I) para controlar el ciclo.
  • El ciclo debe ejecutarse 10 veces.
  • Imprimir el total de la nómina.

Diagrama de Flujo

Ejemplo de uso esperado (Java)

import java.util.Scanner;

public class NominaRepetitiva {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        double nomina = 0; // Acumulador
        double sueldo;

        System.out.println("Ingrese los 10 sueldos:");

        // Estructura Repetir (FOR)
        for (int i = 1; i <= 10; i++) {
            System.out.print("Sueldo del trabajador " + i + ": ");
            sueldo = scanner.nextDouble();
            nomina = nomina + sueldo; // Acumular
        }

        System.out.printf("\nEl total de la nómina es: %.2f\n", nomina);
        
        scanner.close();
    }
}

Notas rápidas

  • Este ejemplo introduce el concepto de acumulador (una variable que suma valores en cada iteración).
  • También muestra un ciclo definido (FOR), donde se sabe de antemano el número de repeticiones.

Promedios Lluvias Regiones Cerealeras

En el centro meteorológico de Argentina se llevan los promedios mensuales de las lluvias caídas en las regiones NORTE, CENTRO y SUR. Se necesita calcular: a) El promedio anual de la región centro, b) El mes y registro con menor lluvia en la región sur, c) La región con mayor lluvia anual.

Requisitos

  • Datos: RNO, RCE, RSU (lluvia de las 3 regiones) por cada mes (12 veces).
  • a) Calcular $PRORCE = (\sum RCE) / 12$.
  • b) Encontrar el valor $MERSU$ (menor lluvia en SUR) y $MES$ (el mes en que ocurrió).
  • c) Comparar los totales $ARNO$, $ARCE$ y $ARSU$ para determinar la región con mayor lluvia.

Diagrama de Flujo

Ejemplo de uso esperado (Java)

import java.util.Scanner;

public class Meteorologico {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        double arno = 0, arce = 0, arsu = 0;
        double mersu = 500000; // Valor inicial alto para buscar el mínimo
        int mesMersu = 0;

        for (int i = 1; i <= 12; i++) {
            System.out.println("--- Mes " + i + " ---");
            System.out.print("Lluvia Región Norte: ");
            double rno = scanner.nextDouble();
            System.out.print("Lluvia Región Centro: ");
            double rce = scanner.nextDouble();
            System.out.print("Lluvia Región Sur: ");
            double rsu = scanner.nextDouble();

            arno += rno;
            arce += rce;
            arsu += rsu;

            if (rsu < mersu) {
                mersu = rsu;
                mesMersu = i;
            }
        }

        // a) Promedio Región Centro
        double prorce = arce / 12;
        System.out.printf("\na) Promedio anual Región Centro: %.2f\n", prorce);

        // b) Menor lluvia Región Sur
        System.out.printf("b) Menor lluvia Región Sur fue en el mes %d (Registro: %.2f)\n", mesMersu, mersu);

        // c) Región con mayor lluvia anual
        System.out.print("c) Región con mayor lluvia anual: ");
        if (arno > arce && arno > arsu) {
            System.out.println("NORTE");
        } else if (arce > arno && arce > arsu) {
            System.out.println("CENTRO");
        } else {
            System.out.println("SUR");
        }
        
        scanner.close();
    }
}

Notas rápidas

  • Este problema combina múltiples cálculos dentro de un solo ciclo FOR.
  • Introduce la técnica de búsqueda de mínimo, inicializando una variable con un valor muy alto.

Intercambiar Renglones de una Matriz Cuadrada

Construya un diagrama de flujo que intercambie los renglones de un arreglo bidimensional cuadrado (A[N x N]). El renglón 1 debe intercambiarse con el N, el 2 con el N-1, y así sucesivamente.

Requisitos

  • Datos: Matriz A[N, N] (tipo entero, $1 < N < 50$).
  • El intercambio es simétrico: Renglón $i$ se intercambia con $N - 1 - i$ (en base 0) o $N - i + 1$ (en base 1).
  • El ciclo principal debe iterar solo hasta la mitad de los renglones ($N / 2$).
  • Se debe usar una variable $AUX$ para el intercambio.

Diagrama de Flujo

Ejemplo de uso esperado (Java)

import java.util.Arrays;

public class IntercambiarRenglones {

    // Método para imprimir la matriz
    public static void printMatrix(int[][] matrix) {
        for (int[] row : matrix) {
            System.out.println(Arrays.toString(row));
        }
    }

    public static void main(String[] args) {
        // Ejemplo N=4
        int n = 4;
        int[][] a = {
            {10, 15, 28, 49},
            {68, 115, 36, 15},
            {90, 0, 7, 28},
            {87, 5, 13, 56}
        };

        System.out.println("--- Matriz Original ---");
        printMatrix(a);

        // Lógica de intercambio (índices base 0)
        // El ciclo va hasta N / 2
        for (int i = 0; i < n / 2; i++) {
            // Iterar por todas las columnas (J)
            for (int j = 0; j < n; j++) {
                int aux = a[i][j];
                a[i][j] = a[n - 1 - i][j]; // Fila opuesta
                a[n - 1 - i][j] = aux;
            }
        }

        System.out.println("\n--- Matriz Modificada ---");
        printMatrix(a);
    }
}

Notas rápidas

  • El bucle exterior (i) solo necesita llegar a N / 2. Si llega hasta N, volvería a intercambiar los renglones, revirtiendo la operación.
  • El bucle interior (j) debe recorrer todas las columnas.

Suma de Matrices Esparcidas

Una matriz esparcida (mayoría de ceros) no se almacena completa. Solo se guardan los valores distintos de cero, junto con su renglón y columna. El programa debe: a) Leer matrices A y B, y guardarlas en arreglos de registros (A1, B1). b) Obtener la matriz C = A + B, usando solo A1 y B1. c) Imprimir C.

Requisitos

  • Datos: Dos matrices A(M x N) y B(M x N), 1 < M < 50, 1 < N < 30.
  • Definir una estructura (Registro) para almacenar: REN, COL, VAL.
  • a) Llenar los arreglos A1 y B1 (Arreglos de Registros) solo con los valores distintos de 0.
  • b) Calcular C(M x N) = A + B. La suma debe hacerse "mezclando" (merge) los arreglos A1 y B1, similar a un merge sort.
  • c) Imprimir la matriz C resultante.

Diagrama de Flujo

Ejemplo de uso esperado (Java)

import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

// (Clase MatrizElemento va primero)

public class SumaMatricesEsparcidas {
    
    // (Clase interna MatrizElemento)
    static class MatrizElemento {
        int ren, col, val;
        MatrizElemento(int ren, int col, int val) {
            this.ren = ren; this.col = col; this.val = val;
        }
    }

    public static void main(String[] args) {
        // Asumimos M=3, N=4 para el ejemplo
        int M = 3, N = 4;
        // Simulación de lectura
        List A1 = new ArrayList<>();
        List B1 = new ArrayList<>();

        // Matriz A: [5,0,0,8], [0,0,7,0], [0,3,0,0]
        A1.add(new MatrizElemento(0, 0, 5));
        A1.add(new MatrizElemento(0, 3, 8));
        A1.add(new MatrizElemento(1, 2, 7));
        A1.add(new MatrizElemento(2, 1, 3));
        
        // Matriz B: [0,0,0,8], [0,6,0,0], [0,3,4,0]
        B1.add(new MatrizElemento(0, 3, 8));
        B1.add(new MatrizElemento(1, 1, 6));
        B1.add(new MatrizElemento(2, 1, 3));
        B1.add(new MatrizElemento(2, 2, 4));

        int[][] C = new int[M][N]; // Inicializada en 0 por defecto

        // b) Lógica de suma (Merge)
        int i = 0, j = 0;
        while (i < A1.size() && j < B1.size()) {
            MatrizElemento elA = A1.get(i);
            MatrizElemento elB = B1.get(j);

            if (elA.ren < elB.ren) { // Renglón A es menor
                C[elA.ren][elA.col] = elA.val;
                i++;
            } else if (elB.ren < elA.ren) { // Renglón B es menor
                C[elB.ren][elB.col] = elB.val;
                j++;
            } else { // Renglones iguales, comparar columnas
                if (elA.col < elB.col) {
                    C[elA.ren][elA.col] = elA.val;
                    i++;
                } else if (elB.col < elA.col) {
                    C[elB.ren][elB.col] = elB.val;
                    j++;
                } else { // Misma posición: sumar
                    C[elA.ren][elA.col] = elA.val + elB.val;
                    i++;
                    j++;
                }
            }
        }
        // Añadir restantes de A1
        while (i < A1.size()) { C[A1.get(i).ren][A1.get(i).col] = A1.get(i).val; i++; }
        // Añadir restantes de B1
        while (j < B1.size()) { C[B1.get(j).ren][B1.get(j).col] = B1.get(j).val; j++; }

        // c) Imprimir C
        System.out.println("--- Matriz Resultante C ---");
        for (int r = 0; r < M; r++) {
            System.out.println(java.util.Arrays.toString(C[r]));
        }
        // Resultado esperado: [5,0,0,16], [0,6,7,0], [0,6,4,0]
    }
}

Notas rápidas

  • Este problema introduce Arreglos de Registros (en Java, `ArrayList` de una clase personalizada).
  • La lógica de suma (inciso b) es el algoritmo de "merge" (fusión) más complejo de este conjunto de problemas.

Calcular Áreas y Volumen de un Prisma Pentagonal

Construya un diagrama de flujo tal que dado el perímetro de la base, el apotema y la altura de un prisma pentagonal; calcule el área de la base, el área lateral, el área total y el volumen.

Requisitos

  • Datos: PER, APO, ALT (variables de tipo real).
  • Calcular Área Base: $AB = (PER \cdot APO) / 2$.
  • Calcular Área Lateral: $AL = PER \cdot ALT$.
  • Calcular Área Total: $AT = 2 \cdot AB + AL$.
  • Calcular Volumen: $VOL = AB \cdot ALT$.

Ejemplo de uso esperado (Java)

import java.util.Scanner;

public class PrismaPentagonal {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Ingrese el perímetro de la base (PER): ");
        double per = scanner.nextDouble();
        System.out.print("Ingrese el apotema (APO): ");
        double apo = scanner.nextDouble();
        System.out.print("Ingrese la altura (ALT): ");
        double alt = scanner.nextDouble();

        // Cálculos
        double areaBase = (per * apo) / 2.0;
        double areaLateral = per * alt;
        double areaTotal = (2 * areaBase) + areaLateral;
        double volumen = areaBase * alt;

        // Resultados
        System.out.println("\n--- Resultados del Prisma ---");
        System.out.printf("Área de la Base: %.2f\n", areaBase);
        System.out.printf("Área Lateral: %.2f\n", areaLateral);
        System.out.printf("Área Total: %.2f\n", areaTotal);
        System.out.printf("Volumen: %.2f\n", volumen);
        
        scanner.close();
    }
}

Notas rápidas

  • Este es un problema secuencial simple.
  • Se enfoca en la correcta aplicación de fórmulas matemáticas.
  • No hay diagrama de flujo en el libro para este problema.

Promedio de 35 Alumnos (Lectura Plana)

En una clase de una universidad se tienen 35 alumnos. Haga un diagrama de flu jo que calcule e imprima la matrícula y el promedio de calificaciones de cada alumno. Cada alumno de la clase tiene 5 calificaciones.

Requisitos

  • Datos: Un total de 35 alumnos.
  • Para cada alumno, se leen 6 datos: $MAT, CAL1, CAL2, CAL3, CAL4, CAL5$.
  • Se debe usar un ciclo FOR (Repetir) que se ejecute 35 veces.
  • Dentro del ciclo, leer los 6 datos, calcular el promedio de las 5 calificaciones.
  • Imprimir la matrícula y el promedio de ese alumno.

Ejemplo de uso esperado (Java)

import java.util.Scanner;

public class PromedioAlumnosV1 {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        final int TOTAL_ALUMNOS = 35;

        // Ciclo externo para los 35 alumnos
        for (int i = 1; i <= TOTAL_ALUMNOS; i++) {
            System.out.println("\n--- Alumno " + i + " ---");
            System.out.print("Ingrese Matrícula: ");
            int matricula = scanner.nextInt();

            // Lectura "plana" de las 5 calificaciones
            System.out.print("Ingrese Calificación 1: ");
            double cal1 = scanner.nextDouble();
            System.out.print("Ingrese Calificación 2: ");
            double cal2 = scanner.nextDouble();
            System.out.print("Ingrese Calificación 3: ");
            double cal3 = scanner.nextDouble();
            System.out.print("Ingrese Calificación 4: ");
            double cal4 = scanner.nextDouble();
            System.out.print("Ingrese Calificación 5: ");
            double cal5 = scanner.nextDouble();

            double promedio = (cal1 + cal2 + cal3 + cal4 + cal5) / 5.0;

            System.out.printf("-> Matrícula: %d, Promedio: %.2f\n", matricula, promedio);
        }

        System.out.println("\nProceso completado.");
        scanner.close();

Contar Ocurrencias en Arreglo Unidimensional

Construya un programa tal que dado como entrada un arreglo unidimensional de enteros y un número entero, determine cuántas veces se encuentra el número dentro del arreglo.

Requisitos

  • Datos: VEC (arreglo de 100 enteros), NUM (entero a buscar).
  • Recorrer el arreglo $VEC$ completo.
  • Usar un contador para registrar las veces que $NUM$ aparece en $VEC$.
  • Imprimir el contador final.

Ejemplo de uso esperado (Java)

import java.util.Scanner;

public class ContarEnArreglo {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        // Simulación del arreglo VEC[100]
        int[] vec = {5, 10, 15, 5, 20, 25, 5, 30}; // Ejemplo corto
        // int[] vec = new int[100];
        // ... (Aquí iría la lógica para llenar el arreglo)

        System.out.print("Ingrese el número a buscar: ");

        for (int i = 0; i < vec.length; i++) {
            if (vec[i] == num) {

            }

Problema PS 4.18 (pág. 446)

Generar Matriz Identidad

Construya un diagrama de flujo que llene de ceros una matriz cuadrada A [N x N], excepto en la diagonal principal donde debe asignar 1.

Requisitos

  • Datos: N (dimensión de la matriz, $1 < N < 50$).
  • Crear una matriz A[N][N].
  • Usar ciclos anidados (para $i$ y $j$).
  • Si $i == j$ (diagonal principal), asignar 1.
  • Si $i != j$, asignar 0.
  • Imprimir la matriz resultante.

Ejemplo de uso esperado (Java)

import java.util.Arrays;
import java.util.Scanner;

public class MatrizIdentidad {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Ingrese la dimensión N de la matriz: ");
        int n = scanner.nextInt();

        if (n < 1 || n > 50) {
            System.out.println("Dimensión fuera de rango.");
        } else {
            int[][] a = new int[n][n];

            // Llenar la matriz
            for (int i = 0; i < n; i++) {
                for (int j = 0; j < n; j++) {
                    if (i == j) {
                        a[i][j] = 1; // Diagonal principal
                    } else {
                        a[i][j] = 0; // Fuera de la diagonal
                    }
                }
            }

            // Imprimir la matriz
            System.out.println("--- Matriz Identidad Generada ---");
            for (int[] row : a) {
                System.out.println(Arrays.toString(row));
            }
        }
        scanner.close();
    }
}

Notas rápidas

  • Este ejercicio es clave para entender el manejo de índices (i, j) en matrices.
  • La condición i == j es la definición de la diagonal principal.
  • No hay diagrama de flujo en el libro para este problema.
Problema PS 4.34 (pág. 453)

Producción de Fábrica (Arreglo Tridimensional)

Se tiene un arreglo tridimensional (FABRICA[12, 4, 3]) con la producción de 12 meses, 4 años y 3 departamentos (dulces, conservas, bebidas). Se pide calcular: a) Departamento con mayor producción en 4 años. b) Mes del 2do año con mayor producción. c) Año con mayor producción. d) Depto, mes y año de la mayor producción.

Requisitos

  • Datos: Arreglo FABRICA[12][4][3] (Mes, Año, Depto).
  • a) Acumular por departamento y encontrar el máximo.
  • b) Acumular por mes (solo del 2do año, índice 1) y encontrar el máximo.
  • c) Acumular por año y encontrar el máximo.
  • d) Encontrar el valor máximo individual en la matriz 3D y guardar sus 3 índices.

Ejemplo de uso esperado (Java)

import java.util.Random;

public class ProduccionFabrica {
    public static void main(String[] args) {
        // [12 Meses][4 Años][3 Departamentos]
        double[][][] fabrica = new double[12][4][3];
        Random rand = new Random();
        String[] deptos = {"Dulces", "Conservas", "Bebidas"};

        // Simular llenado de datos
        for (int m = 0; m < 12; m++) {
            for (int a = 0; a < 4; a++) {
                for (int d = 0; d < 3; d++) {
                    fabrica[m][a][d] = rand.nextDouble() * 1000;
                }
            }
        }

        // a) Departamento con mayor producción en 4 años
        double[] totalDepto = new double[3];
        for (int d = 0; d < 3; d++) {
            for (int m = 0; m < 12; m++) {
                for (int a = 0; a < 4; a++) {
                    totalDepto[d] += fabrica[m][a][d];
                }
            }
        }
        int maxDeptoIdx = (totalDepto[0] > totalDepto[1] && totalDepto[0] > totalDepto[2]) ? 0 : (totalDepto[1] > totalDepto[2] ? 1 : 2);
        System.out.printf("a) Depto. con mayor producción: %s (%.2f)\n", deptos[maxDeptoIdx], totalDepto[maxDeptoIdx]);

        // b) Mes del 2do año (índice 1) con mayor producción
        double maxProdMes = -1;
        int mesMax = 0;
        for (int m = 0; m < 12; m++) {
            double sumaMes = 0;
            for (int d = 0; d < 3; d++) {
                sumaMes += fabrica[m][1][d]; // Año índice 1 (2do año)
            }
            if (sumaMes > maxProdMes) {
                maxProdMes = sumaMes;
                mesMax = m + 1;
            }
        }
        System.out.printf("b) Mes de mayor producción (2do año): Mes %d (%.2f)\n", mesMax, maxProdMes);

        // c) Año con mayor producción
        double[] totalAnio = new double[4];
        for (int a = 0; a < 4; a++) {
            for (int m = 0; m < 12; m++) {
                for (int d = 0; d < 3; d++) {
                    totalAnio[a] += fabrica[m][a][d];
                }
            }
        }
        int maxAnioIdx = 0;
        for (int a = 1; a < 4; a++) {
            if (totalAnio[a] > totalAnio[maxAnioIdx]) maxAnioIdx = a;
        }
        System.out.printf("c) Año con mayor producción: %d (%.2f)\n", maxAnioIdx + 1, totalAnio[maxAnioIdx]);

        // d) Depto, mes y año de la mayor producción individual
        double maxIndividual = -1;
        int mesM = 0, anioM = 0, deptoM = 0;
        for (int m = 0; m < 12; m++) {
            for (int a = 0; a < 4; a++) {
                for (int d = 0; d < 3; d++) {
                    if (fabrica[m][a][d] > maxIndividual) {
                        maxIndividual = fabrica[m][a][d];
                        mesM = m + 1;
                        anioM = a + 1;
                        deptoM = d;
                    }
                }
            }
        }
        System.out.printf("d) Mayor producción: %.2f (Mes: %d, Año: %d, Depto: %s)\n", 
            maxIndividual, mesM, anioM, deptos[deptoM]);
    }
}

  • Es un ejercicio avanzado sobre manipulación de arreglos multidimensionales.
